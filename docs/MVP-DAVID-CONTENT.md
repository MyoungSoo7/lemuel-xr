# MVP-DAVID — XR 실 콘텐츠 (Scene 별 대본·인터랙션·자원)

> **상위 문서**: `MVP-DAVID.md` (구조·설계 — 6 Scene + 5 돌 = 5 감정)
> **본 문서**: 실제 사용자에게 노출되는 *대본·자산·인터랙션 트리거* — Unity 6 LTS + OpenXR 환경에서 그대로 구현 가능한 수준의 데이터.
> **타겟 디바이스**: Quest 3 (기준) / Quest Pro / Vision Pro / Galaxy XR — capabilities-min: 6DoF + hand tracking + spatial audio. eye tracking 은 optional.
> **세션 길이**: 6분 ± 1분. *5분 안에 종료 가능한 short path* 와 *7분 안에 종료 가능한 deep path* 분기.
> **포지셔닝**: *영적 비상 대비 교육 콘텐츠* (큐티 + 민방위 metaphor). *임상/의료 도구 아님 — 누구나 대상*.
> **신학·안전 톤**: `lemuel-xr-theology-tone` 사전 가이드 적용 — disputed_points 명시, R1 (109) 유지 + R2~R5 원리는 일반 사용자 보호선으로 잔류, *AI 보조 — 본문은 성경 참조 — storyteller 역할* footer 자동. 출판 전 *운영자 self-review + R1 통과* 가 검수 게이트.
> **근거 인용**: `THEOLOGY-REFERENCES.md` 의 D1 (장석정 2022, 다윗과 골리앗 — *개념성·속도* 중심 재해석) 을 핵심 인용. D2 (시편 신학) · D3 (한국 구약학 흐름) 보조.

### 0.2 인터랙션 추상화

| 인터랙션 의도 | Quest 3 (기준) | Vision Pro | Galaxy XR | Web 폴백 |
|---|---|---|---|---|
| 물체 잡기 (수금 줄 · 돌) | controller grip / pinch | pinch + dwell | controller grip | click + hold |
| 시선 응시 (NPC 마주봄) | head ray + 1초 dwell | eye gaze + 0.5초 | head ray + 1초 | mouseover + 1초 |
| 돌 던지기 (3m) | controller release + velocity | pinch release + velocity | controller release | click + drag arrow |
| 다음 진행 | A button / pinch | pinch | A button | click "다음" |
| 침묵 모드 (말 안 함) | controller 잠시 내려놓기 (10초 무동작) | hand 휴식 자세 | 동일 | "잠시 멈춤" 버튼 |
| 메뉴 호출 | menu button | 손 손바닥 위로 | menu | top-right ⋯ |

→ 모든 결정은 *손동작* 으로 표현. 컨트롤러 키 라벨에 의존하지 않음 — *말이 아니라 행위* 가 다윗 미션의 핵심. 특히 **돌 잡기 / 돌 던지기** 는 손 자체로 해야 하는 *제의적 동작*. controller 없는 Vision Pro 의 *pinch* 도 *동등 가치* — *어느 디바이스에서도 다윗의 손이 된다*.

### 0.3 시간·공간 안락성

- 카메라 *이동 없음* (정지 시점 only) — 모션 시크니스 회피
- 큰 환경 전환은 fade-to-black 0.8초 + 페이드인 1.2초로 처리
- *3D 사운드 우선 + 텍스트 자막 동기* (청각 장애 / 무음 환경 대응)
- 모든 NPC 음성 (다윗 자신·엘리압·사울·골리앗·내레이션) 은 Coqui XTTS-v2 사전 캐시 (오프라인 동기화 가능, R5 AI opt-out 시에도 작동). voice_id 매핑:
  - `david_v1` — 소년 톤. *너무 어리지 않게·너무 성숙하지 않게* 큐레이션
  - `eliab_v1` — 30대 남성, 약간 빈정거리는 톤
  - `saul_v1` — 중년 남성, 위엄 + 약간의 피로
  - `goliath_v1` — 낮은 베이스 + 약한 reverb. *위협 강도 토글* (off/약/강)

### 0.4 결정 기록 (백엔드)

각 Scene 의 사용자 결정 → `POST /api/game/david/scene/{n}/decide` →
- `game_decisions` 테이블에 JSONB 로 기록 (V4 schema)
- `scene_views` 에 entered/exited timestamp 기록 (Window of Tolerance 분석용)
- `interaction_meta` 에 *돌을 잡고 망설인 시간, 돌 선택 순서, sling 회전 횟수* 같은 마이크로 신호 기록

→ Day 30 리포트 (`v_user_30d_summary`) 에서 *어느 감정 돌을 가장 *먼저* / *마지막* 으로 골랐는가* 가 의미 있는 패턴으로 노출.

### 0.5 항상 노출되는 footer

화면 좌하단 (UI 안전 영역) 에 작은 글씨로 *영구* 노출:

```
AI 보조 — 본문은 성경 참조 — storyteller 역할 | 위기 시 109
```

→ R5 + theology-tone 7번 + R1 (109) 항상 충족. *AI 는 치료자/자살예방 전문가 아닌 이야기 안내자 — 위기 영역은 외부 자원으로 즉시 연결*.

### 0.6 다윗 미션 *전체* 에 걸친 톤 정책 (R2/R3 사전 가드)

- *"믿음으로 거인을 이기세요"* 류 압박 톤 **차단**. 대신 *"오늘 한 돌만 주머니에 넣어도 충분합니다"*.
- *"믿음과 능력은 적이 아니다"* — D1 (장석정 2022) 의 *속도 vs 무게* 통찰을 기반으로, *"다 맡기고 가만히 있으라"* 식 수동성 미화 표현을 **사전 차단**. *누구나* — 절망 대비 훈련 중인 사용자가 *"네가 약해서 못 이긴다"* 로 미끄러질 어휘 제거.
- *"작다 = 약하다"* 가 아니라 *"작다 = 누구의 옷도 입지 않은 자유"* — 사용자 자기비난의 reframe.

## 1. Scene 1 — 양치는 베들레헴 (1분)

### 1.1 배경·환경

- **공간**: 베들레헴 들판. 해 질 무렵. 멀리 양 떼 12 마리가 풀을 뜯고 있음. 사용자는 *돌 위에 앉아있는 시점* (정지 카메라).
- **사용자 위치**: 손 안에 *수금 (lyre)* 이 자동 fade-in. 사용자가 *손으로 줄을 건드릴 수 있음*.
- **에셋 분량**: glb 10MB (manifest: `david/scene1/quest3/v1.0.0.json`)
- **공간 음향**: 멀리서 양의 *낮은 메에* 소리 (좌우 panning), 바람 소리, 들판 풀벌레. 수금 줄이 건드려질 때 *부드러운 현 소리* (5 음계 사전 샘플).

### 1.2 대본

**[내레이션 — 0:00]**
> *"여기 베들레헴 들판에 한 소년이 있다.*
> *8 형제 중 막내. 들에서 양을 지키는 자.*
> *해가 지면 그는 수금을 들고 노래한다."*

**[사용자 손 안에 수금 fade-in — 0:10]**

UI:
- 수금이 살짝 빛남
- 사용자가 *손으로 줄 5개* 를 건드릴 수 있음. 각 줄을 건드릴 때마다 *시편 23편의 한 구절* 이 fade-in.

**[수금 줄 ↔ 시편 23편 매핑]**

| 줄 | 떠오르는 구절 |

### 1.3 인터랙션

- 사용자는 *수금 줄 5개* 를 *어떤 순서로든* 건드릴 수 있음. 순서 자체가 `interaction_meta.lyre_string_order` 로 기록 — *어떤 구절에 먼저 끌렸는가* 가 사용자 정서 신호.
- 줄을 건드릴 때 *햅틱 약함* (지속 80ms, 강도 0.25) — 현의 진동 감각.
- *건너뛰기 가능* (3초 후 우상단에 작은 버튼) — Scene 1 의 평온이 *지루함* 으로 느껴지는 사용자 보호.

### 1.4 안전·신학 footer

- **신학**: 시편 23편은 *목자의 노래로 인류가 가장 오래 외워 온 시편* — 평안의 어휘로 *내적 단련* 의 토대. (참고 서지: Pargament — *Religious Coping*. 임상 메커니즘이 아니라 *내적 단련 근거 서지* 로 격하 인용.) 본 Scene 은 *"3000년 시인의 평온"* 톤으로 reframing — *장례식 연상* 으로 미끄러지지 않게.
- **D2 인용**: *"하나님 나라와 언약관점으로 본 시편 신학연구"* — 시편은 *다윗 언약의 노래* 이자 *목자 다윗의 노래*. Scene 1 은 *왕이 되기 전* 의 다윗 — *시인 정체성* 의 토대.
- **disputed**: 시 23편의 저작권 — 다윗 단독 vs 후대 편집. 본 Scene 은 *전통적 다윗 저작* 입장 채택 (보수 개신교 톤) 하되 *학문적 이견 존재* 는 disputed_points 에 기록.

## 2. Scene 2 — 형들의 진영 방문 (1분)

### 2.1 배경·환경

- **공간**: 엘라 골짜기의 이스라엘 진영. 막사 12 개가 둥글게 배치. 멀리 *블레셋 군대* 가 *반대편 능선* 에 보임 — 안개 처리로 디테일 최소화.
- **사용자 위치**: 진영 한가운데. 정면 2.5m 앞에 큰 형 *엘리압* 이 칼을 닦으며 사용자를 바라봄. 양 옆에 작은 형 둘 (아비나답·삼마) — 묵묵.
- **사운드**: *낮은 군대 웅성거림* + 멀리서 골리앗의 *희미한 외침* (베이스 톤, 단어는 안 들림). 사울 군대 *전체가 위축된* 분위기 — 무기 정비 소리도 *느리고 무겁게*.
- **에셋**: 13MB. NPC 18명 (병사 LOD 3단계).

### 2.4 안전·신학 footer

- **R3 회복 압박 회피**: *모든 선택지가 정당*. *"B 침묵을 골랐다 = 비겁"* 같은 자동 해석 차단. *"침묵도 다윗의 자리에 있는 한 종류의 지혜"* 톤.
- **R2 트리거**: Scene 2 의 *가족 모욕* 이 *현실 형제 비교 트라우마* 사용자에게 자극될 수 있음. 진입 *2초 뒤* 우상단에 *"건너뛰기"* 버튼 표시 (3초 페이드인).
- **참고 서지 (내적 단련 근거)** — Self-Compassion in Comparison (Neff): 엘리압의 비웃음은 *형제 위계 안의 가장 어린 자* 의 원형. *"엘리압이 틀렸다"* 가 아니라 *"엘리압의 말은 다윗을 멈추지 못했다"* — 가족 안의 자기 인정 reframing. *치료 메커니즘이 아닌 내적 단련 근거 서지 격하 인용*.

## 3. Scene 3 — 골리앗과 마주함 (1분 30초)

### 3.1 배경·환경

- **공간**: 진영 *최전선*. 사용자 정면 *15m 거리* 에 *골리앗* 이 능선 위에 서 있음. 약 *3m 높이* — 사용자 시점에서 *올려다봐야 함*.
- **시각화 정책**: 골리앗은 *얼굴 디테일 최소화* (실사풍이면 트라우마 자극 우려). *약간의 추상화 + 갑옷 디테일* 강조. 거리감 유지 (zoom 없음).
- **사운드**: 골리앗의 *위협적 외침* 3D 오디오 (정면 좌측 + 거리 15m 시뮬레이션). 사울 군대의 *침묵* 이 배경 — *40일째 반복된 도전* 의 무게.
- **에셋**: 16MB. 골리앗 단일 NPC + 사울 군대 80명 (멀리 있는 imposter).

### 4.2 5 돌 ↔ 5 감정 매핑 (핵심 인터랙션)

### 4.3 XR 인터랙션

1. **돌을 손으로 만진다** — 사용자가 *각 돌을 손으로 잡으면* 그 돌의 *감정 한 줄* 이 *돌 위* 에 fade-in (0.5초). 햅틱 차이로 *몸이 먼저 인지*.

2. **5 개를 골라 주머니에 넣는다** — 사용자 허리에 *주머니 socket* 이 노출. 잡은 돌을 *주머니로 가져가면 흡착* (Pocket Socket).

3. **선택 순서 기록** — 어느 감정을 *첫 번째* 로 골랐는지, 어느 감정을 *마지막* 으로 골랐는지가 `interaction_meta.stone_selection_order` 로 기록.

4. **5 개를 모두 넣지 않으면 진행 안 됨** — 단, *"어떤 감정도 버릴 수 없다"* 의 의식으로. *"5 종류 다" 가 아니라* *"5 개 다"* — 사용자가 같은 색을 2개 골라도 됨. (현실: 감정 다양성은 사용자 선택).

5. **돌 1개를 *내려놓고 다시 고르는* 행위 가능** — *번복은 자유*. *결정의 무게* 가 *압박* 으로 변하지 않게.

### 4.4 결정 기록

```json
{
  "scene_number": 4,
  "scene_name": "five_stones",
  "decision": {
    "stones": ["fear", "loneliness", "anger", "hope", "sadness"],
    "stone_order": ["fear", "loneliness", "anger", "hope", "sadness"],
    "color_distribution": {"red": 1, "blue": 1, "gray": 1, "yellow": 1, "black": 1}
  },
  "interaction_meta": {
    "hesitation_seconds": 22.4,
    "stone_pickup_count": 11,
    "stone_replace_count": 6
  }

```

→ `stone_order` 의 *첫 돌* 과 *마지막 돌* 이 사용자 정서의 강한 신호. *첫 돌 = 가장 의식되는 감정 / 마지막 돌 = 가장 인정하기 어려웠던 감정* 패턴.

### 4.5 안전·신학 footer

- **참고 서지 (내적 단련 근거) — Affect Labeling (Lieberman 2007)**: *돌에 감정 이름을 붙이는 행위* 가 *내적 단련의 한 형식* 임을 뒷받침하는 서지. *치료 메커니즘 주장 아님 — storyteller 입장의 격하 인용*. *"감정을 부르는 것이 감정을 다스리는 시작"* 이라는 누구나의 보편 통찰.
- **신학 — 마음을 지키라 (잠 4:23, TRACK-A-6 연결)**: 5 감정을 *주머니에 넣는다* = *경계 형성* 의 의식. *모든 감정이 다윗 안에 있되 그것은 *주머니에 담긴* 상태* — *감정에 휘둘림 vs 감정을 가짐* 의 분별.
- **R3 회복 압박 회피**: *"두려움 돌을 *반드시* 골라야 합니다"* 같은 강제 어휘 차단. *"두려움이 너의 감정이라면 가지고 가라. 아니라면 다른 돌을 골라도 좋다"*.
- **disputed**: *5 라는 숫자* 의 의미 — *완전수* 해석 vs *단순 실용적 비축* 해석. 본 Scene 은 *후자 (실용)* 톤이 기본 — *과도한 상징주의* 차단.

- **disputed**: *밧세바 사건 후 시 51 회개* 본문은 **MVP 범위 밖** (Phase 2 로 이월, MVP-DAVID.md 와 일관). 본 Scene 은 *17장 골리앗 사건* 만 다룸 — *영웅 다윗 / 죄인 다윗* 두 측면 중 *전자만* 명시 (디스클레이머).

## 10. 안전 게이트 — 실 동작 예

> *본 절은 임상 위기 개입이 아닌 **storyteller 의 안전 매너** 다. AI 는 *치료자/자살예방 전문가* 가 아니라 *이야기 안내자*. 위기 영역은 *외부 자원 (109 등)* 으로 즉시 연결.*

### 10.1 R1 시뮬레이션 — 사용자 발화에 자해 키워드

Scene 4 의 *돌 선택* 단계에서 사용자가 *음성 입력* 으로 *"나는 너무 작아"* + *"내가 사라지면 아무도 모를 거야"* 같은 발화 (음성 입력 기능 있을 경우):

1. SafetyController.detectSelfHarmRisk 통과 → severity = HIGH (*"내가 사라지면"* 의미 매칭)
2. *현재 Scene 즉시 일시정지* (fade-to-black)
3. 위기 자원 카드 노출:
   > *"잠시 멈추겠습니다.*
   > *지금 힘드시면 함께할 자원이 있어요.*
   > *[109 자살예방상담 — 24시간] [지금 닫고 메인으로]"*
4. 사용자가 *"메인으로"* 누르거나 30초 대기 → 미션 종료, 메인 화면 복귀. `game_sessions.abandoned_at` 기록.
5. `safety_alerts` row 생성 (severity=high, source=game, raw_excerpt_hash 만 — 원문 미저장, category='suicidal_ideation_semantic').
6. *"내가 너무 작아"* 단독은 severity=medium → 위기 자원 카드 *동반 노출* 하되 흐름 차단 없이 Scene 4 계속. *"이 게임은 *작은 자* 를 위한 이야기입니다"* 한 줄 reframing 추가.

### 10.2 R3 시뮬레이션 — Scene 5 던지기 실패 반복

사용자가 *sling 회전을 5회 이상 실패* (회전 너무 약함 / 던지기 빗나감):

- *실패 카운트 노출 안 함*. 단순 *"다시 한 번 돌려보세요"* 안내 (압박 X)
- 5회 실패 후 *옵션 카드*: *"손으로 *부드럽게 놓아도* 골리앗에 닿게 도와드릴까요? [예 / 계속 시도]"*
- *결과* 가 *능력 시험* 이 아닌 *의식* 임을 명문화

### 10.3 R4 시뮬레이션 — Scene 3 골리앗 트리거

Scene 3 진입 직전에 동의 카드 (§3.2). 사용자 *옵션*:
- *off* — 골리앗 음성 *자막만 표시*, 오디오 mute
- *약* — 음성 볼륨 -40%, reverb 제거
- *강 (기본)* — 정상 강도
- *건너뛰기* — Scene 4 (시냇가) 로 직행, Scene 5 도 *내레이션 요약* 으로 압축

### 10.4 R5 시뮬레이션 — AI 응답 OFF 사용자

`users.allow_ai_response = false` 경우:
- Scene 2 의 다윗 내면 한 줄 → *사전 큐레이션된 시편 구절* 로 대체 (시 27:14 *"너는 여호와를 바랄지어다"*)
- Scene 5 의 다윗 첫 돌 독백 → *삼상 17:45 본문 한 줄만* 노출
- Scene 6 회복 문구 → *faith_tone × 진입 감정* 조합만 (첫 돌 분기 제거)
