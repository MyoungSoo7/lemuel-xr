## 0. 왜 에스더가 이 작품에 필요한가 — 침묵도 정당하다는 위로

요셉이 _결정의 무게_, 모세가 _순종의 떨림_, 다윗이 _작음을 인정한 능동_, 엘리야가 _무너짐을 허락받는 수용_ 이었다면, 에스더는 **말하지 않아도 되는 자유와 말할 자유가 동시에 정당한 자의 이야기**다.

기존 인물들의 구원 서사는 대개 _결단의 순간이 곧 해방_ 이라는 곡선을 공유한다. 그러나 현대인이 매일 마주하는 갈등은 종종 _말할 것인가 말 것인가_ 라는, **정답이 없는 채로 반복되는 저울질**이다. 진단명을, 성정체성을, 이주 신분을, 신앙을, 가족사를 — 언제, 누구에게, 어디까지 말할 것인가. 에스더는 성경에서 이 저울질을 인물의 실제 결정 과정으로 가장 상세히 그리는 인물이다.

에스더는:

- _자기 민족과 종족을 말하지 아니한_ 자 — 모르드개의 명령에 따른 은폐가 서사의 출발점 (에 2:10)
- 그 침묵의 대상이 된 민족 전체가 *말살 조서*의 표적이 되는 것을 지켜본 자 (에 3:13)
- _"홀로 목숨을 건지리라 생각하지 말라"_ 는 다급한 압박을 받은 자 (에 4:13)
- 그러나 그 압박 안에서도 _"침묵해도 구원은 다른 데로 온다"_ 는 절반의 말을 함께 들은 자 (에 4:14)
- _"죽으면 죽으리이다"_ 라는 결단의 말과 함께, **혼자가 아니라 공동체의 사흘 금식**을 먼저 요청한 자 (에 4:16)
- 왕에게 **한 번에 말하지 않고, 두 번을 미루고 세 번째에야** 말한 자 (에 5:3→5:6→7:2)

이 결의 사용자에게 주는 가치:

| 사용자 상태                                  | 에스더 서사가 제공하는 것                                                                     |
| -------------------------------------------- | --------------------------------------------------------------------------------------------- |
| _"이걸 말해야 할지 계속 저울질만 하고 있어"_ | 삼십 일을 부름 없이 지낸 에스더 — 저울질의 시간은 실패가 아니다                               |
| _"말하면 잃을 게 너무 많아"_                 | "다른 데로 말미암아 놓임과 구원을 얻으려니와" — 침묵을 선택해도 구원은 온다는 본문 자체의 말  |
| _"나 혼자 감당해야 할 것 같아"_              | 왕에게 나아가기 전, **먼저 공동체의 금식을 요청한** 에스더 (4:16)                             |
| _"한 번에 못 미치겠어, 자꾸 미루게 돼"_      | 왕의 세 번의 물음에 두 번을 미룬 뒤 세 번째에야 말한 구조 자체 (5:3→5:6→7:2)                  |
| _"말한다고 뭐가 달라질지도 몰라"_            | 금 규가 내밀어질지 아무도 몰랐던 안 뜰의 정적 (5:2) — 결과를 보장받지 못한 채로도 나아가는 것 |
| _"용기 내라는 말이 제일 부담스러워"_         | 이 미션은 어디에도 "용기를 내라"고 말하지 않는다 — 그것이 이 미션의 R3 축이다                 |

→ 에스더 미션의 핵심은 _"결국 말해야 한다"_ 가 아니라 **"말하지 않아도, 준비해도, 말해도 — 어느 쪽도 이 이야기 안에서 정당하다"** 다. 이것이 기존 인물들과 구별되는 _6번째 구원 카테고리(정체 개시의 위험 부담)_ 의 정체성.

## 1. 게임 컨셉 — _"누가 알겠느냐"_

정답이 없는 저울질 앞에 선 왕후가, *침묵도 준비도 개시도 전부 정당하다*는 것을 몸으로 통과하는 6분의 XR 묵상.

### 핵심 메시지

> _"말하지 않아도, 먼저 곁을 만들어도, 오늘 말해도 — 무엇을 택하든 당신은 이 이야기 안에서 정당하다."_
> — 에스더가 사용자 안에 남기는 한 문장

### 미션 구조 (5~7분, 5 Scene · 360초)

```
Scene 1: 이름 없는 민족 (60초, R4 동의 게이트 ★)
   ↓ [감정: 은폐 위에 조서가 내려앉는 두려움]  ← 집단 학살 조서(3:13)는 동의 시에만
Scene 2: 성문 밖의 통곡 (75초)
   ↓ [감정: 공동체적 애통 — 남의 고통은 선택지가 아니다]
Scene 3: 법과 삼십 일 (90초, XR 핵심 ★ 유일한 분기)
   ↓ [감정: 갈림 — disclose_label 3 카드, 결말 품질 차등 없음]
Scene 4: 사흘 (45초, R1 민감 ★)
   ↓ [감정: 결단 — "죽으면 죽으리이다"는 목격이지 모방 촉구가 아니다]
Scene 5: 안 뜰 → 금 규 → 세 번의 물음 → 청원 (90초, 최종)
   [감정: 단계적 개시 — 두 번의 미룸도 실패가 아니다]
```

→ _은폐-위협의 자각-공동체적 애통-갈림-단계적 개시_ 의 곡선. **개시(Scene 5)는 단 한 번의 도약이 아니라 세 번의 물음과 두 번의 미룸을 거친 뒤에야 온다** — 이 구조 자체가 "즉시 용기를 내라"는 압박을 서사적으로 반박한다.

## 2. Scene 별 디테일

> 아래는 이미 작성된 `content/esther/scene1.yml` ~ `scene5.yml` 의 요약이다. 전문은 각 파일을 정본으로 한다.

### Scene 1 — 이름 없는 민족 (감정 anchor: 은폐 위에 조서가 내려앉는 두려움) ★ R4 Pre-Scene 0 동의 게이트 (60초)

배경: 수산 궁 알현실. 냉정한 관료적 대낮. 하만이 사용자에게서 먼 거리(등·측면)에 서서 서류를 읽는다.

**XR 인터랙션**: `ix_s1_witness_only` — 조작 없는 청취/목격. 이 Scene 의 유일한 인터랙션은 *듣는 것*이다.

**내레이션 순서** — 2:10(은폐, "말하지 아니하니") → 3:8(하만의 고발, 전문 인용 — 생략 금지) → [동의 시에만] 3:9(뇌물) → 3:13(집단 학살 조서 전문). *"내가 숨긴 그것이 지금 고발당하고 있다"*는 감정을 2:10→3:8 순서로 성립시킨다.

**R4 동의 게이트 (Pre-Scene 0)**: 진입 직전 `esther_scene1_edict_warning` 카드가 조서 본문 노출(어린이·여인 포함)을 사전 고지하고, [계속한다]/[건너뛰기] 선택을 받는다. 건너뛰는 사용자는 같은 파일 안의 대체 라우트 `s1_alt_summary`(40초, 3:13 요약 자막 1장으로 대체)로 진행한다 — 6번째 파일을 만들지 않는다.

**LLM 호출**: 0회 (전부 본문 + 사전 캐시).

### Scene 2 — 성문 밖의 통곡 (감정 anchor: 공동체적 애통) (75초)

배경: 궁 안 창가에서 성문 밖을 내려다보는 구도 — 사용자(에스더)와 모르드개 사이에 명확한 공간적 단절. 재에 누운 군중은 원경 실루엣 다수로만, 얼굴 클로즈업 금지.

**내레이션 순서** — 4:1(모르드개의 애통) → 4:3(성 전체의 애통) → 4:8(하닥이 조서 초본을 전달) → 사용자 1인칭 목격("성문 밖의 통곡이 여기까지 들려온다. 나는 그 소리를 듣는다").

**XR 인터랙션**: `ix_s2_unroll_edict_replica` — 조서 초본 복제물을 두 손으로 펼치는 선택적 물체 조작. 문서 면은 읽히지 않는 문자 텍스처만 — **3:13 전문은 여기서 다시 렌더하지 않는다**(그 절은 Scene 1 전용, R4 동의 카드가 고지한 범위를 넘지 않기 위함).

**설계 의도**: 이 Scene 에는 분기가 없다 — _남의 고통은 선택지가 아니다._ 결단은 Scene 3·4의 몫이며, Scene 2 는 목격으로 끝난다.

**LLM 호출**: 0회.

### Scene 3 — 법과 삼십 일 (감정 anchor: 갈림) ★ XR 핵심 · 유일한 사용자 분기 (90초)

배경: 궁 안 조용한 방. 하닥을 통한 전언으로 4:11-14 가 전달된다 — 모르드개를 사용자 정면에 세우지 않는다(화자이지 도덕적 권위가 아님).

**내레이션 순서** — 4:11(에스더의 위험 축소 없는 회답) → 4:13(모르드개의 다급함, "홀로 목숨을 건지리라 생각하지 말라") → 4:14(핵심 절 — "다른 데로 말미암아 놓임과 구원을 얻으려니와... 네가 왕후의 자리를 얻은 것이 이 때를 위함이 아닌지 **누가 알겠느냐**").

**분기 — `disclose_label`**: 62초 시점, `pre_branch_notice_ko`("세 장은 나란히 있습니다. 순서도 단계도 아니고, 더 나아간 카드가 없습니다")를 먼저 제시한 뒤 카드 3장:

| 카드               | disclose_label  | 정적 응답                                              |
| ------------------ | --------------- | ------------------------------------------------------ |
| 말하지 않기로 한다 | `nondisclosure` | "말하지 않기로 하셨군요. 그 선택은 그대로 괜찮습니다." |
| 먼저 곁을 만든다   | `gather_first`  | "먼저 곁에 있을 사람을 떠올리셨군요."                  |
| 지금 말하기로 한다 | `speak_now`     | "말하기로 하셨군요. 속도는 당신이 정합니다."           |

카드 순서는 `card_order_policy: shuffle_per_session`(세션마다 랜덤), 렌더는 `card_render_style: flat_siblings`(1/2/3 번호 매김·단계 표시 UI 금지) — 세 카드가 "개시를 향한 진행 막대"로 읽히는 것을 원천 차단한다.

**LLM 호출**: 기본 0회 — `default_path: static_curation`, `llm_optin_only: true`(R5). opt-in 시에만 `POST /api/game/esther/decision`.

### Scene 4 — 사흘 (감정 anchor: 결단, 그러나 혼자가 아닌) ★ R1 민감 Scene (45초)

배경: 수산 궁 사적 처소, 낮은 조명, 금식의 어스름.

**내레이션**: 4:16 전문 — _"죽으면 죽으리이다"_ 는 이 미션에서 자해 위험에 가장 근접한 문장이다. **인용 자막 + 절제된 낭독으로만** 노출하고, 사용자 1인칭 대사로 재생성하지 않는다. 직후 "사흘이 지나갔다"는 짧은 내레이션 — 금식의 사흘은 성취·게임 목표가 아니다(타이머·진행 바·완료 뱃지 금지).

**XR 인터랙션**: `ix_s4_witness_fasting` — `auto_proceed`, 선택지 없음. 사용자는 사흘을 지켜볼 뿐이다.

**안전 설계**: `dwell_limit_on_death_resolve`(4:16 자막 직후 최대 3초 → 자동 전환, `fade_to_gentle_light`로 — 암전으로 끝내지 않는다). 모르드개는 이 Scene 에서 무언(無言) — 등장·발화 모두 없음.

**LLM 호출**: 0회.

### Scene 5 — 안 뜰 → 금 규 → 세 번의 물음 → 청원 (감정 anchor: 단계적 개시) ★ 최종 Scene (90초)

배경: 궁 안뜰에서 어전으로. 시간 경과에 따라 조명이 낮과 잔치의 따뜻함으로 전환.

**내레이션 순서(정밀 타이밍)** — 5:1(안 뜰 진입) → 5:2(금 규, 이 정적은 `dwell_limit_exempt` — 사용자가 통제하는 시간) → 5:3(왕의 1차 물음) → 5:4(에스더의 1차 미룸: 잔치 초대) → 5:6(왕의 2차 물음 — **5:3 과 같은 화면 위치에 반복 렌더**해 "같은 질문이 또 왔다"를 시각화) → 5:8(에스더의 2차 미룸) → 2초 암전(하룻밤 경과) → 7:2(왕의 3차 물음) → 7:3-4(**개시** — 여기서 처음으로 "내 민족"이 발화된다) → 7:6(하만 지목 — 하만은 미등장, 자막만) → 8:6(마무리 인용).

**XR 인터랙션**: `ix_s5_enter_inner_court` — 문지방을 넘는 비버튼 전진 이동, `reversible_no_failure`(몇 번을 물러나도 실패로 기록하지 않는다).

**라우팅(사용자 선택 아님)** — `br_s5_closing_message`, `triggered_by_event: [scene_enter]`, `decision_key: disclose_label`. Scene 3 에서 정한 `disclose_label`(nondisclosure/gather_first/speak_now/null 폴백) × `faith_tone`(strong/balanced/soft) 조합의 **정적 큐레이션 마무리 문구**로 자동 전환된다 — 실질 9(+1) 패턴. 전문은 `scene5.yml`. **"당신은 지금 안전한 자리에 있고" 류 사용자 상태 단정 문장은 전 Scene 금지** — 상태가 아니라 선택만 인정한다.

**바로 뒤 이어지는 것**: 하만 처형(7:7-10)·6장 굴욕 반전·반격 조서(8:7-17)·9장 부림절 보복은 이 Scene 어디에도 등장하지 않는다 — 개시의 축은 7:3-6 에서 완결되고, 처형·보복은 그 축 밖의 보상 서사이기 때문이다.

**LLM 호출**: 기본 0회(R5, `default_path: static_curation`). 트랙 A 브리지("이 시간을 기록하시겠어요?" → 시편 27편, 서지 미확보 — 인간 검토 대상)는 opt-in.

## 10. 작가 노트 (작품 의도)

에스더 서사를 _"용기를 낸 여인이 결국 다 말해서 민족을 구했다"_ 로 만들면 사용자는 _"나도 결국은 말해야 해"_ 라는 **개시 압박의 재생산**으로 끝난다. 그래서 에스더는 _결단의 영웅_ 이 아니라 **저울질이 정당한 자**로 설계했다. <!-- lint_forbidden_tokens 인용 -->

핵심 장면 — 에스더 4:14 의 절반. "네가 왕후의 자리를 얻은 것이 이 때를 위함이 아닌지 누가 알겠느냐"는 자주 소명의 확언으로 읽히지만, 그 앞 문장은 스스로를 방어한다 — "네가 만일 잠잠하여 말이 없으면 유다인은 **다른 데로 말미암아 놓임과 구원을 얻으려니와**." 침묵을 선택해도 구원은 다른 데로 온다는 이 절반을 지우면, 4:14 는 "너 아니면 안 된다"는 압박으로 미끄러진다. 이 미션은 그 절반을 `mandatory_clause`로 Scene 3 narration_blocks 에 고정했다 — 생략하면 반려다. <!-- lint_forbidden_tokens 인용 -->

Scene 5 의 _세 번의 물음_ 도 극적인 반전이 아니다. 에스더는 두 번을 미룬다. 사용자는 왕의 같은 관용구가 **같은 화면 위치에 두 번 반복**되는 것을 본다. 저울질은 반복돼도 실패가 아니다. _"드디어"_·_"마침내"_·_"용기를 내어"_ — 이 미션은 이 어휘들을 71종 금지 토큰 목록(seed §7-0-1, §12.8 감사 반영)에 넣어 기계적으로도 차단했다.

사용자는 게임 후 *"어느 카드를 골랐어도 정당했다"*를 기억해야 한다. 이것이 에스더 미션의 마지막 위로다 — 그리고 R3(개시 압박 금지)의 신학적 뿌리다.

## 12. 영성·감성·이성 3차원 진입 + 정신건강 효과

### 12.1 에스더 서사를 3차원으로 풀면

| 차원     | 에스더 서사의 핵심                                                                        | 사용자에게 활성화되는 인지                                     |
| -------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **영성** | 하나님이 이름으로 등장하지 않는 책(DP1) — _감춰진 임재_, "다른 데로 말미암아"의 열린 물음 | 확언 없는 신뢰 — _증명되지 않아도 정당한_ 믿음의 형태          |
| **감성** | 저울질·미룸·공동체적 애통 — 어느 감정도 재판받지 않음                                     | 선택의 존중 — *결과가 아니라 과정 자체가 정당화*되는 정서 경험 |
| **이성** | 단계적 개시의 구조(세 번의 물음, 두 번의 미룸) — 즉시성이 아니라 순서                     | 메타인지 — _위험 판단의 자기 결정권_ 재구성                    |

### 12.3 정신건강 효과 (근거 기반 — 최소 3 메커니즘)

> ⚠️ 아래는 _임상 처방·진단이 아니라_ 서사·표현의 _내적 단련 근거 서지_(THEOLOGY-REFERENCES 정책 §0). _치료 메커니즘 주장 아님 — storyteller 격하 인용._ 아래 3건 모두 **본 세션에서 PMID/KCI 원문을 직접 확인하지 않았다** — 인접 서지 후보로만 제시, 인간 검토자의 드릴다운이 필요하다.

#### A. **ACT — 수용전념치료(Hayes)** — 불확실성 속의 가치 기반 행동

Scene 3 의 세 카드는 "결과를 확신할 수 없어도 선택은 가능하다"는 ACT 의 _심리적 유연성_ 구조와 상응한다. 금 규가 내밀어질지 아무도 몰랐던 5:2 의 정적은, 결과를 통제할 수 없는 채로도 자신이 정한 가치(가족·공동체·신념)를 향해 나아가는 _committed action_ 의 서사화다.

- 효과: 회피-접근 갈등에서의 경직성 완화, 불확실성 인내력 ↑
- 우리 앱: 3 카드 어디에도 "결과가 좋을 것"이라는 보장을 걸지 않음 — 선택 자체가 가치 행동

#### B. **Compassion Cultivation Training (CCT, Stanford)** — 자기 자비와 속도의 존중

"먼저 곁에 있을 사람을 떠올리셨군요" 라는 `gather_first` 응답과, 4:16 의 공동체적 금식 요청은 *혼자 감당하지 않아도 된다*는 자기 자비의 서사화다. 미룸을 실패로 규정하지 않는 R3 설계는 CCT 의 _자기 비난 완화_ 축과 같은 방향이다.

- 효과: 자기 비판적 반추 완화, 도움 요청 행동에 대한 수치감 완화
- 우리 앱: Scene 5 마무리 문구 어디에도 "더 빨리 말했어야 했다"는 문장이 없음

#### C. **Self-Transcendence(Frankl/Reed)** — 고립된 결정에서 공동체적 의미로

Scene 2 의 공동체적 애통과 Scene 4 의 "나도 나의 시녀와 더불어 이렇게 금식한 후에"는, 혼자 짊어지는 결정에서 *자기 밖의 연결*로의 재구성이다. 결정이 고립을 요구하지 않는다는 것 자체가 위로다.

- 효과: 고립감 완화, 결정의 부담이 관계 속에서 재분배되는 인지적 재구성
- 우리 앱: 3 카드 중 `gather_first` 가 별도 존재 — "곁을 만드는 것"도 하나의 정당한 경로

### 12.5 사용자 진입 모드 UX

```
┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│  영성       │ │  감성       │ │  이성       │
│             │ │             │ │             │
│ *감춰진*    │ │ *어느 선택도*│ │ *단계적*    │
│ *임재를*    │ │ *재판받지*  │ │ *구조로*    │
│ *신뢰하며*  │ │ *않도록*    │ │ *다시 짜며* │
└─────────────┘ └─────────────┘ └─────────────┘
        또는: ⚙ AI 자동 (이전 패턴 기반)
```

같은 미션, 3 가지 내레이션 톤 + Scene 강조점 변화. `faith_tone`(strong/balanced/soft) 3단은 이 UX 진입 모드와 연동 후보이나, 정확한 매핑(예: "영성" 진입=strong)은 **아직 확정되지 않았다** — 인간 검토 대상.

> ⚠️ 위 3건 및 §12.3 근거를 `docs/THEOLOGY-REFERENCES.md`에 옮기는 작업은 **이번 산출물 범위 밖**이다(COMMON §11 이 허용하는 5개 파일 밖은 건드리지 않음). 인간 저자가 새 §를 추가할 때 엘리야 §5 형식(`### N.1 핵심 서지 (출처 확정 — 본문 fetch 미완)` + `#### [ES1]…[ES3]`)을 그대로 따를 것을 권고한다.

### 12.8 lint_forbidden_tokens — 71종 (참고용 사본, 정본은 scene3.yml·scene5.yml)

R2/R3 게이트 중 실제로 토큰 블록을 가진 3곳(Scene 3 의 `R2_calling_not_asserted_from_4_14`·`R3_disclosure_is_not_the_right_answer`, Scene 5 의 `R3_no_courage_pressure_in_endings`)에 동일하게 적용되는 71종:

>
> 1. **어간형 5축이 부정형 위로를 삼키고 있었다** — 한국어 부정은 어간 _뒤_ 에 `-지 않`으로 붙으므로 `용기를 내`·`두려움을 넘`·`입을 여/열`·`타협 없이 지` 는 이 미션이 하려는 말("용기를 내지 않아도 됩니다", "입을 열지 않아도 됩니다")을 그대로 차단했다. 당위·명령 어미를 한 음절 이상 붙여 가해형만 남겼다.
> 2. **문맥 없는 짧은 조각 4축이 전역에서 오검출했다** — `언젠가`·`결국은`·`이 고난은`·`데는 이유가` 는 다른 인물 미션의 정상 위로("지치는 데는 이유가 있습니다")까지 잡았다. 축(유예된 개시 압박·목적론적 의미부여)을 지키는 긴 표층형으로 교체했다.
