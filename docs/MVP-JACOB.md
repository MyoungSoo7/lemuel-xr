# MVP — 야곱 XR 미션 상세 설계 (내가 가해자인 관계의 회복 중심)

> **담당**: [@MyoungSoo7](https://github.com/MyoungSoo7)
> **단계**: Phase 2+ (요셉 → 모세 → 다윗 → 엘리야 → 솔로몬 → **야곱**, PLAN.md Track B Theme 18)
> **구원 카테고리**: **내가 가해자인 관계의 회복** — 기존 유형(요셉=경제 / 모세=정치 / 다윗=외세 / 엘리야=정서적 소진 회복 / 예수=영적)에 없는 신규 카테고리. **피해자 서사가 아니라 상처를 준 쪽에 선 사람**의 회복. 절연·가족 불화·오래된 채무감을 가진 사용자가 대상.
> **축 배타 할당** — 이 미션의 축은 _"내가 준 상처 앞에 다시 서는 것"_(용서를 받는 쪽이 아니라 비는 쪽)이다. "이미 저지른 뒤의 자기정죄에서 회복"은 **베드로(14)** 의 축(하나님과의 관계 회복)이고, "지연된 약속"은 **아브라함(17)** 의 축이다 — 20년을 _기다림_ 서사로 쓰지 않는다.
> **핵심 감정 anchor**: _가해의 자리에서 시작 → 상대의 고통을 목격함(개입 불가) → 두려움을 숨기지 않는 기도 → 씨름과 이름 대면(정체성) → 대면·비대칭 회복(도착 지점과 무관하게 완결)_
> **성경 본문**: 창세기 27장(부분) · 32장(부분) · 33장(부분)

> ⚠️ **초안 성격 고지** — 이 문서는 ouroboros interview 도구 대체로 **수기(手記) 크리스탈라이즈된 seed(seed-JACOB v5-b, 독립 채점 완료본) 기반**의 ≤70% 초안이다. 최종 확정 전 **`lemuel-theology-reviewer`(신학 톤) + `lemuel-mental-health-safety`(정신건강 안전선) 에이전트의 사후 검토**가 반드시 필요하다. 이 미션은 **신규 구원 카테고리 도입 + 가족 내 기만·살해 위협·학대 관계 재회**를 다루므로 **3단 합의 검증 + 인간 안전검토자 사인오프가 특히 필수**다.
>
> ⚠️ **이 미션의 특수 구조 고지** — 사용자는 미션 전체에서 **가해자의 자리**에 선다(피해자가 아니다). 이 사실은 Scene 1 진입 전 R4 동의 카드에서 명시 고지된다. 가족 안에서 **상처를 받은 쪽**에 서 있는 사용자를 위해 5개 Scene 전부에서 상시 이용 가능한 **이탈로(`cc_jacob_not_my_seat`)**를 별도로 둔다 — 이는 "연출을 건너뛰는" 스킵(`1_alt`/`5_alt`)과 다른, "이 자리 자체가 내 자리가 아니다"라는 세 번째 경로다.

## 0. 왜 야곱이 이 작품에 필요한가 — 가해자 자리에서 회복을 말하기

요셉이 _결정의 무게_, 모세가 _순종의 떨림_, 다윗이 _작음을 인정한 능동_, 엘리야가 *무너짐을 허락받는 수용적 안식*이었다면, 야곱은 **자기가 낸 상처 앞에 다시 서는 자**다.

기존 5 인물의 구원 서사는 전부 사용자를 _상처받은 쪽_(또는 부담을 짊어진 쪽)에 세운다. 그러나 현실의 관계 회복 서사 중 상당수는 **내가 먼저 잘못한 쪽**에서 시작한다 — 속인 형제, 등 돌린 자녀, 연락을 끊은 친구. 이 자리를 다루는 인물이 지금까지 lemuel-xr Track B에 없었다.

야곱은:

- _아버지를 속이고 형의 축복을 가로챈_ 자다 (창 27:19, 27:35)
- 그 직후 _속은 형의 절규와 살해 의도를 그대로 목격한_ 자다 (창 27:34, 27:41) — 자신이 만든 상처의 실재 규모를 축소하지 않는다
- 20년 뒤 돌아가는 길에서 _두려움을 숨기지 않고 기도한_ 자다 (창 32:9-11)
- 얍복 나루에서 _홀로 남아 씨름하며 자기 이름을 정직하게 답한_ 자다 (창 32:24-27)
- 형 앞에서 _예물을 내밀었다가 거절당하고, 다시 청하는_ 자다 (창 33:9-11) — 화해는 깔끔하게 오지 않는다

이 감정의 결이 사용자에게 주는 가치:

| 사용자 상태                                               | 야곱 서사가 제공하는 것                                                  |
| --------------------------------------------------------- | ------------------------------------------------------------------------ |
| _"그 사람에게 준 상처가 아직도 마음에 걸려"_              | 속인 자리에서 시작하는 Scene 1~2 — 회피 없이 상처의 크기를 그대로 마주함 |
| _"연락을 끊었는데, 이게 맞는 건지 모르겠어"_              | `stay_and_pray` — 가지 않는 것도 정당한 결정으로 처리(§5-2-a)            |
| _"먼저 다가가고 싶은데 두려워"_                           | 32:11 "겁이 나기 때문이니이다" — 두려운 채로 가는 것도 정당              |
| _"내가 누구인지부터 다시 마주해야 할 것 같아"_            | 32:27 "네 이름이 무엇이냐" — 정체성 대면이 화해보다 먼저                 |
| _"화해했는데도 뭔가 남아 있어"_                           | 32:31 절뚝임 — 회복은 원상복구가 아니다. 남은 것은 남은 것이다           |
| _"용서를 강요받는 것 같아 부담스러워"_ (피해자 쪽 사용자) | `cc_jacob_not_my_seat` 이탈로 — 이 미션은 그 자리를 다루지 않는다고 명시 |

→ 야곱 미션의 핵심은 *"화해하라"*가 아니라 **"당신이 준 상처 앞에 다시 서는 것 자체가, 결과와 무관하게 완결된 걸음이다"** 다.

## 1. 게임 컨셉 — _"다시 내미는 손"_

속인 자리에서 시작해, 상대의 절규를 그대로 목격하고, 20년 뒤 두려운 채로 돌아가 씨름 끝에 자기 이름을 정직히 답한 뒤, 형 앞에서 한 번 거절당한 예물을 다시 내미는 6분의 XR 여정.

### 핵심 메시지

> _"내가 준 상처 앞에 다시 서는 것은, 관계가 회복된다는 보장이 아니다. 그 자체로 이미 완결된 걸음이다."_
> — 야곱이 사용자 안에 남기는 한 문장

### 미션 구조 (약 6분, 5 Scene, 합 360초)

```
Scene 1: 속임 (60초) — 창 27:19, 27:35
   ↓ [감정: 가해의 자리 — 선택 없음, 이미 저지른 자리에서 시작]
Scene 2: 부르짖음 (60초) — 창 27:34, 27:36, 27:41
   ↓ [감정: 목격 — 남의 고통은 선택지가 아니다. 관찰만]   ← R1 인접 가족 학대·살해 위협 맥락
Scene 3: 이십 년 (60초, 유일한 3지 분기: return_label) — 창 32:9-11
   ↓ [감정: 두려움을 숨기지 않는 기도]
Scene 4: 얍복 (90초, XR 핵심 #1: 지속 그립) — 창 32:24-28, 32:30-31
   ↓ [감정: 정체성 대면 — "네 이름이 무엇이냐"]
Scene 5: 받으니라 (90초, XR 핵심 #2: 예물 내밀기 + 자동 라우팅 마무리) — 창 33:1, 33:3-4, 33:8-11
   [감정: 비대칭 회복 — 재회는 선택 이전에 이미 일어난다, 예물은 결과와 무관하게 완결]
```

→ 상승·하강 곡선이 아니라 **"자리 → 목격 → 결단 → 대면 → 완결"**의 선형 곡선. Scene 5의 마무리는 사용자가 어느 경로(완주/스킵/Scene 4 중도 종료/피해자 이탈로)로 오든 **동일한 마무리 문구 세트**에 도달한다(§3.5).

| 경로                          | 재생 절                  | `entry_mode_after` |
| ----------------------------- | ------------------------ | ------------------ |
| `rt_offer_again`(다시 내민다) | 33:10 → 33:11(받으니라)  | `full`             |

**LLM 호출**: 0회(기본 경로) — `default_path: static_curation`, `llm_optin_only: true`. AI 응답은 opt-in 시에만.

## 4. 백엔드 API (기존 인물과 동일 hexagonal 구조 공유)

| Endpoint                              | 설명                                                                                |
| ------------------------------------- | ----------------------------------------------------------------------------------- |
| `POST /api/game/jacob/start`          | 캐릭터='jacob', Scene 1 페이로드 + R4 동의 카드(`cc_jacob_family_deception`) 데이터 |
| `POST /api/game/jacob/scene/3/decide` | `return_label`(`send_ahead`\|`go_afraid`\|`stay_and_pray`\|`null`) 저장             |
| `POST /api/game/jacob/complete`       | Scene 5 진입 시 자동 라우팅 — `return_label` × `faith_tone` → 마무리 문구 10종 중 1 |
| `GET /api/scripture/genesis/{ref}`    | 창세기 27·32·33장(사용 범위 22절만)                                                 |

- Scene 1·2·4는 _decide 엔드포인트 없음_ — 분기가 없다(`branches: []`). `scene_views`에 entered/exited만 기록.
- Scene 5의 예물 인터랙션(`ix_jacob_gift`)은 `records_decision: false` — 별도 엔드포인트 없이 클라이언트 로컬 상태로만 처리, 서버에 남기지 않는다.
- `cc_jacob_not_my_seat` 이탈로는 `records_decision: false` — decisions에 아무것도 남기지 않고 `mission_complete: true`로만 표시(진행률·재시도 유도 없음).

## 5. 데이터 모델

`game_sessions.decisions` JSONB:

```json
{
  "scene3_return_label": "go_afraid",
  "scene4_hold_completed": true,
  "scene4_name_response_given": true,
  "scene4_limp_persistent": true,

```

## 10. 작가 노트 (작품 의도)

야곱 서사를 *"속인 자가 결국 벌 받고 다듬어져 성공한 이야기"*로 만들면, 사용자는 자기 삶의 불행을 자기 죄의 대가로 읽는 인과응보 신앙으로 끝난다. 그래서 라반 밑에서의 20년은 **의도적으로 서사에서 뺐다**(§4-1) — "그 20년이 너를 다듬었다"는 이 미션이 가장 경계하는 문장이다.

핵심 장면은 창 33장의 왕복이다 — 에서는 처음에 사양하고(33:9), 야곱은 물러서지 않고 다시 청하고(33:10), 결국 받는다(33:11). **이 어색함을 매끄럽게 다듬지 않는다.** 화해는 깔끔하게 오지 않는다는 것이 이 미션이 정직하게 남기는 질감이다. 단, "강권하면 받아준다"를 사용자에게 요구되는 방법론으로 프레이밍하지 않는다 — 본문 안에서 일어난 일이지 사용자에게 주는 지시가 아니다.

가장 조심한 지점은 재회(33:4)를 예물 선택보다 **먼저** 배치한 것이다. 재회가 선택의 보상이 되는 순간, 이 미션은 "거절당해도 다시 밀면 받아준다"를 몸으로 훈련시키는 도구가 된다. 재회를 선택 이전에 이미 지나간 사건으로 만들어야만, 물러서는 선택이 손해가 되지 않는다.

`stay_and_pray`를 종결 상태로 명시한 것도 같은 이유다. 가족과 영구히 접촉하지 않기로 **결정한 것이 옳은** 사용자가 이 미션의 명시 대상 중 하나다. 그 사용자에게 "아직"이라는 시제 하나가 결정을 취소하라는 압박이 될 수 있다는 것을, 이 초안은 가장 조용한 형태의 R3 위반으로 다룬다.

### 12.3 정신건강 효과 (근거 기반 — 최소 3 메커니즘)

> ⚠️ 아래는 _임상 처방·진단이 아니라_ 서사·표현의 _내적 단련 근거 서지_(THEOLOGY-REFERENCES 정책). _치료 메커니즘 주장 아님 — storyteller 격하 인용._

#### A. **Self-Transcendence + 의미 추구** (Frankl, Logotherapy)

Scene 5의 예물 재청은 결과(수락 여부)를 통제할 수 없는 상태에서도 자기 밖으로 손을 내미는 행위다. Frankl의 *"내가 삶에 무엇을 할 것인가"*로의 전환이 여기서 일어난다 — 관계 결과에 대한 통제를 내려놓고도 걸음 자체에 의미를 두는 구조.

- 우리 앱: 마무리 문구 10종이 전부 "이것은 야곱에게 있었던 일이며, 당신의 실제 관계에 적용하지 않아도 된다"로 끝나 — 결과가 아니라 걸음 자체를 완결로 남긴다.

#### B. **ACT 수용**(Hayes) — 결과 불확실성 속의 가치 기반 행동

Scene 3의 3지 선택(`send_ahead`/`go_afraid`/`stay_and_pray`)은 전부 "두려움을 없앤 뒤"가 아니라 "두려움을 안은 채" 내리는 결정이다. ACT의 _경험 회피 → 수용 → 가치 기반 행동_ 구조와 일치.

- 우리 앱: 32:11 "겁이 나기 때문이니이다"를 삭제하지 않고 그대로 기도문으로 노출 — 두려움을 없애야 할 조건이 아니라 함께 갈 수 있는 상태로 처리.

#### C. **자기용서/도덕적 회복(moral repair) 관점** — Enright 인접 연구

Enright의 용서 과정모델은 주로 피해자의 용서를 다루지만, 인접 연구는 가해자 쪽의 *자기용서(self-forgiveness)*를 "책임 인정 → 후회 → 배상 시도 → 자기 자비"의 단계로 본다. 야곱의 자리(속임 인정 → 20년 뒤 두려운 기도 → 예물 왕복)는 이 구조와 서사적으로 겹친다.

- 우리 앱: 책임을 흐리지 않으면서도(27:35 "속여" 명시 인용) 자기 정죄로 끝나지 않게 — Scene 4의 절뚝임은 벌이 아니라 "남은 것은 남은 것"으로 처리(§8).

#### D. (보조) **Affect Labeling** (Lieberman 2007)

Scene 3의 32:10-11은 감당할 수 없음과 두려움을 정직하게 이름 붙이는 기도다. 부정 정서를 억누르지 않고 말할 수 있게 하는 것이 정서 조절의 한 축.

- 우리 앱: 어느 선택 카드도 "죄책감을 극복하라"는 방향으로 유도하지 않고, 감정을 있는 그대로 진술하게 한다.
