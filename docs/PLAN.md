# Lemuel Faith — 기독교 기반 감정 회복 + 서사 게임 플랫폼

> **한 줄 컨셉**: 성경의 인물·지혜를 매개로 *감정 회복(passive)* 과 *자기 서사화(active)* 를 양방향 제공하는 AI 기반 영적 웰빙 앱.

---

## 1. 핵심 가치 제안

| 기존 명상 앱 | Lemuel Faith |
|---|---|
| 보편적 마음챙김 (종교 중립) | **성경적 세계관에 뿌리** |
| 정적 콘텐츠 위주 | **정적 + 게임 듀얼 트랙** |
| AI 보조적 사용 | **AI 전방위 활용** (개인화 묵상·서사 분기·대화) |

→ "성경 + AI + 게임" 의 한국 시장 빈자리 점유.

---

## 2. 콘텐츠 아키텍처 — 듀얼 트랙

### 2.1 트랙 A: 정적 회복 (Theme 1~7)

사용자가 *감정을 입력*하면 매칭된 콘텐츠 제공.

| # | 주제 | 사용자 상태 | 콘텐츠 형태 |
|---|---|---|---|
| 1 | 일기와 묵상 | 자기 성찰 욕구 | 일기 작성 + AI 묵상문 |
| 2 | 잠언과 지혜 | 결정 어려움 | 상황별 잠언 + 해석 |
| 3 | 전도서와 인생 | 허무·공허 | 전도서 구절 + 인생관 카드 |
| 4 | 시편과 감정 | 슬픔·분노 | 시편 낭독 + 감정 라벨링 |
| 5 | 고통과 진리 | 실존적 고통 | 욥기·고난서사 + 신학 해설 |
| 6 | 마음을 지키는 것 | 불안·과부하 | 마음 보호 가이드 + 호흡 |
| 7 | 사람을 두려워하지 않는 것 | 대인 공포 | 다윗·다니엘 사례 + 실천 팁 |

### 2.2 트랙 B: 서사 게임 (Theme 8~11)

사용자가 *게임을 원할 때* 인물 서사를 선택지 기반으로 체험.

| # | 인물 | 구원 유형 | 게임 컨셉 |
|---|---|---|---|
| 8 | 요셉 | **경제** | 배신 → 노예 → 통치자. *경제적 위기 극복 RPG* |
| 9 | 모세 | **정치** | 도피 → 광야 → 출애굽. *리더십 결정 게임* |
| 10 | 다윗 | **외세** | 소년 → 도망자 → 왕. *역경 극복 액션* |
| 11 | 예수 | **영적** | 고난 → 십자가 → 부활. *철학적 선택 어드벤처* |

→ 마치 *매슬로 욕구 5단계* 와 유사한 *구원 카테고리화*. 사용자 위기 종류별 맞춤 서사.

### 2.3 분기 흐름

```
사용자 진입
    │
    ▼
감정/의도 입력 ("우울해" / "재밌는 거" / "묵상")
    │
    ├──[감정/위로]──► 트랙 A (1~7 매칭)
    │
    └──[탐색/몰입]──► 트랙 B (8~11 선택)
```

## 3. AI 활용 — 8가지 시나리오

1. **감정 분류** — 사용자 입력 → 1~7 중 추천
2. **개인화 묵상문 생성** — 일기 + 성경 결합한 personal devotional
3. **게임 시나리오 분기** — 8~11 인물 서사의 사용자 선택지 LLM 생성
4. **위로 대화 (챗봇)** — 시편 톤의 공감 응답
5. **TTS 낭독** — 일기·묵상 음성 합성 (출퇴근 듣기)
6. **이미지 생성** — 성경 장면 일러스트 (게임 배경)
7. **주간 리포트** — 감정 변화 + 묵상 키워드 요약
8. **다국어 번역** — 선교 시장 (영/스페인/포르투갈)

## 5. 강점 & 우려

### 5.1 강점

- ✅ **차별화 명확** — 성경 + AI + 게임 조합은 한국 빈자리
- ✅ **듀얼 모드** — 정서 상태에 따른 능동/수동 전환
- ✅ **콘텐츠 IP 무료** — 성경은 Public Domain
- ✅ **AI 자유도** — 종교 콘텐츠는 *해석* 으로 환각 허용도 ↑
- ✅ **타겟 명확** — 기독교 + 정신건강 관심층 (한국 ≈ 500만, 글로벌 25억)

### 5.2 우려 & 대응

| 우려 | 대응 |
|---|---|
| **신학적 검증 리스크** — LLM 환각이 이단 해석 | 교단 자문 + 출력 필터 + *"AI 보조 — 본문은 성경 참조"* 명시 |
| **타겟 협소** — 비신자 진입 장벽 | *"성경 지혜 with AI"* 톤 — 종교색 강도 사용자 선택 |
| **게임화 비판** — 성경을 오락화? | *서사 체험* 으로 포지셔닝. 게임 = 깊은 이해 도구 |
| **유료화 모호** | freemium: 트랙 A 무료, 트랙 B (게임) + AI 무제한 = 월 3,900원 |
| **8~11 인물 선택 균형** | V2 에서 베드로·바울·다니엘 추가 — *시즌제 콘텐츠* |

## 6. 기술 스택

| 영역 | 추천 | 이유 |
|---|---|---|
| Backend | Spring Boot 4 + Kotlin | 기존 익숙, 헥사고날 패턴 재사용 |
| AI Orchestration | LangChain (Python) | RAG (성경 vector DB) + 다중 LLM |
| LLM | OpenAI GPT-4o / Claude Sonnet | 종교 콘텐츠 reasoning 강함 |
| Game Engine | Unity 6 LTS | 2D RPG (요셉·다윗) + 분기 서사 |
| Frontend | React Native | iOS/Android 단일 코드 |
| TTS | ElevenLabs | 한국어 음성 자연스러움 1위 |
| 이미지 | Stable Diffusion XL (self-host) + Midjourney (premium 컷) | 비용 최적화 |
| DB | PostgreSQL (일기·사용자) + Pinecone (성경 임베딩) | RAG 검색 |
| 인증 | OAuth (Google/Kakao) + 익명 모드 | 신앙 노출 부담 완화 |
| 분석 | Mixpanel + 자체 (감정 트렌드) | UX 개선 + 효과성 측정 |

## 7. MVP 로드맵

### V1.0 — Minimum Lovable Product (3개월)

- 트랙 A: 1~5 (일기·잠언·전도서·시편·고통)
- AI 묵상문 생성 + 시편 톤 챗봇
- 무료, 무계정 (익명)
- **검증 목표**: D7 retention 30%, *"내일도 쓰고 싶다"* 정성 응답 70%

### V2.0 — Story Game PoC (+3개월)

- 트랙 B: *요셉* 1편 (RPG 30분 분량)
- TTS (일기 낭독)
- 구독 plan (월 3,900원, 첫 7일 무료)
- **검증 목표**: 게임 완주율 50%, 결제 전환 5%

### V3.0 — Scale (+6개월)

- 모세·다윗·예수 게임 추가
- 영어/스페인어 다국어
- 익명 감정 공유 커뮤니티
- B2B (교회 단체 구독)
