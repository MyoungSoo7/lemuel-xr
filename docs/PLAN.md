# Lemuel Faith — 기독교 기반 감정 회복 + 서사 게임 플랫폼

> **한 줄 컨셉**: 성경의 인물·지혜를 매개로 _감정 회복(passive)_ 과 _자기 서사화(active)_ 를 양방향 제공하는 AI 기반 영적 웰빙 앱.

---

## 1. 핵심 가치 제안

| 기존 명상 앱                | Lemuel Faith                                    |
| --------------------------- | ----------------------------------------------- |
| 보편적 마음챙김 (종교 중립) | **성경적 세계관에 뿌리**                        |
| 정적 콘텐츠 위주            | **정적 + 게임 듀얼 트랙**                       |
| AI 보조적 사용              | **AI 전방위 활용** (개인화 묵상·서사 분기·대화) |

→ "성경 + AI + 게임" 의 한국 시장 빈자리 점유.

## 2. 콘텐츠 아키텍처 — 듀얼 트랙

### 2.1 트랙 A: 정적 회복 (Theme 1~7)

사용자가 *감정을 입력*하면 매칭된 콘텐츠 제공.

| #   | 주제                      | 사용자 상태    | 콘텐츠 형태                |
| --- | ------------------------- | -------------- | -------------------------- |
| 1   | 일기와 묵상               | 자기 성찰 욕구 | 일기 작성 + AI 묵상문      |
| 2   | 잠언과 지혜               | 결정 어려움    | 상황별 잠언 + 해석         |
| 3   | 전도서와 인생             | 허무·공허      | 전도서 구절 + 인생관 카드  |
| 4   | 시편과 감정               | 슬픔·분노      | 시편 낭독 + 감정 라벨링    |
| 5   | 고통과 진리               | 실존적 고통    | 욥기·고난서사 + 신학 해설  |
| 6   | 마음을 지키는 것          | 불안·과부하    | 마음 보호 가이드 + 호흡    |
| 7   | 사람을 두려워하지 않는 것 | 대인 공포      | 다윗·다니엘 사례 + 실천 팁 |

### 2.2 트랙 B: 서사 게임 (Theme 8~18)

사용자가 _게임을 원할 때_ 인물 서사를 선택지 기반으로 체험.

> 📌 **이 표가 축(구원 카테고리) 중복 판정의 정본이다.** 신규 인물은 여기 없는 축이어야 하고,
> 축이 인접하면 서로의 프레이밍 문구를 리터럴로 배제한다(축 배타 할당 — 다니엘↔에스더,
> 베드로→에스더·다니엘, 야곱→베드로·아브라함). 이 표가 낡으면 _낡은 표를 근거로 중복 판정을
> 하게 된다_ — 2026-08-05 에 Theme 14~18 이 5개 MVP 문서에만 있고 여기 없던 상태를 해소했다.

| #   | 인물     | 구원 유형                               | 게임 컨셉                                                                                                                                     |
| --- | -------- | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 8   | 요셉     | **경제**                                | 배신 → 노예 → 통치자. _경제적 위기 극복 RPG_                                                                                                  |
| 9   | 모세     | **정치**                                | 도피 → 광야 → 출애굽. _리더십 결정 게임_                                                                                                      |
| 10  | 다윗     | **외세**                                | 소년 → 도망자 → 왕. _역경 극복 액션_                                                                                                          |
| 11  | 예수     | **영적**                                | 고난 → 십자가 → 부활. _철학적 선택 어드벤처_                                                                                                  |
| 12  | 엘리야   | **정서적 소진(번아웃) 회복**            | 절정 → 무너짐 → 탈진 → 돌봄받음 → 고요 → 다시 걸음. _"로뎀나무 아래"_ — 왕상 18~19장 (MVP-ELIJAH.md)                                          |
| 13  | 솔로몬   | **성공 속 허무(실존적 공허) 재정향**    | 부담 → 수용됨 → 분별 → 허무 → 재정향(안착). _"해 아래, 빈 손"_ — 왕상 3:4-28 · 왕상 10:14-29(요약) · 전 1:2, 2:4~11, 12:13 (MVP-SOLOMON.md) |
| 14  | 베드로   | **실패·수치심 이후의 정체성 재구성**    | 중보 → 부인 → 통곡 → 빈손의 밤 → 숯불 앞의 호명. 눅 22 · 요 18 · 요 21 (MVP-PETER.md)                                                         |
| 15  | 다니엘   | **동화 압력 속 정체성 보전(경계 설정)** | 어디까지 협력하고 어디서 멈추는가. 단 1 · 6 (MVP-DANIEL.md)                                                                                   |
| 16  | 에스더   | **정체 개시(disclosure)의 위험 부담**   | 드러내면 잃고 숨기면 나만 산다 — _결단의 영웅이 아니라 저울질이 정당한 자_. 에 4-5 · 7-8 (MVP-ESTHER.md)                                    |
| 17  | 아브라함 | **지연된 약속·불확실성 인내**           | 부름 → 기다림 → 흔들림 → 재확인. 창 12 · 15 · 17~18 · 21 (MVP-ABRAHAM.md)                                                                     |
| 18  | 야곱     | **내가 가해자인 관계의 회복**           | 피해자 서사가 아니라 *상처를 준 쪽*의 회복. 창 27 · 32~33 (MVP-JACOB.md)                                                                      |

→ Theme 12-18 은 기존 4 유형(경제·정치·외세·영적)에 없는 *5-11번째 구원 카테고리* 다.
트랙 A 대응 — 엘리야: Theme 4·5 (시편·고통, MVP-ELIJAH.md §11) / 솔로몬: Theme 3 (전도서와 인생, MVP-SOLOMON.md §11).

⚠️ **런타임 탑재 현황은 이 표와 다르다.** `backend/.../game/domain/Character.kt` 의 `Character` enum 에
실린 인물은 JOB·ELIJAH·MOSES·DAVID·JOSEPH·JESUS·SOLOMON **7개뿐**이며, Theme 14~18(베드로·다니엘·
에스더·아브라함·야곱)은 `docs/` + `content/` + `scripts/gates/` 만 있고 **플레이할 수 없다.**
표에 행이 있다는 것과 앱에서 돌아간다는 것은 다른 사실이다 — 섞어 보고하지 않는다.

→ 마치 _매슬로 욕구 5단계_ 와 유사한 _구원 카테고리화_. 사용자 위기 종류별 맞춤 서사.

## 3. AI 활용 — 8가지 시나리오

1. **감정 분류** — 사용자 입력 → 1~7 중 추천
2. **개인화 묵상문 생성** — 일기 + 성경 결합한 personal devotional
3. **게임 시나리오 분기** — 8-18 인물 서사의 사용자 선택지 LLM 생성
4. **위로 대화 (챗봇)** — 시편 톤의 공감 응답
5. **TTS 낭독** — 일기·묵상 음성 합성 (출퇴근 듣기)
6. **이미지 생성** — 성경 장면 일러스트 (게임 배경)
7. **주간 리포트** — 감정 변화 + 묵상 키워드 요약
8. **다국어 번역** — 선교 시장 (영/스페인/포르투갈)

## 5. 강점 & 우려

### 5.1 강점

- ✅ **차별화 명확** — 성경 + AI + 게임 조합은 한국 빈자리
- ✅ **듀얼 모드** — 정서 상태에 따른 능동/수동 전환
- ✅ **콘텐츠 IP 무료** — 성경은 Public Domain
- ✅ **AI 자유도** — 종교 콘텐츠는 _해석_ 으로 환각 허용도 ↑
- ✅ **타겟 명확** — 기독교 + 정신건강 관심층 (한국 ≈ 500만, 글로벌 25억)

### 5.2 우려 & 대응

| 우려                                          | 대응                                                          |
| --------------------------------------------- | ------------------------------------------------------------- |
| **신학적 검증 리스크** — LLM 환각이 이단 해석 | 교단 자문 + 출력 필터 + _"AI 보조 — 본문은 성경 참조"_ 명시   |
| **타겟 협소** — 비신자 진입 장벽              | _"성경 지혜 with AI"_ 톤 — 종교색 강도 사용자 선택            |
| **게임화 비판** — 성경을 오락화?              | _서사 체험_ 으로 포지셔닝. 게임 = 깊은 이해 도구              |
| **유료화 모호**                               | freemium: 트랙 A 무료, 트랙 B (게임) + AI 무제한 = 월 3,900원 |
| **8-11 인물 선택 균형**                       | 베드로(14)·다니엘(15) 은 **V2 이월이 아니라 이미 §2.2 에 편입 완료**(2026-08-05 정정 — 이 행은 이미 만든 인물을 미착수로 적고 있었다). 바울은 여전히 미착수. _시즌제 콘텐츠_ 기조 유지 |

## 7. MVP 로드맵

### V1.0 — Minimum Lovable Product (3개월)

- 트랙 A: 1~5 (일기·잠언·전도서·시편·고통)
- AI 묵상문 생성 + 시편 톤 챗봇
- 무료, 무계정 (익명)
- **검증 목표**: D7 retention 30%, _"내일도 쓰고 싶다"_ 정성 응답 70%

### V2.0 — Story Game PoC (+3개월)

- 트랙 B: _요셉_ 1편 (RPG 30분 분량)
- TTS (일기 낭독)
- 구독 plan (월 3,900원, 첫 7일 무료)
- **검증 목표**: 게임 완주율 50%, 결제 전환 5%

### V3.0 — Scale (+6개월)

- 모세·다윗·예수 게임 추가
- 영어/스페인어 다국어
- 익명 감정 공유 커뮤니티
- B2B (교회 단체 구독)
