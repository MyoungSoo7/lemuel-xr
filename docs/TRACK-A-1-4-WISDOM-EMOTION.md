# Track A · Theme 1~4 설계 — 영성·감성·이성 × 정신건강

> **트랙**: A (정적 회복 콘텐츠 — 사용자가 *감정 입력* 시 트리거)
> **범위**: 일기/묵상 · 잠언/지혜 · 전도서/인생 · 시편/감정
> **설계 원칙**: 각 주제를 **영성·감성·이성** 3차원으로 풀고, 각 차원이 *어떤 정신건강 효과* 와 연결되는지 명시.

---

## 0. 왜 이 4개를 묶었나

PLAN.md 의 1~7 중 1~4 는 **내적 처리 (internal processing)**, 5~7 은 *행동 지침 (action guidance)* 으로 분류됨.

| Theme | 핵심 | 외부 도움 (정신건강) |
|---|---|---|
| 1. 일기와 묵상 | 자기 표현 | Pennebaker expressive writing (트라우마 회복) |
| 2. 잠언과 지혜 | 인지 재구조화 | Cognitive Reframing (CBT) |
| 3. 전도서와 인생 | 실존 수용 | Mortality Salience (existential therapy) |
| 4. 시편과 감정 | 감정 인증 | Emotion validation (DBT) |

이 4개는 *내면을 들여다보는* 도구 — 사용자가 *지친 상태* 일 때 가장 먼저 만나는 콘텐츠.

## 1. 영성 · 감성 · 이성 — 세 차원 공통 framework

각 주제를 단순히 *성경 텍스트* 로 두지 않고, **3개 차원** 으로 풀어 사용자가 자기 상태에 맞춰 진입.

| 차원 | 정의 | 활성화되는 인지 |
|---|---|---|
| **영성** | 초월·의미·존재의 차원 | 디폴트 모드 네트워크 (DMN), 의미 추구 |
| **감성** | 정서·관계·신체의 차원 | 변연계, 인터로셉션 (몸 인식) |
| **이성** | 분석·언어·문제 해결 차원 | 전전두엽 PFC, 메타인지 |

사용자가 같은 *시편 23편* 을 만나도:
- 영성 진입 → *"내가 부족하다는 것을 인정한다"* 식 묵상
- 감성 진입 → *"양처럼 인도받고 싶은 마음"* 의 정서 체험
- 이성 진입 → *"왜 이 시편이 3000년 살아남았는가"* 의 분석

→ **사용자가 진입 모드를 선택** (또는 AI 가 입력 텍스트에서 추정).

## 2. Theme 1 — 일기와 묵상

### 2.1 정체성

> *"오늘 너에게 무슨 일이 있었는가"* — 자기 표현의 도구.

성경적 근거: 시편 (다윗의 일기), 예레미야 애가 (선지자의 슬픔), 솔로몬의 잠언 일부.

### 2.2 영성·감성·이성 3차원

| 차원 | 사용자 경험 | 활동 |
|---|---|---|
| **영성** | *"나는 누구 앞에서 쓰는가"* | 작성 후 *읽어주는 분이 있다는 인식* — 묵상 일기 |
| **감성** | *"오늘 어떤 감정이 있었나"* | 감정 단어 8개 (불안·슬픔·분노·외로움·기쁨·평온·감사·혼란) 중 선택 + 강도 슬라이더 |
| **이성** | *"무엇이 일어났는가, 왜 그렇게 느꼈는가"* | 5W1H 구조 입력 폼 |

### 2.3 정신건강 효과 (근거 기반)

**Pennebaker Expressive Writing Paradigm** (1980년대~):
- *4일 연속 20분 자유 작성* → 면역 기능 향상, 우울 감소, PTSD 회복
- 메커니즘: 감정 → 언어 변환 시 *전전두엽 활성 + 편도체 진정*
- 한국 연구도 다수 — 한양대 임상심리 그룹 (2015~) 효과 확인

**우리 앱 구현**:
1. **자유 형식** (기본) — 시간 제한 없음, 누가 안 본다는 보장 (로컬 저장 옵션)
2. **AI 거울 모드** — 사용자가 쓰는 동안 *말하지 않는 AI* 가 옆에 있는 느낌 (시각적 호흡 표시기만)
3. **묵상 변환** — 작성 후 *"이 일기를 묵상으로 바꿔드릴까요?"* — AI 가 시편 톤으로 한 문장 응답 (옵션, 거절 가능)

### 2.4 핵심 기능

```
[일기 쓰기]
  ├── 자유 형식 (그냥 쓰기)
  ├── 5W1H 구조 (이성 진입)
  ├── 감정 라벨 + 강도 (감성 진입)
  └── 묵상 응답 받기 (영성 진입, 선택)

[묵상 변환]
  - 사용자 일기 → AI 가 시편/잠언 톤 1~2 문장
  - 저장 또는 폐기 (압박 없음)
```

### 2.5 정신건강 안전장치

- **자해·자살 키워드 감지** → 즉시 *위기 자원* 안내 (1577-0199 자살예방상담전화, 한국심리상담센터 등)
- **반복 부정 표현** (3일 연속 우울/절망 강도 9+) → *"전문가 상담 추천드려요"* 카드 노출
- **AI 응답 톤 제어** — 사용자가 *"AI 가 답하지 말기"* 토글 가능. 기본은 ON

## 3. Theme 2 — 잠언과 지혜

### 3.1 정체성

> *"내가 지금 어떻게 결정할까"* — 인지 재구조화의 도구.

성경적 근거: 잠언 (솔로몬), 욥기 일부, 전도서의 일부 격언.

### 3.2 영성·감성·이성 3차원

| 차원 | 사용자 경험 | 활동 |
|---|---|---|
| **영성** | *"하나님이 보시기에 어떤 선택이 옳은가"* | 잠언 1개 + 신학적 묵상 |
| **감성** | *"이 잠언이 내 마음을 어떻게 만지는가"* | 잠언 1개 + 사용자 정서 반응 입력 |
| **이성** | *"이 격언의 일반화 원칙은 무엇인가"* | 잠언 1개 + 현대 심리학·철학 해석 |

### 3.3 정신건강 효과

**Cognitive Reframing (CBT)** — Aaron Beck (1960년대):
- *자동 사고* 의 *재구조화* — *"그 일이 끝났다"* → *"그 일이 *지금* 끝났다, 다음이 있다"*
- 잠언이 가진 *시간 거리* (수천 년 전) 는 *이미 검증된 사고 패턴* 이라는 권위가 됨
- **메타인지** 활성 — *"내 사고 패턴을 보는* 사고"

**우리 앱 구현**:
1. **잠언 카드 3장** — 사용자 상황 입력 → AI 가 매칭된 3개 잠언 카드 제시 (선택지)
2. **재구조화 워크시트** — 잠언 1개 + *"이걸 내 상황에 어떻게 적용?"* 질문 3개
3. **반박 모드** — *"이 잠언이 틀린 것 같으면 반박해 보세요"* — 자기 사고와 *대화하는* 경험

### 3.4 정신건강 안전장치

- **잠언의 단순화 위험** — *"노력하면 된다"* 류 잠언은 *우울증 환자에게 해로움*. AI 가 사용자 상태 (지난 7일 입력) 보고 *적절한 잠언만* 노출
- **"네 마음을 지키라"** (잠 4:23) 같은 잠언은 *지금 마음을 지키지 못하는 상태* 의 사용자에게 *역효과* — 노출 차단

### 3.5 핵심 기능

```
[잠언 카드 추천]
  - 사용자 상황 1문장 입력
  - AI 가 잠언 3장 + 각 카드의 *적합도* 표시
  - 사용자 1장 선택

[3차원 진입]
  - 영성: 신학 묵상 (2~3분)
  - 감성: 정서 반응 입력 (1~2분)
  - 이성: 현대적 재해석 (2~3분)
```

## 4. Theme 3 — 전도서와 인생

### 4.1 정체성

> *"이 모든 것이 헛되다"* — 실존 수용의 도구.

성경적 근거: 전도서 전체 (솔로몬 전기). *지혜의 절정에서 무력감* 을 노래한 책.

### 4.2 영성·감성·이성 3차원

| 차원 | 사용자 경험 | 활동 |
|---|---|---|
| **영성** | *"이 헛됨 너머에 무엇이 있는가"* | 전도서 + *"하나님을 경외하라"* 결론 (전 12:13) |
| **감성** | *"허무함의 감정을 그대로 인정"* | 전도서 1~3장 + 사용자 *"오늘 내 인생도 헛되다"* 적기 |
| **이성** | *"왜 솔로몬이 이걸 깨달았는가"* | 전도서 + 현대 실존철학 (사르트르·하이데거) 비교 |

### 4.3 정신건강 효과

**Existential Therapy** (Frankl, Yalom):
- *"인생은 의미가 없다는 인식이* 진짜 의미를 찾는 시작"
- 죽음·고독·자유·무의미 4가지 *궁극 관심사* 직면
- 한국에서는 *임상신학* 영역에서 다뤄짐

**Mortality Salience** (Greenberg et al, 1986):
- 인간이 *자기 유한성* 을 인식하면 *깊은 가치* 추구로 전환
- 단, *너무 직접적* 죽음 노출은 *방어 기제* 활성화
- 전도서는 *시적·은유적* 으로 죽음 다룸 — 안전한 거리 제공

**우리 앱 구현**:
1. **전도서 낭독** — 사용자 *허무함* 입력 시 전도서 1:2~11 음성 낭독 (Coqui TTS, 시 같은 톤)
2. **헛됨 vs 의미 게임** (선택지) — *"오늘 한 것 중 헛된 것 / 의미 있는 것 각 1개"* — 둘 다 인정
3. **계절 챕터** — 전도서 3:1~8 (*"모든 일에는 때가 있다"*) → 사용자 *"지금 어떤 계절"* 선택

### 4.4 정신건강 안전장치

- **공허감 위험** — 전도서가 *우울증 환자의 nihilism* 을 강화할 수 있음. AI 가 *전도서 직후 자살 키워드 모니터링* 강화
- **결론 회피 금지** — 전 12:13 ("하나님을 경외하고 그의 명령을 지킬지어다") 의 *결론* 까지 함께 보여주기. 1~11장만 노출 X
- **반어법 인식 어려움** — 전도서는 *반어법* 많음 (*"청년이여 즐거워하라... 그러나 심판이 있을 줄을 알라"*). AI 가 *현대인이 오해하기 쉬운 구절* 에 *각주* 자동 추가

### 4.5 핵심 기능

```
[전도서 모드]
  ├── 낭독 (오디오) — 1:2~11
  ├── 헛됨/의미 일기
  ├── 계절 챕터 (3:1~8 매칭)
  └── 결론 함께 보기 (12:13~14)

[현대 비교]
  - "사르트르가 *지옥은 타인이다* 라고 했다"
  - "솔로몬은 *허무가 출발이다* 라고 했다"
  - 같은 통찰, 다른 결론
```

## 5. Theme 4 — 시편과 감정

### 5.1 정체성

> *"내 감정이 부끄럽지 않다"* — 감정 인증의 도구.

성경적 근거: 시편 150편. *분노·복수·기쁨·찬양* 까지 모든 감정 포함된 *인간 감정 백과사전*.

### 5.2 영성·감성·이성 3차원

| 차원 | 사용자 경험 | 활동 |
|---|---|---|
| **영성** | *"내 감정을 누구 앞에서 토로하는가"* | 시편 + *"이 감정도 들어주신다"* 인식 |
| **감성** | *"이 감정을 나만 느끼는 게 아니구나"* | 사용자 감정 → 매칭 시편 (분노=58편, 외로움=42편, 기쁨=98편) |
| **이성** | *"이 시인은 왜 이렇게 표현했나"* | 시편 1편 + *작시 배경 + 문학적 분석* |

### 5.3 정신건강 효과

**Emotion Validation** (Marsha Linehan, DBT):
- 감정을 *틀린 것* 으로 판단하지 않고 *그 자체로 인정*
- *수치심 감소* — 가장 강한 회복 메커니즘 중 하나
- 시편은 *3000년 전 시인도 같은 감정* — *세대 간 인증*

**Affect Labeling** (UCLA, Lieberman et al, 2007):
- 감정을 *이름 붙이는* 순간 편도체 활성 ↓
- *"분노" 라고 말하는* 것만으로 분노 강도 감소
- 시편이 *수많은 감정 어휘* 제공 — *어휘 다양성* 자체가 치료

**우리 앱 구현**:
1. **시편 매칭기** — 사용자 감정 입력 → AI 가 매칭 시편 1~3개 추천
2. **시편 음성 낭독** — Coqui TTS, *3가지 톤* (애절·평온·찬양) 사용자 선택
3. **나만의 시편 쓰기** — 시편 형식 따라 사용자 작성 (해당 감정의 *공식 표현* 가지기)
4. **시편 일기** — 매일 *하루 1편* 추천 + 사용자 *오늘의 한 줄*

### 5.4 정신건강 안전장치

- **저주 시편 (Imprecatory Psalms)** — 시 58·109편 등 *원수에 대한 저주* 강함. *현대 사용자에게 그대로 노출 시 폭력 정당화* 우려. AI 가 *해석 같이 노출* 또는 *사용자가 명시적 요청* 시만 표시
- **시편의 *극단적 감정*** — 22편 *"내 하나님이여 어찌하여 나를 버리셨나이까"* 같은 강한 표현. 우울증 진단 사용자에게 *추가 위로 문구* 자동 동반
- **시편을 *읽는* 동안 자살 키워드 입력 시** — 즉시 위기 자원 + *전문가 상담 권유*

### 5.5 핵심 기능

```
[시편 매칭]
  - 감정 입력 → AI 추천 1~3편
  - 시편 본문 (개역개정 + 현대 번역 토글)
  - 음성 낭독 (3 톤)

[나만의 시편]
  - 시편 형식 (탄식·간구·찬양) 선택
  - 사용자 입력
  - AI 가 *시편 운율* 로 다듬어주기 (옵션)
  - 저장 → 개인 시편집

[시편 일기]
  - 매일 1편 추천 (시편 순환 150일)
  - 사용자 한 줄 응답
```

## 6. Theme 간 흐름 — 사용자 여정

```
사용자 입력: "오늘 너무 지쳤어"
   │
   ├──► AI 감정 분류: 피로·체념·외로움
   │
   ├──► Theme 4 (시편 매칭) 우선 추천
   │       "시편 42편 (목마른 사슴) 들어보시겠어요?"
   │
   ├──► (낭독 후) Theme 1 (일기) 자연 연결
   │       "이 감정 일기에 남기시겠어요?"
   │
   ├──► (며칠 후, 비슷한 패턴 3회) Theme 3 (전도서) 추천
   │       "허무감이 자주 오시네요. 전도서 같이 보실래요?"
   │
   └──► (사용자가 *결정 어려움* 입력) Theme 2 (잠언) 추천
           "잠언 3장 5~6절 카드 추천드려요"
```

→ **4 Theme 이 *서로 보완*** — 한 주제만 노출하지 않음.

| 잠언 카드 추천 (상황 → 잠언 3장) | Theme 2 | 동일 |
| 묵상 변환 (일기 → 시편 톤) | Theme 1 (옵션) | Claude 3.5 (긴 컨텍스트) |
| 안전장치 (자해·자살 키워드) | 전 Theme | gpt-4o-mini |
| 사용자 시편 다듬기 | Theme 4 | Claude (운율 감지) |

**예상 사용자당 월 비용**: 30회 사용 가정 → **$0.50~1.00 / 사용자 / 월**

## 8. 측정 — 사용자 회복 지표

PHQ-9 (우울 검사) 류 *공식 검사* 를 *앱 안에* 넣으면 *진단* 으로 오해됨 → 대신 **자체 지표** 사용:

| 지표 | 측정 |
|---|---|
| 감정 다양성 (Emotion Diversity) | 사용자가 입력하는 감정 단어 종류 수 |
| 감정 강도 변화 | 같은 감정의 *강도 슬라이더* 추이 |
| 일기 길이 변화 | 자유 일기의 글자 수 (Pennebaker: 짧음 → 김 = 회복) |
| 자기 표현 어휘 풍부도 | NLP 측정 (어휘 다양성 + 추상도) |
| 시편/잠언 즐겨찾기 패턴 | 어떤 감정을 *반복적으로 마주하는가* |

이 지표는 *사용자에게 직접 보여줌* — *"이번 달 너의 감정 어휘가 12개에서 18개로 늘었어요"* 류.

→ 단, *전문가 진단을 대체하지 않음* 항상 명시.


또는 "*상관없음, 그냥 시작*" 옵션 — AI 가 사용자 패턴 보고 자동 선택.

## 10. 트랙 B (게임) 와의 연결

Theme 4 (시편) 끝난 사용자가 *다윗 시편 작가* 라는 사실 인식 → 트랙 B 다윗 미션 자연 추천.

Theme 3 (전도서) 사용자에게 *솔로몬* 인물 카드 노출 → Phase 3 에서 솔로몬 게임 추가 가능성 시사.

Theme 2 (잠언) 사용자가 *결정 어려움* 호소 → 트랙 B 요셉 (결정의 게임) 추천 가능.

→ **트랙 A·B 가 *서로의 진입로*** 가 됨. 사용자는 자기도 모르게 *깊은 영역* 으로 이동.

## 11. 신학적 균형 — 1~4 의 위험

| Theme | 위험 | 대응 |

## 13. 작가 노트

이 4개를 *콘텐츠 모음* 으로 만들면 *Bible.com 의 또 다른 버전* 이 된다. 차별화는 **3차원 진입 + 정신건강 안전장치 + AI 거울**.

영성·감성·이성을 분리한 이유 — 사용자는 *영성 모드만 강요받는* 종교 앱에 지쳐있다. *이성으로 분석하고 싶은 날* 도 있고 *그냥 감정만 토로하고 싶은 날* 도 있다. 같은 시편 23편이라도.

정신건강 안전장치를 *근거 기반* 으로 넣은 이유 — Pennebaker, Linehan, Lieberman 의 연구는 *교회 밖의 권위* 다. 비신자·반신앙 사용자에게도 *진지한 회복 도구* 로 인식되게.

핵심: 이 앱은 *전도 도구* 가 아니다. *회복 도구* 다. 회복된 사람이 *어디로 가는가* 는 사용자 몫.

---

> **TL;DR** — 4 Theme × 3 차원 (영성·감성·이성) × 정신건강 근거 (Pennebaker·CBT·Existential·DBT). 사용자가 *진입 모드를 선택* 하고, AI 가 *거울* 이 되고, 신학·심리 안전장치가 *함부로* 응답하지 않게 한다. 회복 도구로서의 성경.
