# lemuel-xr — Mission

> *"누구든 절망에 빠질 수 있다. 절망에 *대비* 하는 사람만이 그 한순간을 견딘다."*

## 1. 위치 (Positioning)

**lemuel-xr** 은 *자살예방 영적단련 교육 콘텐츠* 다. 임상 진단·치료의 영역이 아니라, 큐티·민방위 교육과 같은 *예방적 자기훈련* 의 영역에 있다.

| 우리는 | 우리는 아니다 |
|---|---|
| 일반인 누구나의 *영적 회복력* 을 *미리* 훈련하는 교육 콘텐츠 | 우울증·자살위험을 *진단* 하거나 *치료* 하는 임상 도구 |
| 성경 인물 4인의 절망 극복 *이야기* 를 매개로 한 몰입 체험 | 정신건강 전문가·신학자의 자문 *필수* 통과를 요구하는 거버넌스 시스템 |
| 사용자의 일상 *습관 형성* (AR 1~7) 을 지원하는 트레이너 | 위기 개입·상담·약물 처방의 대체재 |
| 누구나 시작·종료 가능한 *교육* 프로그램 | 의료보험·임상시험·진료의 일부 |

## 2. 왜 (Why)

대한민국은 OECD 자살률 1위 의 불명예를 안고 있다. 그 절망의 한순간을 *미리 견딜 수 있게 준비된 사람* 과 *준비되지 않은 사람* 의 차이는 크다.

극기훈련이 *극한의 신체 상황* 에 대비하듯, 민방위 교육이 *비상사태* 에 대비하듯, 영적 단련 은 *절망이라는 비상사태* 에 대비한다. 우리는 그 *대비 훈련* 을 누구나 접근 가능한 디지털 형태로 제공한다.

## 3. 무엇으로 (What)

**핵심 매개:** 성경의 네 인물 — **요셉 · 모세 · 다윗 · 예수** — 각각 *완전히 다른 형태의 절망* 을 겪었고, 모두 *신적 구원* 의 스토리로 마무리됐다. 수천 년이 지난 지금까지 그 이야기가 살아남았다는 것은 그 이야기에 *시대를 넘는 회복의 원형* 이 들어있다는 신호다.

```
VR (몰입 의식)              AR (일상 습관)
┌──────────────────┐      ┌──────────────────┐
│  요셉 — 배신·기다림 │      │  1. 감사 기록      │
│  모세 — 두려움·소명 │ ←→  │  2. 호흡 의식      │
│  다윗 — 죄책·회복   │      │  3. 본문 묵상      │
│  예수 — 고난·용서   │      │  ...               │
└──────────────────┘      │  7. 침묵 시간      │
                          └──────────────────┘
   각성 트리거                  반복 단련
```

VR 4인의 만남은 *각성의 한순간* — 단단함을 *떠올리게* 한다.
AR 1~7 의 반복은 *근육의 단련* — 단단함을 *몸에 새긴다*.

핵심은 후자다. 큐티 어플의 *streak* 처럼, 매일의 작은 실천이 위기의 순간에 빛을 발한다.

## 4. 누가 (Who)

**모두를 위한 콘텐츠.** 우울증을 진단받았거나 자살위험이 평가된 사용자가 사용해도 도움이 되도록 (위기자원 안내 footer 상시 노출), 하지만 *대상* 으로 삼지는 않는다.

대상은 *지금은 멀쩡한* 모든 사람 — 그 멀쩡함이 언제 흔들릴지 모르기 때문에, 흔들리기 전에 자기를 단련하려는 모든 사람.

## 5. 어떻게 (How)

**플랫폼:** VR (Quest 3 / Vision Pro / Galaxy XR) + AR (모바일 Web) + 백엔드 (Spring Boot 4) + AI 사이드카 (Python FastAPI) + TTS (Coqui XTTS-v2).

**작업 모드:** 자문가 *검증* 프로세스 없이 *제작자 책임* 하에서 자체 안전 가이드라인 (`docs/safety-guidelines.md`) 을 지킨다. 출시 시점에 신학·정신건강 전문가의 *추천 인용* 1~2명을 받는 것은 *신뢰도용 옵션* 이며 *필수 검증 절차* 가 아니다.

**모니터링:** 사용자의 *체험 만족도·습관 형성도* 만 추적한다. 정신건강 상태·진단·치료 결과는 추적·기록·저장하지 않는다 (그 영역은 임상 전문가의 몫).

## 6. 거버넌스 (Governance)

**자문 필수 검증** 모델은 폐기됐다 (2026-05-22). 그 대신:

- *자체 안전 룰* — `docs/safety-guidelines.md`
- *제작자 책임* — 자해 묘사·트리거 표현 회피, 위기자원 (109 자살예방 상담전화) footer 상시 노출
- *공개 피드백* — 사용자 의견 수렴 채널은 운영하되, 그것이 *검증 절차* 는 아님

## 7. 비유 (Analogies)

- **큐티 어플 모델** — 매일 5분의 성경 묵상 + 일기. 임상 도구 아니지만 수십 년간 수많은 신자의 영적 회복에 기여.
- **민방위 교육 모델** — *지금은* 비상사태가 아니지만, *언젠가의* 비상에 대비. 군사적 강제력 없는 *예방 훈련*.
- **요가·명상 어플 모델** — 의료 영역 아니지만 *심신 회복* 보조. Calm, Headspace 등의 카테고리에 인접.

## 8. 비목표 (Non-Goals)

다음은 *명시적으로* 우리의 목표가 아니다 :

- 우울증·자살위험 사용자의 *진단* / *분류* / *위험 평가*
- *실시간 위기 개입* (사용자가 위기 상태로 진입하면 즉시 `109` 안내로 외부 위탁)
- *임상시험* 또는 *의료보험 적용* 또는 *처방* 의 일부가 되는 것
- 신학적 정통성의 *공식 검증* (성경 본문은 *현대인의 성경* 번역 그대로 인용, 자체 해석 *최소화*)
- 사용자의 정신건강 데이터 *수집* / *저장* / *분석*
