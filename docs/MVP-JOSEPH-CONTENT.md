# MVP-JOSEPH — XR 실 콘텐츠 (Scene 별 대본·인터랙션·자원)

> **상위 문서**: `MVP-JOSEPH.md` (구조·설계)
> **본 문서**: 실제 사용자에게 노출되는 *대본·자산·인터랙션 트리거* — Unity 6 LTS + OpenXR 환경에서 그대로 구현 가능한 수준의 데이터.
> **타겟 디바이스**: Quest 3 (기준) / Quest Pro / Vision Pro / Galaxy XR — capabilities-min: 6DoF + hand tracking + spatial audio. eye tracking 은 optional.
> **세션 길이**: 6분 ± 1분. *5분 안에 종료 가능한 short path* 와 *7분 안에 종료 가능한 deep path* 분기.
> **톤 가이드**: `lemuel-xr-theology-tone` + `lemuel-xr-mental-health-safety` 사전 가이드 적용 — disputed_points 명시, R1~R5 안전선 (영적 비상 대비 교육 맥락) 통합, *AI 보조 — 본문은 성경 참조* footer 자동. *임상/의료 도구 아님 — 누구나 절망 비상에 대비하는 영적 단련*.
> **근거 인용**: `THEOLOGY-REFERENCES.md` 의 J1 (박영원 2015, 요셉 내러티브와 섭리) 을 핵심 인용.

### 0.2 인터랙션 추상화

| 인터랙션 의도 | Quest 3 (기준) | Vision Pro | Galaxy XR | Web 폴백 |
|---|---|---|---|---|
| 물체 잡기 | controller grip / pinch | pinch + dwell | controller grip | click + hold |
| 시선 응시 (대상 확정) | head ray + 1초 dwell | eye gaze + 0.5초 | head ray + 1초 | mouseover + 1초 |
| 다음 진행 | A button / pinch | pinch | A button | click "다음" |
| 침묵 모드 (말 안 함) | controller 잠시 내려놓기 (10초 무동작) | hand 휴식 자세 | 동일 | "잠시 멈춤" 버튼 |
| 메뉴 호출 | menu button | 손 손바닥 위로 | menu | top-right ⋯ |

→ 모든 결정은 *손동작* 으로 표현. 컨트롤러 키 라벨에 의존하지 않음 — *말이 아니라 행위* 가 요셉 미션의 핵심.

### 0.3 시간·공간 안락성

- 카메라 *이동 없음* (정지 시점 only) — 모션 시크니스 회피
- 큰 환경 전환은 fade-to-black 0.8초 + 페이드인 1.2초로 처리
- *3D 사운드 우선 + 텍스트 자막 동기* (청각 장애 / 무음 환경 대응)
- 모든 NPC 음성은 Coqui XTTS-v2 사전 캐시 (오프라인 동기화 가능, R5 AI opt-out 시에도 작동)

### 0.4 결정 기록 (백엔드)

각 Scene 의 사용자 결정 → `POST /api/game/joseph/scene/{n}/decide` →
- `game_decisions` 테이블에 JSONB 로 기록 (V4 schema)
- `scene_views` 에 entered/exited timestamp 기록 (몰입 흐름·페이스 분석용)
- `interaction_meta` 에 *망설인 시간 (자루를 손에 쥐고 있던 시간), 시선 분배* 같은 마이크로 신호 기록 — *사용자 자신의 묵상 패턴 회고용* (임상 평가 X)

→ Day 30 리포트 (`v_user_30d_summary`) 에서 *자기 묵상 패턴* 으로 노출 — *진단/평가 톤 차단*.

### 0.5 항상 노출되는 footer

화면 좌하단 (UI 안전 영역) 에 작은 글씨로 *영구* 노출:

```
AI 보조 — 본문은 성경 참조 | 위기 시 1577-0199
```

→ R5 + theology-tone 7번 + R1 항상 충족.

### 0.6 5 Scene 의 영성·감성·이성 차원 매핑

본 미션은 *영성만의 미션이 아님*. *누구나 — 절망 대비 훈련 사용자* 가 *자기 상태에 맞춰 진입할 수 있게* 5 Scene 을 *영성 (초월·의미)*, *감성 (정서·관계)*, *이성 (분석·결정)* 의 3차원으로 매핑.

- 범례: ● 주로 활성되는 차원 / ◐ 부차적 차원 / · 약한 활성

| Scene | 영성 (초월·의미) | 감성 (정서·관계) | 이성 (분석·결정) |
|---|---|---|---|
| 1 (파라오 꿈) | ◐ 꿈→섭리 해석 | · | ● 7년 풍년·흉년 패턴 인식 |
| 2 (저장) | · | ◐ 백성 향한 책임감 | ● 비율 결정 (1/5·1/3·1/2) |
| 3 (분배) | ◐ 누구를 우선할 것인가 | ● NPC 시선·아이의 손짓 | ● 자루 수 분배 |
| 4 (재회) | ● 창 45:5 섭리 메시지 | ● 형제 정서 | ◐ 응답 선택 (밝힘/시험/침묵) |
| 5 (회복) | ● 한 줄 본문 | ● 회복 문구 정서 | · |

→ 이 매핑은 사용자가 자기 상태에 맞춰 진입할 수 있게 함 — *영성만의 미션이 아님*. 이성 활성 사용자는 Scene 1~3 의 *결정 흐름* 에 몰입 가능, 감성 활성 사용자는 Scene 3~5 의 *관계·정서* 에 몰입 가능, 영성 활성 사용자는 Scene 4~5 의 *섭리 메시지* 에 몰입 가능.

→ `lemuel-xr-theology-tone` SKILL.md §6 (영성·감성·이성 3차원 균형) 조항 충족.

## 1. Scene 1 — 파라오의 꿈 (1분)

### 1.1 배경·환경

- **공간**: 이집트 궁전 알현실 (밤). 횃불 4개 → 따뜻한 주황 톤. 천장 높이 가시화 위해 *위쪽* 에 화려한 상형문자.
- **사용자 위치**: 대전 한가운데. 정면 4m 앞에 파라오 (NPC) 가 옥좌에 앉음. 양 옆 신하 NPC 4명 침묵.
- **에셋 분량**: glb 12MB (manifest: `joseph/scene1/quest3/v1.0.0.json`)
- **공간 음향**: 멀리서 들리는 *나일강 소리 + 풍금 같은 저음* 루프. 횃불 burning crackle (좌우 panning).

### 1.2 대본

**[파라오, 첫 호출 — 0:00]**
> *"나에게 두 가지 꿈이 있었다.* (3초 침묵)
> *살찐 일곱 마리 소가 강에서 올라왔는데… 마른 일곱 마리 소가 그것을 삼켰다.*
> *내 술 맡은 관원장이, 옥에 있는 한 히브리 청년이 꿈을 해석한다 하더라."*

**[사용자 손 안에 *책 한 권* 이 fade-in — 0:18]**

UI:
- 책 표지 *"꿈의 책"* (히브리어·이집트어 혼재한 가상 폰트)
- 사용자가 *책을 펼침* → 페이지가 자동으로 한 장씩 넘어가며 다음 텍스트가 떠오름:

**[책에 떠오르는 텍스트 — 0:30]**
> *"일곱 살찐 소는 일곱 해의 풍년이요*
> *일곱 마른 소는 일곱 해의 흉년이라*
> *(창세기 41:26~27)"*

**[요셉 (자신의 목소리, 사용자 내면 narration) — 0:50]**
> *"나는… 이 꿈의 의미를 알 것 같다.*
> *그러나 알고도 그 뜻을 따라 *행동* 하지 않는다면, 그 백성은 굶을 것이다."*

→ 자동으로 Scene 2 진입 (fade out 0.8초)

### 1.3 인터랙션

- 사용자는 *오직* 책을 펼치는 동작만 한다 (양 손으로 책 잡기 → 펼치기 제스처)
- 책을 펼치지 않으면 *60초 후 자동 진행* (음성 가이드: *"책을 펼쳐 보시겠어요?"* 1회만)
- 책 페이지가 넘어가는 동안 *햅틱 약함* (지속 100ms, 강도 0.3) — 종이 결의 감각

### 1.4 안전·신학 footer

- **신학**: 본 Scene 은 *섭리* 개념 도입. *섭리* 가 *수동적 운명론* 으로 해석되지 않도록 *"행동하지 않으면 백성은 굶을 것이다"* 라는 요셉의 자유의지 표현 포함.
  > 박영원 (2015, J1) 의 *요셉 내러티브와 섭리* 논의 — *자유의지와 예정의 공존, 인간 죄악을 궁극적 선으로 인도하는 섭리* — 를 따라 본 Scene 에서는 두 차원을 *함께* 노출.
- **disputed**: free will vs predestination — Scene 1 에서는 *단일 입장 채택 없이* 두 차원을 *함께* 노출

## 2. Scene 2 — 풍년기, 저장 결정 (1분 30초)

### 2.1 배경·환경

- **공간**: 황금빛 보리밭. 지평선 위 *7개 곡식 창고* 가 *건설 중* 으로 보임 (반투명 상태에서 점점 완성).

- **에셋**: 11MB. 보리밭 셰이더는 *바람에 흔들리는 GPU instancing*.
- **사운드**: 바람·풀 스치는 ASMR-tier 자연음 + 멀리서 농부들 노래 (Coqui 합성, 짧은 멜로디 5초 loop, 톤은 *기쁘되 절제*).

> *얼마나 저장할 것인가… 백성의 *오늘* 과 *내일* 사이에서 선택해야 한다."*

**[UI — 0:15]**
사용자 정면 1.5m 앞에 *곡식 자루 3개* 가 떠 있음.

## 6. faith_tone 3단 분기 (Scene 5 회복 문구 예)

`users.faith_tone` 에 따라 Scene 5 의 동일 회복 문구가 3단으로 분기. 본 문서는 *대표 4 감정 × 3 tone = 12개* 를 명시. 나머지 *6 감정 × 3 tone = 18개* 는 §11.3 *사전 캐싱 대상* 으로 노트.

**감정 = 두려움** 케이스 예시:

| tone | 출력 |
|---|---|
| **strong** | *"여호와는 너의 두려움 안에서도 책임 있는 결정을 하게 하셨다. 그 자체가 *그분의 자유* 다. (창 45:5)"* |
| **balanced** | *"두려움 안에서도 너는 *책임 있는 결정* 을 했다. 그 자체가 자유다. 요셉의 이야기는 *결정의 의미가 시간이 흘러* 드러난다 말한다."* |
| **soft** | *"3000년 전의 이야기는 *두려움 속에서도 결정을 내릴 수 있다는 것* 이 자유의 시작이라 보았다. 결정의 의미는 *지금 다* 보이지 않아도 된다."* |

**감정 = 불안** 케이스 예시:

| tone | 출력 |
|---|---|
| **strong** | *"여호와께서 너의 불안 가운데서도 곡식을 미리 쌓게 하셨다. *지금의 결핍* 은 *미래의 누군가* 를 살릴 양식이 될 수 있다. (창 41:36)"* |
| **balanced** | *"불안은 *준비* 의 또 다른 이름이기도 하다. 요셉이 7년 풍년을 *7년 흉년의 양식* 으로 옮겼듯, 지금의 결핍이 미래의 누군가를 살릴 양식이 될지 모른다."* |
| **soft** | *"고대의 이야기 하나는, *불안 안에서도 작은 양식을 한 자루 옮기는 일* 이 미래를 바꿀 수 있다고 말한다. 지금 다 해결하지 않아도 괜찮다."* |

**감정 = 분노** 케이스 예시:

| tone | 출력 |
|---|---|
| **strong** | *"여호와는 형제의 해함조차 너의 길을 막을 수 없게 하셨다. 그 길은 *끝이 아니었다*. (창 50:20)"* |
| **balanced** | *"형제의 해함이 너의 길을 막은 듯 보였으나, 그 길이 끝이 아니었다. 분노는 *너의 약함이 아니라 너의 정당함* 의 신호이기도 하다."* |
| **soft** | *"고대의 한 이야기는, *해를 입은 길이 끝이 아니었음* 을 기억하라 한다. 지금의 분노를 *너의 약함* 으로 읽지 않아도 된다."* |

**감정 = 무자격감** 케이스 예시:

| tone | 출력 |
|---|---|
| **strong** | *"여호와는 *노예와 죄수* 의 자리에 있던 너를 *총리* 로 세우셨다. 자리가 너를 만들지 않는다 — *그분이 너를 만드신다*. (창 41:41)"* |
| **balanced** | *"노예와 죄수의 자리에서도 너는 *총리* 였다. 자리가 너를 만들지 않는다. 너의 결정의 무게는 *직함이 아니라 책임* 에서 온다."* |
| **soft** | *"오래된 이야기 하나는, *자리가 사람을 만들지 않는다* 고 말한다. 지금 너의 자리가 너의 가치를 결정하지 않는다."* |

→ 위 *4 감정 × 3 tone = 12개* 는 본 문서에서 *문서상 검증 완료*. 나머지 *6 감정 (슬픔·외로움·지침·혼란·기쁨·감사) × 3 tone = 18개* 는 §11.3 사전 캐싱 대상.

## 8. 백엔드 호출 흐름 (Spring + LLM)

```
[Scene 1 시작]
  POST /api/game/joseph/start
    → 게임 세션 생성 (game_sessions row)

    body: {"save_ratio": 0.33}

[Scene 3 결정]
  POST /api/game/joseph/scene/3/distribute
    body: {"distribution": {"farmer": 6, "immigrant": 4, "merchant": 2}}
    → 분배 패턴 계산 → 결말 톤 결정
    → game_decisions row + interaction_meta (hesitation 등)

[Scene 4 선택]
  POST /api/game/joseph/scene/4/respond
    body: {"choice": "reveal" | "test" | "silence"}

[Scene 5 종료]
  POST /api/game/joseph/complete
    → game_sessions.completed_at, scene_count_completed, duration_seconds
```
