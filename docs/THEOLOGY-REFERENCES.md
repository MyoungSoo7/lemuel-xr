# 신학·교육 참고 서지 (MVP 콘텐츠 작성 보조)

> **수집 일자**: 2026-05-21 (사용 정책 재정착: 2026-05-22)
> **목적**: 요셉·모세·다윗·예수 4 인물 MVP 콘텐츠 작성 시 *문화·교육 콘텐츠 근거 서지* 제공.
> **수집 방식**: KCI / KISS / koreascholar / earticle 웹 검색 후 핵심 5편은 본문/초록 fetch, 나머지는 학술지 출처만 기록 (드릴다운 추후).
> **포지셔닝 (2026-05-22 재정착)**: lemuel-xr 는 *영적 비상 대비 교육 콘텐츠* — *임상/의료 도구가 아님*. 본 서지는 *교육 콘텐츠 작성 시 *서사·표현*의 근거 참고*. *임상 처방·진단 근거로 사용 금지*. 학자 이름·이론은 *내적 단련 어휘의 출처 표시* 일 뿐, *치료 메커니즘 주장* 아님.

## 0. 사용 가이드

- 각 인물 MVP 문서 (`MVP-{NAME}-CONTENT.md`) 의 *근거 서지 footer* 에서 본 문서의 항목을 인용한다. *§8 정신건강 근거* 같은 *임상 게이트* 절은 폐기 — 운영자 self-review + R1 (1393) 라우팅으로 대체.
- 학술지 출처 (예: 신학연구·구약논집) 는 *드릴다운 후보* 다. 콘텐츠 다음 라운드에서 *해당 학술지의 특정 호 + 저자* 까지 좁힌 뒤 추가 fetch.
- 신학 분쟁 가능 지점 (예: 형벌적 대속 vs Christus Victor) 은 *다중 입장 병기 원칙* — *단일 입장 채택 금지*.
- 인용 시 *치료 효과 주장 금지*. *"~ 의 *내적 단련 어휘를 차용*"* / *"~ 의 *서사적 framing 참고*"* 같은 *문화·교육 어휘* 로 표현.

## 1. 요셉 (Joseph) — 창세기 37~50

### 1.1 확정 논문 (본문 fetch 완료)

#### [J1] The Joseph Narrative in the Context of Divine Providence and Its Logical Consistency
- **저자**: PARK Young-Won (박영원, 충남대학교 영문과)
- **학술지**: Literature and Religion (문학과 종교) 제20권 2호
- **연도**: 2015년 6월
- **출처**: https://db.koreascholar.com/Article/Detail/302158
- **핵심 주장**: 형들의 죄악적 행동이 역설적으로 요셉을 애굽 총리로 만들고 기근에서 가족을 구하는 계기가 됨. 신의 섭리가 *"인간의 죄악을 궁극적 선으로 인도"* 하는 방식을 문학적으로 보여줌. 자유의지 vs 예정 공존 논의.
- **분쟁 지점**: free will defense / Augustinian determinism 다중 입장 — *MVP-JOSEPH §11 disputed_points* 에 명시 권장
- **MVP 활용**: Scene 5 (창 50:20 *"당신들은 나를 해하려 하였으나 하나님은 그것을 선으로 바꾸사"*) 의 신학 footer 인용 근거

### 1.2 드릴다운 후보 (학술지 출처 확보)

#### [J2] 창세기 속임수 내러티브 어떻게 이해할 것인가 — 야곱 이야기 중심
- **출처**: https://dspace.kci.go.kr/handle/kci/1918597
- **언급**: 아브라함·이삭·야곱·요셉 모두에서 속임수가 반복되는 패턴 분석. 요셉의 채색옷·꿈 보고 등이 가족 갈등 유발자로서 거론됨
- **활용 가능 영역**: Scene 1 (꿈을 보고함의 *순진함 / 자기과시* 두 해석 분기)

#### [J3] 창세기 내러티브 읽기: 익숙함과 낯섦의 주제 (김도형)
- **출처**: https://journal.kci.go.kr/ksots/archive/articlePdf?artiId=ART002855803
- **언급**: 창 37:2~50:26 을 *야곱 가족 내러티브* 로 보고 요셉의 위치 분석
- **활용 가능 영역**: 캐릭터 정체성 — *형제 중 11번째 / 가족의 이방인* 정체성

### 1.3 추가 검색 필요 영역

- 요셉의 *trauma 경험* (애굽 노예·감옥 13년) 을 트라우마 신학 관점에서 다룬 한국 KCI 논문 — 1차 검색 미발견

## 4. 예수 (Jesus) — 복음서 + 속죄론

> **참고**: 이 MVP 는 godjinho 담당 (issue #3). 본 참고는 *그 친구가 MVP-JESUS.md 작성 시 참조* 할 자원.

### 4.1 확정 논문 (본문 fetch 완료)

#### [Y1] Trauma and Faith
- **저자**: Duck Kyu Yun (윤덕규)
- **학술지**: 한국기독교신학논총 (Korean Christian Theology Quarterly) 제81권, pp.311-328
- **연도**: 2012년 4월
- **출처**: https://kiss.kstudy.com/Detail/Ar?key=3109566
- **핵심 주장**: *"trauma paradox"* — 트라우마가 *하나님 사랑의 신뢰를 파괴* 함과 동시에 *영적 의미·목적 추구로 이끔*. 예수의 십자가·부활을 트라우마와 회복의 성서적 증언으로 봄. 트라우마는 *"신적 임재와 자비"* 가 생존자의 실존적 변화·회복을 가능케 하는 *장소* 가 될 수 있음.
- **MVP 활용**: MVP-JESUS 의 십자가 Scene 의 *트라우마 신학 footer* + R2 (가스라이팅 방지) 와 *함께* 사용. *"트라우마가 의미가 된다"* 압박 톤이 되지 않게 paradox 강조.
- **주의**: 트라우마 paradox 를 *"고난이 좋은 것"* 으로 미끄러뜨리면 R2 가스라이팅 위험. *"두 방향 모두 가능"* 으로만 표현.

#### [Y2] 몰트만의 십자가 신학에 대한 비판적 고찰 — 고난받는 하나님을 통한 희망의 발견
- **저자**: 김막미
- **학술지**: 한국개혁신학 제37권, pp.220-255
- **연도**: 2013년
- **출처**: https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001745311
- **핵심 주장**: 몰트만의 *"고난받는 하나님"* 개념 — 하나님을 *"형이상학적 무감정의 신이 아니라 정열의 신"* 으로 재해석. 십자가를 *삼위일체 사건* 으로 읽음. 임상적 함의: *고통받는 인간 경험의 신적 정당화·위로*.
- **MVP 활용**: 겟세마네 Scene 의 *"하나님이 너의 고통을 함께 느끼신다"* 메시지의 신학적 근거.
- **분쟁 지점**: *몰트만 자체에 대한 비판* — *고난받는 하나님* 이 *영원불변* 교리 / impassibility 와 충돌. 보수 진영 일부에서 우려. *MVP-JESUS disputed_points* 에 명시.

#### [Y3] 구속교리에 대한 해석학적 고찰 — 승리자 그리스도 모델을 중심으로
- **저자**: 윤철호
- **학술지**: 장신논단 (Korea Presbyterian Journal of Theology) 제44권 1호, pp.131-162
- **연도**: 2012년
- **출처**: https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001658434
- **핵심 주장**: **Christus Victor 모델** — 그리스도가 *"인간을 억압하는 독재자인 악마"* 에 승리. 이레네우스부터 그레고리 보이드까지 추적. *형벌적 대속 모델* 과 달리 *사탄의 권세에 대한 신의 승리* 강조.
- **MVP 활용**: 부활 Scene 의 *"악의 권세에 대한 승리"* 신학 톤. *형벌적 대속 단일 입장 채택 금지* 원칙 (theology-tone §5) 의 한 축.
- **분쟁 지점**: *형벌적 대속 (Penal Substitution) vs Christus Victor vs Moral Influence vs Satisfaction* — 네 모델 모두 정통 개신교 범위 안 — *MVP-JESUS disputed_points* 에 다중 모델 인정 명시
