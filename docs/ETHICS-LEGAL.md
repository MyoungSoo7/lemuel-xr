## 1. 의료기기 회피선 — 가장 중요한 법적 경계

### 1.1 한국 식약처 — 의료기기 vs 웰빙 앱

**의료기기로 분류되면**:
- 식품의약품안전처 허가 필요 (수개월~수년)
- 임상 시험 필요
- *진단·치료·예방* 표현 금지

**웰빙 앱으로 유지하려면**:
- *"진단·치료·예방* 표현 절대 금지
- *"우울증 치료"·"불안 완화"* 같은 *의학적 효과 주장 금지*

### 1.2 허용되는 표현 vs 금지 표현

| ❌ 금지 (의료적 주장) | ✅ 허용 (웰빙 표현) |
|---|---|
| 우울증을 치료합니다 | 마음을 들여다보는 데 도움 됩니다 |
| 불안 장애 완화 효과 | 평온한 시간을 가질 수 있어요 |
| PTSD 회복 프로그램 | 트라우마 기억을 *글로 옮기는* 시간 |
| 자살 충동 차단 | 어려운 마음에 *함께* 합니다 |
| 정신건강 진단 도구 | 마음의 흐름을 *관찰* 해요 |

### 1.3 모든 화면에 *고지 의무*

#### 첫 진입 시 (Screen 1.3 — 안전 안내)

```
📌 이 앱은 *치료 도구가 아닙니다*
📌 *진단·치료·의학적 조언* 을 제공하지 않습니다
📌 위급 시 1577-0199 (자살예방상담전화, 24/7)
📌 지속적 어려움이 있다면 *정신건강의학과 진료* 권장
```

→ 사용자 *체크박스 동의* 필수 (이용 약관 일부).

#### 모든 콘텐츠 끝에

화면 하단 작은 글씨:
```

   임상적 진단·치료는 의료진과 상담하세요.
```

### 1.4 전문가 추천 의무 — 트리거 조건

다음 조건 만나면 *반드시* 전문가 상담 권유:

| 조건 | 액션 |
|---|---|
| 자살·자해 키워드 매칭 (immediate) | 위기 자원 즉시 + *전문 상담 추천 카드* |
| 같은 부정 감정 (강도 7+) 3회/주 | 사용 14일 후 *"전문가 상담을 고려해보세요"* 카드 |
| 사용자가 *명시적 호소* ("죽고 싶다") | 즉시 |
| 30일 후 *회복 지표 악화* | 부드러운 권유 |

### 2.4 GDPR 대응 (글로벌 출시 시)

- *Right to Access*: 사용자가 *모든 데이터 .json 다운로드* 가능
- *Right to Erasure*: 사용자가 *모든 데이터 영구 삭제* 요청 가능
- *Right to Portability*: 다른 서비스로 *내보내기* 가능
- *Lawful basis*: 동의 (Consent) 우선

### 2.5 데이터 삭제 절차 (자세히는 DB-SCHEMA §12.2)

사용자 *모든 데이터 삭제* 요청 시:
1. 본인 확인 (디바이스 또는 OAuth)
2. 7일 *유예 기간* (마음 바뀔 시간)
3. 영구 삭제 — Cascade + 익명화 + LLM 캐시 키 정리

## 3. 종교 콘텐츠 — 균형의 윤리

### 3.1 *전도 도구 vs 회복 도구* 의 분별

이 앱은 *전도 도구* 가 아니다. *회복 도구* 다.

| 우리는 하지 않는다 | 우리가 한다 |
|---|---|
| *"예수님을 영접하세요"* 강요 | 사용자가 *원하면* 영적 묵상 제공 |
| 교회 출석 권유 | 자기 마음 들여다보기 |
| 헌금·구원 유도 | 시편·잠언으로 위로 |
| 특정 교단 우월성 주장 | 정통 신학 범위 내 *균형* |

### 3.2 비신자 보호 — 톤 설정

사용자 *톤 설정* 으로 조절:
- **신앙 강**: 성경 구절 그대로, *하나님* 명시
- **균형** (기본): 신학 + 심리 + 일반인 톤
- **약함**: *"고대 지혜"·"지혜 문학"* — 비신자 진입 가능

### 3.3 다른 종교·무신론 사용자

- *"기독교만 진리"* 식 표현 금지
- 다른 종교 *비판·폄하* 금지
- 무신론 사용자도 *비신자 톤* 으로 자기 마음 만남 가능

### 3.4 *극단적 콘텐츠* 자체 검열

- **저주 시편** (시 58, 109편 등) — 명시적 요청 시만, *해석 함께*
- **종말론·예언 해석** — 본 앱 범위 밖, 미제공
- **방언·예언·기적 약속** — 미제공

## 4. AI 환각·오용 방지

### 4.1 환각 방어 (자세히는 AI-ARCHITECTURE §10)

- 성경 본문 LLM 출력 *금지* — DB 에서만 인용
- LLM 응답에 *AI 가 생성한 것임* 명시
- 검토 절차 거친 콘텐츠만 *published* (자세히는 CONTENT-WORKFLOW.md)

### 4.2 AI 응답 *거절 권한*

사용자는 어느 화면에서든 *AI 응답을 안 받을* 수 있음:
- *"AI 묵상 생성"* 토글 OFF 가능
- *기본값 OFF* (사용자가 요청 시만 ON)

### 4.3 AI 오답 신고

콘텐츠 끝에 *피드백 버튼*:
```
이 응답 어땠어요?
👍 좋아요   🤔 어색해요   🚨 신고
```

신고된 콘텐츠는 *검토 큐* 진입, 누적 3회 시 *자동 비활성*.

## 7. 사용자 콘텐츠 — 일기·시편의 소유

### 7.1 사용자 일기·시편 = 사용자 IP

- *작성한 본문* 의 저작권은 사용자
- 운영자는 *서비스 제공 목적* 만 사용 (콘텐츠 추천·AI 묵상)
- *제3자 공유·판매 금지*

### 7.2 AI 생성물 — *공동 소유*

사용자 일기 + AI 묵상 = *사용자·운영자 공동 IP*

*공유* 기능 사용 시:
- 사용자 *명시적 동의*
- 본인 다음에 *익명화 후 공개* (Phase 3 — 익명 기도 매칭)

### 7.3 운영 후 익명화 통계 사용

운영 분석을 위해 *익명화된 집계* 데이터 사용:
- *어떤 시편이 가장 많이 추천되었나*
- *어떤 감정이 어떤 미션과 연결되나*
- *평균 회복 시간*

→ 사용자 *개별 식별 불가* 형태. 이용 약관에 명시 + 사용자 거부 옵션.

## 14. 운영 윤리 — 데이터 활용 시

### 14.1 우리는 다음을 *하지 않는다*

- ❌ 사용자 일기 본문을 *AI 모델 학습* 에 사용
- ❌ 사용자 데이터를 *제3자에 판매·공유*
- ❌ *광고 트래커* 삽입
- ❌ *심리적 약점* 을 마케팅에 이용 (예: 외로움 강한 사용자에게 *프리미엄 강매*)
- ❌ *비교·랭킹* (사용자 간 게임화) — 정신건강에 해로움

### 14.2 우리는 다음을 *한다*

- ✅ *익명화된 집계* 로 콘텐츠·UX 개선
- ✅ *사용자 명시적 동의* 후 *피드백 데이터* 자문단과 공유
- ✅ *공개적·투명* 데이터 사용 정책
