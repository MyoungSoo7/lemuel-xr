# MVP — 모세 XR 미션 상세 설계 (감정 중심)

> **담당**: [@MyoungSoo7](https://github.com/MyoungSoo7)
> **단계**: Phase 2 (요셉 MVP 검증 후 착수 예정)
> **핵심 감정 anchor**: *두려움 → 부름 → 떨림 → 책임 → 신뢰*

---

## 0. 왜 모세가 이 작품에 필요한가 — 감정의 무게

요셉의 서사가 *"풍요와 결핍의 결정"* 이라면, 모세의 서사는 **"자기 무자격감 앞에서의 부름"** 이다.

요셉은 *해석할 수 있는 사람* — 꿈을 읽고, 곡식을 분배할 줄 안다. 모세는 *해석할 수 없는 사람* — 말 더듬고, 도망자고, 신뢰받지 못한다. 그러나 그가 부름 받는다.

**이 감정의 비대칭이 사용자에게 주는 가치**:

| 사용자 상태 | 모세 서사가 제공하는 것 |
|---|---|
| *"나는 자격이 없어"* | 모세도 *"내가 누구이기에"* 라고 답함 (출 3:11) |
| *"실패해서 도망쳤어"* | 광야 40년 후에야 부름 받음 — 실패가 끝이 아니다 |
| *"두려워서 못 하겠어"* | 모세가 떨면서도 한 발 내딛는 장면 — 두려움은 사라지지 않고 *동반자가 된다* |
| *"리더가 부담스러워"* | 백성의 원망 한가운데서도 *내려놓지 않은* 모세 |

→ 요셉이 *결정의 무게* 라면, 모세는 **자기 무자격감에도 불구하고 한 발 내딛는 경험**.

---

## 1. 게임 컨셉 — *"떨기나무 앞에서"*

도망자가 부름 받고, 떨면서도 돌아서 가는 짧은 결심의 순간을 XR 로 재현.

### 핵심 메시지

> *"두려움이 사라진 후에 가는 것이 용기가 아니다. 두려운 채로 가는 것이 용기다."*
> — 모세가 사용자 안에 남기는 한 문장

### 미션 구조 (6~8분)

```
Scene 1: 광야 — 도망자의 침묵 (1분, 감정 흡수)
   ↓ [감정: 자기부정·체념]
Scene 2: 떨기나무 — 부름 (2분, XR 핵심)
   ↓ [감정: 경외 → 두려움 → 거부]
Scene 3: 다섯 번의 변명 (1~2분, 사용자 선택)
   ↓ [감정: 자기방어 → 한 발 양보]
Scene 4: 파라오 앞 — 떨림 (1~2분, XR)
   ↓ [감정: 공포 → 동행 인식]
Scene 5: 홍해 앞 — 외로운 결단 (1분)
   ↓ [감정: 책임의 무게 → 신뢰]
Scene 6: 회복 메시지 (30초)
   [감정: 안식·동반]
```

각 Scene 은 *하나의 감정* 만 다룬다. 사용자가 그 감정을 *손으로* 만지고 *몸으로* 지나가게.

## 2. Scene 별 디테일

### Scene 1 — 광야의 침묵 (감정 anchor: 자기부정·체념)

배경: 미디안 광야. 해 지는 시간. 양 떼가 멀리 있다.

사용자는 **돌 위에 앉아있다**. 손에는 *지팡이* 하나. 화면엔 *침묵*만 있고, 멀리서 양의 울음만 들린다.

40초가 지나면 한 줄 떠오름:
> *"애굽에서 도망친 지 40년이 지났다."*

그리고 또 한 줄:
> *"이제 나는 이름 없는 양치기다."*

사용자는 *아무것도 할 수 없다*. 그저 광야의 *체념* 을 체감.

**XR 인터랙션**: 없음 (의도적). 사용자가 *기다림 자체* 를 느끼게.

**감정 설계 의도**: 인생의 *지친 시기* 를 떠올리게. "나도 도망친 적 있다", "나도 광야에 있다" — 사용자 자기 인식.

**LLM 호출**: 0회. 사전 텍스트만.

---

### Scene 2 — 떨기나무 앞에서 (감정 anchor: 경외 → 두려움 → 거부)

배경: 어두워진 광야. 멀리 *불꽃이 떨고 있는 떨기나무* 가 보임. 타고 있지만 사그라들지 않는다.

사용자는 *자기도 모르게 일어선다* (자동 애니메이션). 손에 든 지팡이가 무거워진다.

**3 단계 인터랙션**:

1. **다가가기** — 사용자는 떨기나무를 향해 *직접 걸어간다* (XR locomotion: teleport 또는 smooth movement). 가까워질수록 *불꽃이 더 크게 보임*. 발걸음마다 음악 텐션 ↑.

2. **신발 벗기** — *공중에 메시지 떠오름*: "네 신을 벗으라. 네가 선 곳은 거룩한 땅이니라" (출 3:5). 사용자는 *손으로 발을 가리키며 신을 벗는 제스처*. 작은 인터랙션이지만 *몸이 기억하는 경외*.

3. **부름** — 화면에 음성 (혹은 텍스트) — "모세야, 모세야". 사용자가 *고개를 들면* 떨기나무에서 *목소리가 마음 안에서 울리는 듯한 효과* (3D 오디오).

**감정 설계 의도**:
- 경외 (불꽃이 떨고 있는데 *왜 안 타지는가*) → "지금까지 내가 보던 세상의 법칙이 깨졌다"
- 두려움 (이름이 두 번 불릴 때) → "이게 나를 향한 거구나"
- 거부 (다음 Scene 의 변명) → "왜 하필 나야"

**LLM 호출**: 0회 (모든 대사가 출 3 장 본문). 본문은 DB 에서 로드.

---

### Scene 3 — 다섯 번의 변명 (감정 anchor: 자기방어 → 한 발 양보)

배경: 떨기나무 그대로. 사용자 앞에 *5개의 카드* 가 부유 (천천히 한 장씩).

각 카드는 모세가 실제 했던 변명 (출 3:11~4:13):

1. **"제가 누구이기에"** — 자격 없음
2. **"이름이 무엇이냐 물으면"** — 권위 없음
3. **"믿지 않으면"** — 신뢰 없음
4. **"말이 둔하니"** — 능력 없음
5. **"보낼 만한 자를 보내소서"** — 마음 없음

사용자는 *각 카드를 손으로 잡고 떨기나무 쪽으로 던질지, 자기 가슴에 가져갈지* 선택.

| 행동 | 의미 |
|---|---|
| 떨기나무로 던짐 | "이건 나의 문제예요" (변명을 *내려놓음*) |
| 가슴에 가져감 | "이건 진짜 무서워요" (변명을 *고백*) |

각 카드마다 *떨기나무가 반응* — 사용자 변명을 *받아들이면서도 답을 줌* (출 4:2~4, 11~12 본문 인용). 예:
> *카드 4 ("말이 둔하니") 후* → "누가 사람의 입을 지었느냐. 내가 너와 함께하여 할 말을 가르치리라"

**사용자 선택 분기 결과**:
- 5장 모두 떨기나무에 던짐 → 결말 톤 "용기있는 결단"
- 5장 모두 가슴에 가짐 → 결말 톤 "고백한 자의 부름"
- 혼합 → "고백하며 한 발 내딛은 모세"

→ *모든 분기에서 게임은 진행된다*. 차이는 *마지막 메시지 톤*. 사용자에게 "변명해도 부름은 멈추지 않는다" 는 메시지.

**LLM 호출**: 분기별 *모세의 내면 독백* 한 줄 생성 (캐시 가능, 3 분기 × 1 독백 = 3개).

---

### Scene 4 — 파라오 앞에서 (감정 anchor: 공포 → 동행 인식)

배경: 거대한 이집트 궁전. 사용자 앞에 *파라오의 발만* 보임 (눈을 들 수 없다는 의도적 카메라).

옆에 *아론* (NPC) 이 서 있음. 사용자는 *자신의 손* 을 본다 — *떨고 있는 손* (햅틱 진동).

**핵심 인터랙션**: 사용자는 *지팡이를 던질지* 결정.

- A: 던진다 (출 7:10 — 지팡이가 뱀이 됨)
- B: 망설인다 (시간 카운트다운 5초 — 그 동안 *심장박동 사운드*)
- C: 아론을 본다 (옆에 있는 형) — *"형이 도와줄 거야"*

**모든 선택이 결국 던지게 된다** (자동 결말). 차이는:
- A: 즉시 — *결단의 모세*
- B: 망설였지만 — *떨면서도 모세*
- C: 동행자와 — *함께가는 모세*

지팡이가 뱀이 되어 파라오 앞을 가로지른다 (XR 카메라가 자동 따라감). 파라오의 표정은 *분노 + 두려움*.

**감정 설계 의도**:
- 공포 (파라오의 발만 보이는 압박)
- 동행 인식 (아론 옆에 있는 안도감) — *"혼자가 아니다"*

**LLM 호출**: 선택 후 *아론의 한 마디* 생성 (캐시 가능).

---

### Scene 5 — 홍해 앞에서 (감정 anchor: 책임의 무게 → 신뢰)

배경: 새벽. 사용자 뒤로 *수만 명의 백성* 의 그림자. 앞은 *바다*. 멀리서 *애굽 군대의 말발굽 소리*.

사용자 옆에 한 사람이 와서 말한다 (TTS — 사전 녹음 또는 캐시):
> *"애굽에 매장지가 없어서 우리를 광야에 죽게 하느냐"* (출 14:11)

사용자 앞에 *지팡이가 떠있다*. 그리고 한 줄:
> *"두려워하지 말고 가만히 서서 여호와의 구원을 보라"* (출 14:13)

**XR 인터랙션**: 사용자는 *지팡이를 들고 바다를 향해 손을 뻗는다*. 단 한 번의 결단.

손을 뻗는 순간 — *바다가 갈라진다* (3~5초의 압도적 비주얼). 사용자 발 아래로 *마른 길* 이 펼쳐진다.

→ **사용자는 걷는다** (자동 locomotion). 양 옆은 *물의 벽*. 음악이 잦아들고 *발걸음 소리만*.

**감정 설계 의도**: 책임의 무게가 *신뢰* 로 변하는 순간. 사용자는 *결정하지 않는다* — 그저 *지팡이를 든다*. 결정은 위에서 내려온다. 이것이 *모세의 핵심 깨달음*.

**LLM 호출**: 0회. 본문 + 사전 영상.

---

### Scene 6 — 회복 메시지 (30초)

사용자는 *어두운 묵상 공간* 으로 복귀. 화면에 한 줄:

> *"내가 반드시 너와 함께 있으리라" (출 3:12)*

그 아래, 사용자가 처음 입력한 감정에 매칭된 회복 문구:

| 입력 감정 | 회복 문구 |
|---|---|
| 무자격감 | *"부름은 자격을 묻지 않는다. 동행을 약속할 뿐이다."* |
| 두려움 | *"두려움이 사라진 후에 가는 것이 용기가 아니다. 떨면서 가는 것이 용기다."* |
| 외로움 | *"너 혼자 가지 않는다. 아론이 있고, 무엇보다 함께 가시는 분이 있다."* |
| 실패의 부담 | *"광야 40년이 헛되지 않았다. 그 시간이 너를 만들었다."* |

미션 종료.

## 3. XR 인터랙션 포인트

| Scene | 인터랙션 | Unity 구현 |
|---|---|---|
| 1 | 침묵의 대기 (인터랙션 없음) | 카메라 고정 + 환경 사운드만 |
| 2 | 다가가기 → 신 벗기 → 고개 들기 | XR Locomotion + Gesture (손으로 발 가리키기) |
| 3 | 5개 카드 잡기 → 던지기 / 가슴에 | `XR Grab Interactable` + 2가지 Socket (떨기나무 / 사용자 가슴) |
| 4 | 지팡이 던지기 / 망설이기 / 아론 보기 | Grab + Throw + Gaze tracking |
| 5 | 지팡이 들고 손 뻗기 | Two-handed Grab + Direction detection |
| 6 | 텍스트 응시 | World Space TextMeshPro |

**Quest 3 기본 — Apple Vision Pro 시선 응시 옵션 추가 (Scene 2 떨기나무 응시).**

## 4. 백엔드 API (요셉과 공유 — 같은 Spring Boot 앱)

| Endpoint | Method | 변경점 |
|---|---|---|
| `POST /api/game/moses/start` | POST | 캐릭터 = 'moses', Scene 1 페이로드 |
| `POST /api/game/moses/scene/{n}/decide` | POST | 5개 카드 분기 + 변명 패턴 저장 |
| `POST /api/game/moses/complete` | POST | 감정 회복 매핑 |
| `GET /api/scripture/exodus/{ref}` | GET | 출애굽기 3~14 장 본문 |

기존 요셉 API 의 hexagonal 구조 그대로 재활용. 도메인만 `moses/` 패키지로 분리.

## 7. 차별화 한 줄 (모세 MVP)

> *"두렵게 떨면서도 한 발 내딛는 7분의 경험. 무자격감을 만나는 가장 작은 의식."*

요셉이 *결정의 게임* 이라면 모세는 *순종의 의식*. 사용자가 *결정* 하지 않고 *지나가는* 것이 차별점.

---

## 8. 결정 사항 (2026-05-21 초안)

1. **타겟 디바이스**: 요셉과 동일 (Quest 3 + Vision Pro + Galaxy XR / Unity OpenXR)

2. **TTS**: 파라오 / 아론 / 백성 / 떨기나무 음성 4종 — 자체 Coqui XTTS-v2 호스팅. 떨기나무 음성은 *의도적 내레이터 톤* (직접적인 신 표현 회피).

3. **본문 번역**: 요셉과 동일 (현대인의 성경 + 개역개정 fallback). 출애굽기 3~14 장.

4. **시각화 우려 — 떨기나무 / 갈라지는 바다**:
   - 떨기나무: Unity Particle System + custom shader 로 *추상적 빛* 표현. 실사풍 회피.
   - 바다 갈라짐: pre-rendered cinematic (3~5초) 으로 비용 절감. 실시간 시뮬레이션 안 함.

5. **사용자 선택 분기 — 5개 카드의 결합 경우의 수**:
   - 2^5 = 32 분기지만, 결말 톤은 *3가지* (모두 던짐 / 모두 가짐 / 혼합)
   - LLM 캐시 3개로 커버. 미세한 카드 조합은 *Scene 6 회복 문구* 의 톤만 살짝 조정.

6. **사용자 정서 보호 장치**:
   - Scene 1 의 침묵 *건너뛰기* 버튼 (3초 후 표시) — *지친 상태* 사용자 보호
   - Scene 4 의 햅틱 진동 강도 설정 (off/약/강) — 트라우마 자극 회피

## 9. 감정 anchor 매핑 — 사용자 입력 → Scene 추천

사용자가 트랙 A 에 *감정 입력* 했을 때 *모세 미션 추천* 트리거:

| 입력 키워드 (예) | 추천 이유 |
|---|---|
| "내가 부족해", "자격 없어" | 핵심 매칭 — Scene 3 변명 시퀀스 |

## 10. 작가 노트 (작품 의도)

모세 서사를 *결정의 게임* 으로 만들면 사용자는 *답이 있는 퍼즐* 처럼 느낀다. 그래서 모세는 *결정의 무게* 가 아니라 *순종의 떨림* 으로 설계했다.

핵심 장면 (Scene 5 홍해) 에서 사용자는 *결정하지 않는다*. 손을 들 뿐. 결과는 위에서 내려온다. 이 *수동성* 이 모세 서사의 영적 핵심이다 — *내가 결정하는 게 아니라, 나는 도구다* 라는 인식.

요셉이 *적극적 결정자* 라면, 모세는 *떨면서 한 발 내딛는 자*. 두 서사가 같은 듯 다른 *영성의 두 면* 을 보여준다.

사용자는 게임을 마치고 *지팡이를 든 손의 무게* 를 기억해야 한다. 그 무게가 *부름의 무게* 이고, 그것을 *손이 기억하게* 하는 것이 이 미션의 목표다.

---

> **TL;DR** — 6분의 광야와 떨기나무, 5개 변명의 카드, 떨리는 손 끝의 지팡이. *"두렵게 떨면서도 한 발 내딛는"* 그 한 발의 무게를 사용자 안에 남긴다.
