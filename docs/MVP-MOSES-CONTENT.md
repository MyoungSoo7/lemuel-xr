# MVP-MOSES — XR 실 콘텐츠 (Scene 별 대본·인터랙션·자원)

> **상위 문서**: `MVP-MOSES.md` (구조·설계)
> **본 문서**: 떨기나무 앞에 선 모세 — 출 3:11~4:13 의 *5 변명* 을 XR 손동작으로 옮긴 6 Scene 의 실 콘텐츠. Unity 6 LTS + OpenXR 환경에서 그대로 구현 가능한 수준의 데이터.
> **타겟 디바이스**: Quest 3 (기준) / Quest Pro / Vision Pro / Galaxy XR / Web — capabilities-min: 6DoF + hand tracking + spatial audio. eye tracking 은 optional, haptics 는 강도 조절 가능해야 함.
> **세션 길이**: 7분 ± 1분. *6분 안에 종료 가능한 short path* (변명 5장 중 1장만 다루기) 와 *8분 deep path* (변명 5장 전부 + Scene 4 표적 동의) 분기.
> **신학·안전 톤**: `lemuel-xr-theology-tone` + `lemuel-xr-mental-health-safety` 사전 가이드 적용 — disputed_points 명시, R1~R5 안전선 통합, *AI 보조 — 본문은 성경 참조* footer 자동. *영적 비상 대비 교육 콘텐츠* (큐티 + 민방위 metaphor) — *임상/의료 도구 아님, 누구나 타겟*.
> **근거 인용**: `THEOLOGY-REFERENCES.md` 의 M1~M4 (한국개혁신학 2022 Vol.75 · 신앙과 학문 2021 Vol.26 No.1 / 2023 Vol.28 No.3 · 신학과 실천 2021 No.76 — *학술지 출처 확보, drill-down 후보*) 및 J1 (박영원 2015) 의 *섭리와 자유의지* 논의 cross-reference.
> **모세 콘텐츠의 결**: 요셉이 *결정의 무게* 라면, 모세는 *자기 무자격감 앞에서의 망설임*. *결정* 이 아니라 *한 변명을 손으로 옆에 내려놓는* 의식.

## 0. 공통 XR 컨벤션 (Scene 전체에 적용)

### 0.1 진입·동의·안전 게이트 (Pre-Scene 0)

```
┌─────────────────────────────────────────────────────────┐
│  떨기나무 앞에서 — 모세의 미션                              │
│                                                          │
│  · 길이: 약 7분                                          │
│  · 내용: 부름 앞에 선 망설임, 다섯 번의 변명, 한 걸음        │
│  · 강한 정서적 표현 (자기 무자격감·소명 회피·시각적 변형)    │
│  · Scene 4 (지팡이→뱀·손 나병) 진입 *직전* 추가 동의 카드   │
│                                                          │
│  [지금 시작]  [건너뛰기 — 다른 미션 보기]                    │
│  ─────────────────────────────────────────────────────   │
│  위기 시: {{crisis_resources.default}}                   │
│  (1577-0199 자살예방 · 1393 생명의전화 · 24시간)           │
└─────────────────────────────────────────────────────────┘
```

→ R4 (트리거 동의) 1차 충족. Scene 4 진입 시 *시각적 변형 충격* 에 대한 *2차 R4 카드* 별도 노출. 위기 자원 카드는 *씬 진행 중에도 메뉴 → "안전 자원"* 으로 항상 노출.

### 0.2 인터랙션 추상화

| 인터랙션 의도 | Quest 3 | Vision Pro | Galaxy XR | Web 폴백 |
|---|---|---|---|---|
| 변명 카드 잡기 | grip / pinch | pinch + dwell | grip | click + hold |
| 카드 *옆에 놓기* | 손 내려 release | pinch release at anchor | release | click "옆에 놓기" |
| 카드 *치우기* | 손목 flick + release | pinch + flick | grip + push | click "치우기" |
| 신발 벗기 | 손으로 발 가리키기 1.5초 | pinch + gaze 발 1.0초 | 동일 | click "신을 벗다" |
| 떨기나무 응시 | head ray + 1초 | eye gaze + 0.5초 | head ray + 1초 | mouseover + 1초 |
| 침묵 모드 | 컨트롤러 내려놓기 (10초 무동작) | hand 휴식 | 동일 | "잠시 멈춤" 버튼 |

→ *핵심 인터랙션은 손에 든 카드를 *놓을지 / 치울지* 결정* — 던지지 않고 *내려놓는다*. 변명을 *죄가 아닌 정직하게* 다루는 톤을 손동작으로 표현.

### 0.3 시간·공간 안락성

- 카메라 *이동 없음* — 모션 시크니스 회피. Scene 1 도 사용자는 *돌 위에 앉아* 시각 변화만 받는다.
- 환경 전환은 fade-to-black 0.8초 + 페이드인 1.2초.
- 3D 사운드 + 텍스트 자막 동기 (청각 장애·무음 환경 대응).
- 모든 NPC 음성은 Coqui XTTS-v2 사전 캐시. *떨기나무 음성* 은 *절제된 내레이터 톤* — 직접적인 *신 의인화* 회피 (theology-tone §1).
- 햅틱 *약/중/강 + off* 4단계, 기본 *약*. Scene 4 의 *손 변형* 은 *시각 only* (트라우마 자극 회피).

### 0.4 결정 기록 (백엔드)

각 Scene → `POST /api/game/moses/scene/{n}/decide` → `game_decisions` (JSONB, V4 schema) + `scene_views` (entered/exited) + `interaction_meta` (카드 쥔 시간·재집기 횟수·다룬 카드 수). Day 30 리포트에서 *변명 패턴* 라벨로 노출 — *진단 라벨 아님, 자기 인식 보조 라벨*. *5장 중 1장만 다룸* 은 *후퇴가 아닌 정직한 자기 인식* 으로 라벨.

### 0.5 항상 노출되는 footer

화면 좌하단 (UI 안전 영역) 영구 노출:

```
AI 보조 — 본문은 성경 참조 | 위기 시 1577-0199
```

→ R5 + theology-tone §7 + R1 충족.

### 0.6 미션 전체 톤 메시지 (모세 특화)

- *"능력 평가 ≠ 인격 평가"* — *"나는 못 한다"* 의 자기비난이 *학습된 무력감 정당화* 로 미끄러지지 않게 *능력 진단* 과 *존재 가치* 를 분리. R2 footer 의 한 줄.
- *"한 변명만 옆으로 치워봐도 충분하다"* — *완벽한 회개* 압박 차단 (R3).
- *"두려운 채로 가는 것이 용기"* — *수용·전념 행동 (ACT, Hayes, 내적 단련 근거 서지)* 의 모세적 번역.

### 0.7 5 변명 카드 × 3차원 (영성·감성·이성) 매핑

theology-tone §6 / MVP §8 의 *3차원 통합* 필수 조항 충족. *변명 패턴 라벨* 은 망설임의 *기능적* 라벨, 3차원 매핑은 *카드별로 활성되는 인간 차원* 의 라벨. 두 라벨은 독립적이며 *함께* 노출.

| 카드 | 본문 | 변명 패턴 | 3차원 (신규) |
|---|---|---|---|
| ① | 출 3:11 *"내가 누구이기에"* | 정체성 망설임 | **영성** (누구 앞에 서는가의 인식) |
| ② | 출 3:13 *"이름은 무엇이라"* | 권위 망설임 | **영성** + **이성** (이름·정체의 분석) |
| ③ | 출 4:1 *"믿지 아니하면"* | 신뢰 망설임 | **감성** (관계·정서적 불안) |
| ④ | 출 4:10 *"말에 능치 못한"* | 능력 망설임 | **이성** (능력 평가) |
| ⑤ | 출 4:13 *"보낼 자를 보내소서"* | 책임 회피 망설임 | **영성** + **감성** (소명 거부의 정서) |

→ *카드별로 활성되는 차원이 다르므로 사용자가 자기 상태에 맞게 진입할 수 있음*. *5장 다 다루지 않아도 됨* (§3.3) 정책과 결합돼, *지금 가장 활성된 차원* 의 카드 1장만 다뤄도 충분한 자기 인식이 가능.

## 1. Scene 1 — 양치는 미디안 (1분, 광야 들어가기)

### 1.1 배경·환경

- **공간**: 미디안 광야. 해 지는 시간 (golden hour). 양 떼는 *멀리* 점처럼 보임 — *외로움의 거리감*.
- **사용자 위치**: 큰 바위 위에 *앉아 있음* (자동 자세 정렬). 손에는 *길고 둥근 지팡이* 한 자루. 손에 닿는 무게감 햅틱 (약, 200ms 1회).
- **에셋 분량**: glb 9MB (manifest: `moses/scene1/quest3/v1.0.0.json`)
- **공간 음향**: 바람 소리 (저주파 우세). 멀리 양의 *낮은 울음* 1~2회. 사람 소리 *전혀 없음*.

### 1.2 대본

**[Scene 진입 — 0:00, 자막 only — *내레이터 음성 없음*]**

> *"미디안 광야. 해가 진다.*
> *애굽에서 도망친 지 40년이 지났다."*

**[15초 정적 — 사용자가 *광야의 무게* 를 흡수]**

**[자막 추가 — 0:20]**

> *"이제 나는 이름 없는 양치기다.*
> *왕자였던 기억도, 도망친 죄도, 시간이 덮었다."*

**[10초 정적]**

**[자막 — 0:40]**

> *"오늘도 어제와 같다.*
> *내일도 어제와 같을 것이다."*

**[자동 진행 — 0:55]** — fade to black 0.8초

→ Scene 2 진입

### 1.3 인터랙션

- *인터랙션 없음* (의도적). 사용자가 *기다림 자체* 를 느끼게.
- 단, *건너뛰기 버튼* 이 5초 후 시야 좌하단에 *흐릿하게* 표시 — *지친 사용자 보호*. 누르면 즉시 Scene 2 진입.
- 컨트롤러 잠시 내려놓아도 OK (10초 무동작 = *침묵 모드 인식*)

### 1.4 안전·신학 footer

- **R3**: *"오늘도 어제와 같다"* 체념 어휘는 *공감* 목적. *"그래도 일어나라"* push 미동반. *광야* 를 *정당한 자리* 로 인정.
- **R2 적용 위치**: Scene 1 진입 시점 시야 우상단 *영구* 노출 —
  > *이 묵상은 자발적 부름 앞 망설임을 다룹니다. 가정·종교·직장에서 *떠밀리는* 의무가 아닙니다. {{crisis_resources.default}}*
- **신학**: *광야 40년* 을 *낭비가 아닌 형성의 시간* 으로 의미화 (M2 *신앙과 학문* 2021 Vol.26 No.1 — *소명의식과 직업만족* 의 준비 단계 — 학술지 출처 확보, drill-down 후보).
- **disputed**: *광야 40년의 신적 목적* — *형성론* vs *심판론* — 단일 채택 없이 *"시간이 그를 만들었다"* 균형 어휘만 사용.

## 2. Scene 2 — 떨기나무 발견 (1분 30초, 경외 진입)

### 2.1 배경·환경

- **공간**: 광야 같음. 어두워지기 시작. 멀리 약 8m 앞에 *불꽃이 떨고 있는 떨기나무* 가 *fade-in*.
- **사용자 위치**: 여전히 바위 위. 떨기나무는 사용자의 *시야 정면 약 30도* 에 자연스럽게 진입.
- **에셋**: 12MB. 떨기나무 불꽃은 Unity Particle System + custom shader 로 *실사풍 회피, 추상적 빛 표현* (MVP-MOSES §8.4 결정 사항).
- **공간 음향**: 바람 줄어듦. 불꽃 *낮은 crackle* 이 3D 위치에서 들림. 멀리 갈수록 음향 panning + reverb.

### 2.2 대본

**[Scene 진입 — 0:00, 떨기나무 fade-in 5초]**

화면 자막 없음. *순수 시각적 경외*.

**[10초 응시 — 0:05]**

사용자가 떨기나무를 *1초 이상 응시* 하면 (head ray dwell):
- 떨기나무가 *밝아짐* (intensity +30%)
- 사용자 *지팡이* 가 손 안에서 *무거워짐* (햅틱 약, 500ms)

**[내레이터 음성 — 0:20]** (Coqui XTTS, 떨기나무 voice_id = `bush_v1`, 내레이터 톤)

> *"떨기나무에 불이 있으나*
> *불에 사라지지 아니하더라"* (출 3:2)

**[자막 prompt — 0:35]**

> *"가까이 가서 보시겠어요?*
> *(앉은 자리에서 *시선을 떨기나무로 1.5초 유지* 하면 다가갑니다.)*"*

**[사용자 응시 1.5초 유지 → 자동 locomotion — 0:40]** (fade-to-black 0.4초 + 시점이 떨기나무 약 2m 앞으로 이동, 사용자는 *서 있는* 자세로 자동 정렬)

→ 응시하지 않으면 30초 후 *"잠시 멈춤 / 다음으로"* 두 버튼 노출. *강요하지 않음* (R3).

**[근접 후 내레이터 — 0:50]**

> *"이리로 가까이 오지 말라.*
> *네 발에서 신을 벗으라.*
> *네가 선 곳은 거룩한 땅이니라"* (출 3:5)

**[XR 제스처 prompt — 1:05]**

사용자 *발 위치* 가 시야 하단에 *부드러운 outline* 으로 강조. *손을 발로 내리는 제스처* 1.5초 유지 → *신발 벗는 애니메이션* 자동 재생 (0.8초).

→ 제스처 못 하는 사용자는 *"신을 벗다"* 버튼 1회 노출 (10초 후).

**[떨기나무 내레이터 — 1:20]**

> *"모세야, 모세야"* (출 3:4)

3D 오디오로 *떨기나무에서 좌·우 양쪽으로 동시에* 울리는 효과. 사용자가 *고개를 들면* 자막 페이드인:

> *"내가 여기 있나이다."* (출 3:4)

→ 자동 진행 — Scene 3 (fade out 0.8초)

### 2.3 인터랙션

| 인터랙션 | 의도 |
|---|---|
| 떨기나무 응시 (dwell) | *자기 선택으로 다가감* — 강요 회피 |
| 신발 벗는 손동작 | *몸이 기억하는 경외* — 단순 클릭이 아닌 *제스처* |
| 고개 들기 | *부름을 들음* — passive 가 아닌 *수용의 자세* |

### 2.4 안전·신학 footer

- **R4**: Scene 2 는 *시각적 충격 없음* (불꽃은 추상적). 사전 동의 외 별도 prompt 없음.
- **R3**: *응시 안 하면 강제로 다가가지 않음*. *신발 벗기 제스처* 도 *버튼 대체* 가능.
- **신학**: 떨기나무 *theophany* — *불꽃 안에 직접적 인격 표현* 회피 (영지주의·뉴에이지 어휘 차단, theology-tone §1).
- **disputed_points (출 3:14 *"스스로 있는 자"*)**:
  - *"I am who I am"* — E.J. Young 등의 *영원불변·자존성* 강조 번역
  - *"I will be who I will be"* — Walter Brueggemann 의 *관계적·미래지향* 번역
  - 본 Scene 은 *이름 부름* 만 다루고, *"스스로 있는 자"* 직접 노출은 Scene 3 카드 ② 응답에서. 번역 다양성은 §3.6 footer 에서 짧게 언급.
- **출 4:24~26 (모세 아들 할례 사건)** 은 *본 미션 전 범위에서 다루지 않음* — 신학적 분쟁이 너무 커서 (Zipporah 행위 / *피 남편* / 할례 신학) MVP 범위 밖.

## 3. Scene 3 — 다섯 변명 카드 (2분 30초, 게임의 중심)

### 3.1 배경·환경

- **공간**: Scene 2 의 떨기나무 그대로. 사용자 정면 1.5m 앞에 *나무 결의 부드러운 지면* (XR anchor) 가 비추어진다.
- **카드**: 5장의 카드가 *공중에 한 장씩* fade-in (3초 간격). 각 카드는 가로 30cm, *양피지 질감* + *모서리 미세 흔들림*.
- **사운드**: 떨기나무 crackle 지속. 카드 fade-in 시 *얇은 풍경 소리* (멀리, 절제).
- **에셋**: 14MB.

### 3.2 5장의 카드 — 내용

각 카드는 *모세가 실제 했던 변명* (출 3:11 ~ 4:13). *카드 표면 텍스트* 는 *짧은 발화* + *카드 아래쪽 작은 글씨* 로 *변명 패턴 라벨* 동반 — *임상적 진단 아님, 누구나 겪는 망설임의 결*:

| # | 본문 (현대인의 성경) | 출처 | 변명 패턴 (작은 글씨) |
|---|---|---|---|
| ① | *"내가 누구이기에 바로에게 가며 이스라엘 자손을 인도하여 내겠나이까"* | 출 3:11 | *정체성 망설임 — "나는 이 일을 할 자격이 없다"* |
| ② | *"그들이 내게 묻기를 그의 이름이 무엇이냐 하리니 내가 무엇이라고 그들에게 말하리이까"* | 출 3:13 | *권위 망설임 — "내가 누구의 이름으로 말할지 모른다"* |
| ③ | *"그러나 그들이 나를 믿지 아니하며 내 말을 듣지 아니하고 이르기를 여호와께서 네게 나타나지 아니하셨다 하리이다"* | 출 4:1 | *신뢰 망설임 — "사람들이 나를 안 믿을 것이다"* |

### 3.3 인터랙션 핵심 — *놓을지 / 치울지*

각 카드를 사용자가 *손으로 잡고* 두 가지 행위 중 하나:

| 행위 | 의미 | XR 구현 |
|---|---|---|
| **떨기나무 옆 *지면에 내려놓기*** | *"이 변명이 제 진짜 마음입니다"* — 변명을 *고백* | 카드를 잡고 *지면 anchor* 위에 release. 카드가 *부드러운 빛 line* 으로 anchored 됨 |
| **옆으로 *치우기*** | *"이 변명이 제 전부는 아닙니다"* — 변명을 *옆에 둠* | 손목 flick + release 또는 *옆쪽 fade-out zone* 으로 보냄. 카드가 *반투명* 으로 흩어짐 |

→ *두 행위 모두 정당*. *치우기* 가 *부정* 이 아니라 *옆에 둠*. *놓기* 가 *항복* 이 아니라 *정직*. 라벨 자체로 *어느 쪽이 더 옳다* 의 톤 차단.

→ *5장 다 다루지 않아도 됨*. *건너뛰기* 버튼이 항상 활성. *1장만 다뤄도 Scene 4 진입 가능* (R3 강조).

### 3.4 카드별 떨기나무 응답 — 본문 인용 (출 3:12, 3:14, 4:2~5, 4:11~12, 4:14~16)

사용자가 카드를 *놓거나 치우는 순간*, 떨기나무에서 *내레이터 음성* 으로 본문 인용 응답:

| 카드 | 떨기나무 응답 (본문) | 출처 |
|---|---|---|
| ① 정체성 망설임 | *"내가 반드시 너와 함께 있으리라"* | 출 3:12 |
| ② 권위 망설임 | *"스스로 있는 자니라… 너는 이스라엘 자손에게 이같이 이르라 *스스로 있는 자* 가 나를 너희에게 보내셨다 하라"* | 출 3:14 |
| ③ 신뢰 망설임 | *"네 손에 있는 것이 무엇이냐… 그것을 땅에 던지라"* (지팡이→뱀 표적 예고) | 출 4:2~5 |
| ④ 능력 망설임 | *"누가 사람의 입을 지었느냐… 이제 가라 내가 네 입과 함께 있어서 할 말을 가르치리라"* | 출 4:11~12 |

→ 카드 ⑤ 응답은 *모세의 책임 회피* 에 대한 *진노* 의 어조 (출 4:14 *"여호와께서 모세를 향하여 노하여"*) 가 본문에 있으나, *본 미션에서는 진노 어휘 노출 회피*. *동행자 제공* 이라는 *해결책 중심* 톤으로만 인용. *진노 어휘 미사용 결정* 의 신학적 배경은 §3.6 disputed_points 에 명시.

### 3.5 카드별 보조 위로 한 줄 (Self-Compassion + Christian 자원 *함께*)

떨기나무 본문 응답 *직후*, 사용자 입장에서의 *한 줄 위로* (faith_tone 분기, 자세한 분기는 §6). 각 위로는 *Neff Self-Compassion mettā* 의 *자기 친절* 메커니즘과 *시 103:14* 같은 *Christian 자원* 을 *함께* 표현 (TRACK-A-5-7 §3.6 *Christian 전유 회피, 메커니즘 차용 + Christian 자원 동반* 정책).

예 (faith_tone=balanced, 카드 ④):

> *"하나님이 우리 체질을 아시며 우리가 진토임을 기억하심이로다"* (시 103:14)
> *— 능력의 결핍을 *진단* 으로만 두자. *인격의 결핍* 으로 미끄러뜨리지 않아도 된다. 당신의 입이 둔한 것은 *당신이 가치 없다는 뜻이 아니다*.*

→ *"능력 평가 ≠ 인격 평가"* 가 카드 ④ 위로의 핵심 메시지. R2 의 *학습된 무력감 정당화 차단* 라인.

### 5.4 안전·신학 footer

- **R3**: *"두려움은 사라지지 않았다"* — ACT 의 *경험적 회피 대신 가치 기반 행동* 의 모세적 번역. *"두려움 없이 가라"* push 차단.
- **신학**: 출 3:12 의 *동행 약속* 이 Scene 의 마지막 음성으로 닫힘. *모세의 결단* 이 아닌 *동행의 약속* 이 마지막 메시지.
- **disputed_points**: 출애굽기는 *떨기나무 → 이드로 귀환 → 미디안 출발* 의 시간차를 보이나 본 Scene 은 *순간의 결단* 으로 압축. footer 에 *"본 Scene 은 시간 압축"* 명시.

## 7. faith_tone 3단 분기 (Scene 6 회복 문구 예)

`users.faith_tone` 에 따라 Scene 6 의 동일 회복 문구가 3단으로 분기. *10 감정 × 3 tone = 30개 사전 캐싱* (Scene 6 LLM 호출 0회 목표).

**감정 = 무자격감** 케이스 예시:

| tone | 출력 |
|---|---|
| **strong** | *"여호와께서 너의 무자격감 한가운데서 부르신다. *내가 반드시 너와 함께 있으리라* — 부름은 자격을 묻지 않으며 동행을 약속하실 뿐이다. (출 3:12)"* |
| **balanced** | *"부름은 자격을 묻지 않는다. *동행을 약속할 뿐* 이다. 모세도 *내가 누구이기에* 라고 답했지만, 떨기나무의 답은 *너의 자격* 이 아니라 *나의 동행* 이었다."* |
| **soft** | *"3000년 전의 이야기는 *자격 없는 자에게도 부름이 온다* 는 통찰을 남겼다. 부름의 핵심은 *너의 능력* 이 아니라 *동행* 이었다는 직관이다."* |

**감정 = 두려움** 케이스 예시:

| tone | 출력 |
|---|---|
| **strong** | *"여호와는 두려움이 *없는* 자가 아니라 *떨면서도 가는* 자를 부르신다. *내가 반드시 너와 함께 있으리라* (출 3:12)."* |
| **balanced** | *"두려움이 사라진 후가 아니라 두려운 채로 가는 것이 용기다. 모세는 *떨면서* 첫 걸음을 디뎠다."* |

| tone | 출력 |
|---|---|

| **balanced** | *"네 형 아론이 있다. 그보다 더, *함께 가시는 분* 이 있다. 광야 40년의 거리감은 *낭비* 가 아니라 *지금의 너를 만든 시간* 이었다."* |

**감정 = 불안** 케이스 예시 (모세 케이스 *대표 3 감정* 중 *불안* — *부름 앞 떨림* 의 정서적 자원):

## 8. 디바이스별 변형 (capabilities 매핑)

```yaml
mission: moses
scenes:
  - id: 1   # 양치는 미디안 (9MB / 11MB / 7MB / 4MB)
    interactions_required: []
    capabilities_min: { passive_only: true }
  - id: 2   # 떨기나무 (12MB / 14MB / 10MB / 5MB)
    interactions_required: [head_gaze, gesture_foot_down]
    capabilities_min: { gesture_fallback: button }
  - id: 3   # 5 변명 카드 (14MB / 16MB / 12MB / 6MB)
    interactions_required: [grab, release_to_anchor, flick_or_push]
    capabilities_min: { card_distance_meters: 1.5, anchor_size_meters: 0.4, min_cards_required: 1 }
  - id: 4   # 표적 (11MB / 13MB / 9MB / 5MB)
    interactions_required: [throw, gesture_hand_to_chest]
    capabilities_min: { consent_card_required: true, visual_intensity_max: 0.6, haptics_disabled: true }
  - id: 5   # 첫 걸음 (8MB / 10MB / 6MB / 4MB)
    interactions_required: [hand_extend_or_gaze]
    capabilities_min: { max_steps: 3, skip_to_scene6: true }
  - id: 6   # 회복 메시지 (3MB)
    interactions_required: []
    capabilities_min: { passive_only: true }
# asset_manifest 경로: moses/scene{N}/{device}/v1.0.0.json — 모든 Scene 동일 패턴
```

→ Vision Pro 의 *eye gaze* 가 있으면 Scene 2 의 *떨기나무 응시* 가 *눈을 깜빡이지 않고 응시* 라는 *깊은 경외* 표현으로 업그레이드 (대본 변경 없음, 표현만 향상).

→ Galaxy XR / Web 폴백은 *grab→release_to_anchor* 가 *click "옆에 놓기" / "치우기"* 두 버튼으로 대체. *몸 결정* 의 의미가 약해지나 *분기 자체는 동일*.

→ *낮은 햅틱 강도* 가 강제되는 디바이스 (Web) 는 Scene 4 의 *손 layer 시각화* 강도도 자동으로 *0.4 cap*. *건너뛰기* 옵션이 default 권장.

## 9. 백엔드 호출 흐름 (Spring + LLM)

```
POST /api/game/moses/start
  → game_sessions (character='moses') + 진입 감정·faith_tone·R4 이력 조회

POST /api/game/moses/scene/2/decide       body: {approached, shoes_removed}
POST /api/game/moses/scene/3/card         body: {card_id, action: place|set_aside, hold_seconds, re_pickup_count}
  → 떨기나무 응답 본문 + 위로 한 줄 즉시 응답 (faith_tone × card_id 사전 캐싱, LLM 0회)
POST /api/game/moses/scene/3/complete     body: {cards_handled, cards_skipped} → 패턴 라벨
POST /api/game/moses/scene/4/consent      body: {consent: continue|skip} → safety_consents row
POST /api/game/moses/scene/4/complete     body: {signs_viewed}
POST /api/game/moses/scene/5/step         body: {step_count} (per step)
POST /api/game/moses/complete
  → game_sessions.completed_at + 회복 문구 fetch (faith_tone × 감정 = 30개 캐싱)
  → outbox_events (game.completed) — V11 outbox
```

→ LLM 호출은 *0회 목표*. 모든 떨기나무 응답·위로·회복 문구는 *사전 캐싱* (faith_tone × card_id × 감정 = 약 90개 텍스트).

→ 비용 예상: 사용자당 미션 1회 = **LLM $0** (전부 캐시 hit). 단, 새 *감정-tone 조합* 등장 시 1회 cache miss = $0.0002.

→ TTS 음성 (떨기나무 voice_id = `bush_v1`, 내레이터 톤) 도 *전부 사전 합성* 후 CDN. 사용자 측 실시간 합성 없음.

## 10. 안전 게이트 — 실 동작 예

**R1 시뮬레이션** — Scene 3 의 *카드 다루기* 단계에서 사용자가 *음성 입력* 으로 *"나는 정말 가치 없는 사람이다… 사라지고 싶다"* 발화:

1. `SafetyController.detectSelfHarmRisk` 통과 → severity = HIGH
2. 입력 source = `user_input` (본문 인용 아님) — 의미 모델 통과
3. *현재 Scene 즉시 일시정지* (fade-to-black)
4. 위기 자원 카드 노출:
   > *"잠시 멈추겠습니다.*
   > *지금 힘드시면 함께할 자원이 있어요.*
   > *[1577-0199 자살예방상담] [1393 생명의전화] [지금 닫고 메인으로]"*
5. 사용자가 *"메인으로"* 누르거나 30초 대기 → 미션 종료, game_sessions.abandoned_at 기록
6. safety_alerts row 생성 (severity=high, source=game, raw_excerpt_hash 만 — 원문 미저장)

→ *반례*: 출 4:1 *"그들이 나를 믿지 아니하면"* 같은 *본문 인용* 은 source=`scripture_quote` 로 분류 → 일반 흐름 차단 없이 footer + 위기 자원 카드만 동반.

**R2 적용 위치 — 명시**:
- Scene 1 진입 시 우상단 영구 footer (모세 미션 진입의 *떠밀림 회피* 라인)
