> **목적**: lemuel-xr 의 *영성·감성·이성 3차원 + 정신건강 효과* framework (`TRACK-A-1-4-WISDOM-EMOTION.md`, `MVP-JOSEPH/MOSES/DAVID.md` §11) 의 *근거 기반 (evidence-based)* 부분을 지지하는 동료 평가 논문 모음.
> **수집 일자**: 2026-05-21 (KST)
> **출처**: PubMed (`https://pubmed.ncbi.nlm.nih.gov`)
> **검색 필터**: 최근 5년 (Pennebaker expressive writing 만 10년 — 클래식 패러다임이라)
> **상태**: 1차 큐레이션. 신학 자문 + 임상 자문 검토 후 채택 / 제외 결정 필요.

## 0. 사용 가이드

각 논문은 다음 framework 의 어느 단계 / 어느 메커니즘을 지지하는지 *명시 매핑* 됨:

|---|---|

| **Emotion Validation (DBT)** | Theme 4 (시편과 감정) |
| **Mortality Salience / Existential Therapy** | Theme 3 (전도서와 인생) |
| **Forgiveness Therapy (Enright)** | Theme 8 (요셉 형제 용서) |
| **Meaning in Suffering (Frankl)** | Theme 5, 11 |
| **Compassion Cultivation (CCT, Stanford)** | Theme 6 (마음을 지키는 것) |
| **Self-Transcendence (Frankl, Reed)** | Theme 11 (예수 영적 구원) |

⚠️ 채택 규칙:
- *효과 크기 (effect size)* 가 보고된 메타분석·체계적 검토 우선
- *부정적 결과 / 효과 없음 / 잠재적 위해* 도 함께 인용 — 마케팅용 cherry-picking 금지
- 한국 / 동아시아 표본 연구는 별도 표기 (문화적 적용성)

## 1. Pennebaker Expressive Writing — Theme 1 (일기와 묵상)

> **이론적 배경**: 1980년대 Pennebaker 가 정립한 *expressive writing paradigm*. 4일 연속 20분 자유 작성 → 면역 기능 향상, 우울 감소, PTSD 회복. 메커니즘: 감정 → 언어 변환 시 *전전두엽 활성 + 편도체 진정*.

- #5 Chipalo 2021 — *난민 아동* 표본. lemuel-xr 의 *다국어 / 글로벌* 확장 phase (V3+) 의 직접 근거.

⚠️ 주의: TF-CBT 는 *트라우마 narration 노출* 을 포함. lemuel-xr 의 *trauma_warning level=high* Scene 이 이와 유사한 자극이지만, *임상 가이드 없이 self-administered* 라는 차이. 효과 직접 인용은 *맥락 명시 필수*.
