## 1. 4 인물의 절망의 결 + 회복의 결

각 인물 = 절망의 *결* 1개 + 회복으로 가는 *영적 가치* 2~3개.

| 인물 | 절망의 결 | 회복의 영적 가치 (2~3) |
|---|---|---|
| **요셉** | 형제 배신 · 노예 · 13년 옥살이 · 억울한 누명 | **신중함**(꿈을 해석하고 7년 저장) · **꾸준함**(13년 옥에서도 능력 발휘) · **용서**(형제 재회 시 정체 밝힘) |
| **모세** | 광야 40년 도피 · 무자격감 · 짊어진 백성의 원망 | **인내**(40년 양치는 기다림) · **동행 인식**(혼자 아닌 아론) · **떨면서도 한 발**(파라오 앞 두려움) |
| **다윗** | 형의 멸시 · 사울의 추격 · 시편 비탄의 자리 | **솔직함**(시편 모든 감정을 토로) · **회개**(나단 앞에서) · **작음을 인정한 능동**(사울 갑옷 벗기) |
| **예수** | 광야 시험 · 겟세마네 고뇌 · 십자가 외침 | **내려놓음**("뜻대로 마옵시고") · **사랑**(원수까지) · **부활의 소망**(죽음 너머) |

→ **공통 패턴**: *절망의 자리* 가 곧 *영적 성숙의 자리*. 절망을 *피하는* 것이 회복이 아니라 *통과* 하는 것이 회복.

## 2. AR 1~7 가치 — 일상 영적 양식

| # | 주제 | 한 줄 정의 | 일상 형식 |
|---|---|---|---|
| 1 | **일기와 묵상** | 오늘 일어난 일을 *솔직히* 적는 자기 표현 | 5분 자유 기록 + AI 묵상 응답 (옵션) |
| 2 | **잠언과 지혜** | 결정 어려운 상황에 *옛 지혜* 카드 한 장 | 상황 한 줄 입력 → 매칭 잠언 + 재구조화 워크 |
| 3 | **전도서와 인생** | 허무·공허에 *인생의 계절* 인정 | 오늘의 계절 (전 3:1-8 중) 선택 + 짧은 노트 |
| 4 | **시편과 감정** | 슬픔·분노·기쁨을 *시* 로 토로 | 감정 선택 → 매칭 시편 낭독 + 사용자 시편 작성 |
| 5 | **욥과 진리** | 고통을 *말할 자유* | 무거운 감정 인정 + 답이 아닌 자리 (욥 38) |
| 6 | **마음 지키기** | 일상의 *호흡·경계 설정* | 잠 4:23 + 1분 호흡 + 오늘의 마음 점수 |
| 7 | **사람 두려워하지 않기** | 대인 공포의 *작은 실천* | 사 51:7 + 오늘의 작은 도전 1개 (실천 일기) |

→ **공통**: *짧은 일상 의식* — 5분 이내. *큐티 톤* — 본문 + 묵상 + 적용.

## 4. *사용자 여정* — 일주일 코스

각 인물 VR 미션 = *그 주의 일일 1~7 가치* 와 연계.

```
Week 1 — 요셉의 신중함·꾸준함
  Mon: VR 요셉 Scene 1~2 (꿈 해석 / 저장 결정)  · AR 1 일기 — "오늘 신중해야 할 결정 하나"
  Tue: VR 요셉 Scene 3 (분배)                  · AR 2 잠언 — "결정의 잠언 한 장"
  Wed: -                                       · AR 1 일기 + AR 2 잠언 (혼자)
  Thu: VR 요셉 Scene 4 (형제 재회)              · AR 7 사람 — "용서할 한 사람"
  Fri: VR 요셉 Scene 5 (결말)                  · AR 6 마음 — "흔들리지 않을 한 자리"
  Sat: 자기만의 가치 1개 적기 — *내 신중함 가치*  (Value Builder)
  Sun: 한 주 회고 + 다음 인물 (모세) 예고

Week 2 — 모세의 인내·동행
  ... (반복 구조)
```

4주 = 4 인물 = 사용자 *자기 7 가치 초안* 완성.

## 5. *자기만의 7 가치 빌더* — 백엔드 모델

사용자가 lemuel-xr 의 *1~7 기본 정의* 를 그대로 쓸 수도 있고, *자기 언어로 7개를 다시 정의* 할 수도 있다.

### DB (V20260522 마이그레이션)

```sql
CREATE TABLE user_value_profiles (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    -- 7 가치 = JSON. 키 1~7 고정, value 는 사용자 정의 텍스트 + 매핑된 인물·본문.
    -- 예: {"1": {"title": "흔들리지 않는 결정", "anchor_character": "joseph", "anchor_scripture": "gen-41:33"}, ...}
    values_json     JSONB NOT NULL,
    started_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    last_updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (user_id)
);

CREATE TABLE user_value_practices (
    id              BIGSERIAL PRIMARY KEY,
    user_id         UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    value_id        SMALLINT NOT NULL CHECK (value_id BETWEEN 1 AND 7),
    practiced_at    TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    duration_sec    INTEGER,
    note            TEXT,
    -- 어떤 인물 미션과 연계됐는지 (옵션)
    linked_character VARCHAR(20)
);
CREATE INDEX idx_practices_user_value_time ON user_value_practices(user_id, value_id, practiced_at DESC);
```

### API

| Endpoint | 용도 |
|---|---|
| `GET /api/values/me` | 본인의 7 가치 프로파일 + 최근 7일 실천 통계 |
| `POST /api/values/profile` | 7 가치 정의 (전체 또는 부분 갱신) |
| `POST /api/values/practice` | 오늘의 실천 1건 기록 (value_id 1~7) |
| `GET /api/values/streak` | 가치별 연속 실천일 (streak) |

## 6. 메트릭 — *Civil Defense Readiness Index*

영적 비상 대비 *준비도* 를 추적하는 자체 지표 (PHQ-9 같은 임상 진단 도구 X). Grafana 대시보드 Row 3 의 새 패널:

```
CDR Index = (지난 7일 실천 횟수 / 49) × 100      (49 = 7 가치 × 7일)
            + (방문 streak 보너스 5점/주)
            - (위기 lockout 발생 시 -10점, 즉시 회복 자원 안내)
```

→ 사용자가 *민방위 등급* 처럼 *영적 비상 대비 등급* (1~5) 으로 자기 상태 확인.

- 5점 (매우 준비됨) : CDR > 80
- 3~4점 (보통)      : CDR 50~80
- 1~2점 (보강 필요)  : CDR < 50

*경쟁* 아니라 *자기 점검*. 다른 사용자와 비교 X — 익명성 보존.
