# Track A · Theme 5~7 설계 — 영적 비상 대비 훈련의 행동 지침

> **트랙**: A (정적 회복 콘텐츠 — 누구나, *결정·관계·자기 보호* 가 필요한 순간 트리거)
> **포지셔닝**: 임상/의료 도구 X. *영적 비상 대비 교육 콘텐츠* — *큐티 + 민방위훈련* metaphor. 절망이 오기 전 *미리* 단련하는 자리.
> **범위**: 고통과 진리 (욥기) · 마음 지키기 (잠 4:23) · 사람 두려워하지 않기 (잠 29:25, 사 51:7)
> **설계 원칙**: 1~4 가 *내면 들여다보기* 라면, 5~7 은 *밖으로 한 걸음 디디기*. 영성·감성·이성 3차원 × 성경 인물의 절망 극복 서사 × 5개 안전선 (R1~R5) 사전 적용. AI 역할은 *임상 전문가가 아닌 storyteller*.

## 0. 왜 5~7 을 묶었나

| Theme | 위치 | 내적 단련 메커니즘 |
|---|---|---|
| 5. 고통과 진리 (욥기) | 의미 찾기 직전의 *분노 단계* | 의미 재구성, 외상 후 성장 서사 (학자 참고는 footer 서지 참조) |
| 6. 마음을 지키는 것 (잠 4:23) | *경계 (boundary)* 형성 | 자기 친설·한계 설정·의도된 멈춤 (footer 서지 참조) |
| 7. 사람을 두려워하지 않기 (잠 29:25, 사 51:7) | 사회 불안·평가 두려움 | 인지 재구조화·평가 두려움 다루기 (footer 서지 참조) |

→ **주의**: 5~7 은 *행동 지침* 이라 *압박 톤* 으로 흐를 위험이 가장 큰 영역. R3 (회복 압박 회피) 가 특히 엄격하게 적용된다.

## 1. 공통 framework — 영성·감성·이성 × *행동의 안전성*

5~7 은 *행동* 을 끌어내는 도구라 *부적절한 상황에서 행동 지침이 가스라이팅이 되는 위험* 이 가장 크다. 작성 시 다음을 *기본값* 으로 둔다:

- **자기 처방 차단**: AI 가 *"이렇게 하세요"* 라고 명령형으로 답하지 않는다. 사용자는 storyteller 가 들려주는 서사를 듣고 *스스로 선택* 한다.
- **피해 상황 사용자가 안전하게 머물 수 있게**: 가정폭력·종교적 학대·정신적 학대 같은 *피해 상황* 에 있을 수 있는 사용자에게 *"참아라" / "마음을 지켜라" / "사람 의식하지 마라"* 를 *그대로* 보여주지 않는다 → R2 footer 강제. 누구나 들어오는 채널이라 *어떤 상황에 있는지 우리는 알 수 없다* 는 전제로 디자인.
- **의지력 신화 금지**: *"믿음으로 / 마음으로 / 의지로"* 만으로 해결되는 듯한 표현 차단. *외부 자원* 항상 동반 가능.
- **위기 자원은 catalog 참조 (hardcode 금지)**: footer·종료 카드·진입 카드의 위기 번호는 *모두* `crisis_resources` 테이블 (V7 migration) 에서 i18n + 대상별로 동적 조회. 본문에는 `{{crisis_resources.default}}` 같은 토큰만 박는다. 한국 catalog 매핑:
  - **자살·자해 키워드 발화 일반** → 109 (자살예방 상담전화) + 1577-0199 (정신건강위기상담) — *법적 의무 라우팅*
  - **청소년 (만 9~24)** → 1388 (청소년상담)
  - **가정폭력·성폭력 키워드 (Theme 6 분기)** → 1366 (여성긴급) + 1577-0199
  - **직장 갑질·괴롭힘 키워드 (Theme 7 분기)** → 1644-0644 (직장갑질119) + 129 (보건복지콜센터)
  - **종교적 학대 키워드** → 1577-0199 + 한국심리상담센터 catalog
- **R1 의미 매칭 — 발화자 구분 정책**: 사용자가 *자해·자살 키워드* 를 발화하면 *즉시* 위기 자원 안내 + 일반 흐름 일시중단. *본문 인용* (욥 3:11 *"어찌하여 내가 태에서 죽어 나오지 아니하였던가"* 등) 은 흐름 차단 없이 footer + 위기 자원 카드만 동반. AI 분류기는 입력 source 메타데이터 (`source=user_input` vs `source=scripture_quote`) 를 받아 분기. 정규식 단독으로는 발화자 구분 불가능하므로 *반드시 의미 모델* 통과. *이 R1 라우팅은 법적 의무 — 완화·제거 금지*.

## 2. Theme 5 — 고통과 진리 (욥기)

### 2.1 정체성

> *"왜 의인에게 고통이 오는가"* — 답이 없는 질문 앞에 정직하게 서는 도구.

성경적 근거: 욥기 1~42장. 욥의 *세 친구* 가 인과응보로 설명을 시도하지만 *욥기 38~41장* 에서 하나님은 *질문에 답하지 않고 더 큰 질문* 으로 받으심.

### 2.2 영성·감성·이성 3차원

| 차원 | 사용자 경험 | 활동 |
|---|---|---|
| **영성** | *"내 고통의 답이 *지금* 없을 수 있다"* | 욥 38:4 ("내가 땅의 기초를 놓을 때에 네가 어디 있었느냐") — *답을 알지 못함의 자유* |
| **감성** | *"욥처럼 분노하고 한탄해도 된다"* | 욥 3장 *(태어난 날을 저주)* + 사용자 *"내 고통에 이름 붙이기"* 자유 작성 |
| **이성** | *"인과응보가 *늘* 옳지 않다는 것을 알아두기"* | 욥 친구들의 인과응보 논리 → *왜 틀렸나* 분석 (현대 *공평한 세상 신화* 와 연결, 서지는 footer) |

### 2.3 내적 단련 메커니즘 (교육적 어휘)

**의미 재구성 서사**:
- 큰 일을 겪은 사람은 *의미 체계* 가 흔들림 — 욥의 친구들이 시도한 *"이유 찾기"* 와 같은 자리
- 회복은 *옛 의미를 그대로 되찾는 것* 이 아니라 *새 의미를 짓는 것* — 욥 42 장 *"내가 너에 대하여 귀로 듣기만 하다가 이제 눈으로 보았나이다"* 와 일치
- *답을 못 찾는 단계* 도 *훈련의 한 자리* — 압박 X

**외상 후 성장 서사 (Post-traumatic Growth 서사 차용)**:
- 큰 일 뒤 *5가지 자리* 에서 새로 만나짐: 자기 인식, 타인과의 관계, 새 가능성, 영적 변화, 인생 감사
- 단, **성장 압박 위험**: *"고난 뒤 성장하라"* 는 가스라이팅이 됨. 욥기는 *성장 압박 없이* 고통을 인정 → 안전한 모델

**공평 세상 신화 깨기**:
- 사람은 *"세상은 공평하다"* 믿음 유지를 위해 *피해자를 비난* 함 (욥 친구들의 패턴)
- 사용자가 *자기 비난* 모드일 때 이 패턴 노출 → *"네 잘못이 아닐 수 있다"* 라는 다른 관점 제시

> 근거 서지 (학자 이름은 footer 처리): Neimeyer (2001) 의 *Meaning Reconstruction*; Tedeschi & Calhoun (1996) 의 *Post-traumatic Growth*; Lerner (1980) 의 *Just-World Hypothesis*. — 본 앱은 *학자 이론 자체를 도구화하지 않음*; 욥기 서사의 *내적 단련 어휘* 로만 차용.

### 2.4 안전선 (R1~R5 적용)

**R1 (자해 키워드 라우팅 — 법적 의무)**:
- 욥 3:11 *"어찌하여 내가 태에서 죽어 나오지 아니하였던가"* 같은 강한 표현 노출 시 *위기 자원 카드* 항상 동반
- 사용자가 욥기 읽는 중 자해·자살 키워드 발화 → 즉시 위기자원 안내 (109 등) + 일반 흐름 일시중단

**R2 (고난 footer 강제)** — Theme 5 는 가장 엄격하게 적용:

> *이 묵상은 자발적으로 마주하는 고난의 의미를 다룹니다. 가정폭력·종교적 학대·정신적 학대 같은 피해 상황을 견디라는 강요가 아닙니다. 피해 상황에 있는 분도 안전하게 이 묵상에 머무를 수 있도록, 안전 자원을 항상 함께 안내합니다. (109 / 1577-0199)*

**R3 (회복 압박 회피)**:
- ❌ "욥처럼 인내하세요" → ✅ "욥은 *3일 동안 침묵* 했습니다 (욥 2:13). 침묵도 정당한 반응입니다."
- ❌ "고난 뒤 두 배로 받을 거예요" (욥 42:10 인용 오용) → ✅ "욥의 회복은 *욥에게* 일어난 한 사건입니다. 모든 고난이 그렇게 끝난다는 약속이 아닙니다."

**R4 (트리거 동의)**:
- 욥 1:18~19 *(자녀들의 죽음)* 노출 전 *사별 관련 부담이 있을 수 있는 사용자* 를 위한 consent card 노출 + skip 옵션

**R5 (AI opt-out)**:
- AI 응답 OFF 사용자에게는 *욥기 본문* 만 노출, *해석·묵상* 은 정적 fallback 사용 (사전 운영자 self-review 통과한 시편 22, 88편 등)

  - 감성: 욥 3장 (저주) → "내 고통에 이름 붙이기" 자유 작성 (R1 키워드 게이트)
  - 이성: 욥 친구 3인 논리 분석 → "공평한 세상이라는 신화 깨기" 워크시트

### 2.6 신학 분쟁 가능 지점 (disputed_points)

- 욥 1:6~12 *(사탄에게 욥을 허락하심)* — *하나님의 주권* vs *악의 문제* — 다중 입장 인정 (Augustinian / Free will defense / Process theology). 단일 답 제시 X
- 욥 42:7 *(엘리바스의 신학을 책망하심)* — 친구들 신학이 *틀렸다는 명시* 는 *인과응보 신학에 대한 성경 자체의 반증* 으로 사용
- 욥 38~41 *(하나님의 답변)* — *직접 답이 없는 답* — 단순 인내 메시지로 환원 금지

## 3. Theme 6 — 마음을 지키는 것 (잠 4:23)

### 3.1 정체성

> *"모든 지킬 만한 것 중에 더욱 네 마음을 지키라 생명의 근원이 이에서 남이니라"* (잠 4:23)

마음을 *닫는* 도구가 아니라 *경계 (boundary)* 를 짓는 도구. *자기 친절 + 한계 설정* 의 성경적 표현.

### 3.2 영성·감성·이성 3차원

| 차원 | 사용자 경험 | 활동 |
|---|---|---|
| **영성** | *"내 마음이 누구의 것인가 인식"* | 잠 4:23 + *"내가 책임지는 영역" / "하나님께 맡기는 영역"* 분리 워크시트 |
| **감성** | *"무엇이 내 마음을 흔드는지 알아채기"* | 사용자 *"오늘 내 마음을 흔든 사건 3개"* → 강도 슬라이더 + *"이건 *내 책임 영역* 인가"* 분류 |
| **이성** | *"경계 설정의 실제 문장 만들기"* | *명확히 말하기 7단계* 워크시트 + 성경적 표현 결합 → 사용자 *"이번 주에 한 사람에게 할 한 문장"* 작성 |

### 3.3 내적 단련 메커니즘 (교육적 어휘)

**자기 친절 (3요소)**:
- *자기 친절* + *공통 인간성 인식* + *마음챙김*
- 자기비판은 줄고 회복력은 올라가는 자리. 잠언이 가진 *지혜의 거리* (격언적) 가 *자기와 거리 두기* 와 일치

**한계 설정 — 명확히 말하기 7단계**:
- 묘사 / 표현 / 단호히 말함 / 강화 / 마음챙김 / 자신감 있게 / 협상
- 7 단계 모두 잠언적 어휘로 재표현 가능 — *"네 입의 말을 다스리라"* (잠 13:3) = 묘사 + 마음챙김
- *"마음을 지킴" = 폐쇄가 아니라 의도된 표현*

**허용의 창**:
- 마음과 몸이 *너무 들뜨거나 너무 가라앉는 자리* 로 빠지지 않는 *허용의 창*
- 마음을 *지킨다* = *허용의 창 안에 머무름*
- 잠 4:23 은 *생명의 근원이 이에서 남* — 몸·감정·행동의 연쇄 인식과 일치

> 근거 서지 (학자 이름은 footer 처리): Neff (2003) 의 *Self-Compassion*; Linehan 의 DBT *DEAR MAN*; Siegel (2010) 의 *Window of Tolerance*; Kross (2011) 의 *self-distanced perspective*. 본 앱은 *임상 도구 처방* 이 아니라 *잠언의 단련 어휘 보조* 로만 사용.

### 3.4 안전선 (R1~R5 적용)

**R1 (자해 키워드 라우팅 — 법적 의무)**:
- 사용자가 *"마음을 지키지 못한 자기 비난"* 류 자해·자살 키워드 발화 → 즉시 위기자원 안내 + 흐름 일시중단. 비-키워드의 자기비난에는 storyteller 가 *"마음을 지키지 못한 것이 *너의 잘못* 이 아닐 수 있어요"* 라고 다른 관점 제시

**R2 (고난 footer)**:
- *"네 마음을 지키라"* 가 *가정폭력 피해 상황의 사용자에게* *"네가 마음을 지키지 못해서 맞은 거다"* 로 들릴 위험 → R2 footer + *"마음 지킴은 가해자를 보호하는 도구가 아닙니다. 안전이 우선입니다. 피해 상황에 있는 분도 이 묵상에 안전하게 머물 수 있게 자원을 함께 안내합니다."* 강조 메시지

**R3 (회복 압박 회피)**:
- ❌ "오늘부터 마음을 지키세요" → ✅ "오늘 *한 가지* 만 다르게 해보는 것도 마음 지킴입니다."
- 단순 *의지력 메시지* ("그냥 마음 단단히 먹어") 차단

**R4 (트리거 동의)**: 해당 없음 (Scene 콘텐츠 아님)

**R5 (AI opt-out)**:
- AI OFF 사용자 → 잠언 카드 정적 노출 + *workbook PDF 다운로드* 형태로 fallback

### 3.6 신학 분쟁 가능 지점 (disputed_points)

- 잠 4:23 의 *"마음 (lev / kardia)"* — 감정 중심인가 의지 중심인가 — 학자별 견해 차 (Bruce Waltke vs Tremper Longman)
- *"네 마음을 지키라"* vs *"내 마음을 의탁하라"* (시 37:5) 의 균형 — 자기 책임과 의탁의 *분쟁* 명시
- *자기 친절 어휘* 사용 시 *불교 자비 (mettā) 와의 연결성* 명시 — *Christian 전유* 가 아님 인정. *한국 보수 개신교 일부 진영* 에서는 *불교적 명상 어휘 유입* 에 대한 우려가 여전히 있다 — 본 앱은 *어휘 자체를 임상 처방으로 도입하지 않고*, 잠언의 *내적 단련 어휘* (자기 친절·공통 인간성·마음챙김) 만 storyteller 적으로 차용. 사용 시 *Christian 신학 자원* (시 103:14 *"하나님이 우리의 체질을 아심"*) 과 *함께* 제시.

## 4. Theme 7 — 사람을 두려워하지 않는 것 (잠 29:25, 사 51:7)

### 4.1 정체성

> *"사람을 두려워하면 올무에 걸리게 되거니와 여호와를 의지하는 자는 안전하리라"* (잠 29:25)
> *"의를 아는 자들아 마음에 내 율법이 있는 백성들아 너희는 사람의 비방을 두려워하지 말며 그들의 비방에 놀라지 말라"* (사 51:7)

사회불안·평가 두려움·인정 갈증을 다루는 도구. *"무관심하라"* 가 아니라 *"두려움의 방향을 옮기라"*.

### 4.2 영성·감성·이성 3차원

| 차원 | 사용자 경험 | 활동 |
|---|---|---|
| **영성** | *"내가 두려워하는 대상의 정체 인식"* | 잠 29:25 + *"내가 가장 두려워하는 사람의 시선" / "그 시선이 내 결정을 어떻게 흔들었나"* 워크시트 |
| **감성** | *"두려움의 신체적 신호 알아채기"* | *"비교당했을 때 / 평가받았을 때 / 무시당했을 때"* 각 신체 반응 입력 (가슴 두근거림·위·목 등) — 인터로셉션 |
| **이성** | *"평가 두려움 안의 *생각 왜곡 5종* 찾기"* | 평가 두려움 자가 체크 16문항 + 생각 기록 워크시트 — *"이 평가가 사실인가 / 추측인가 / 일반화인가"* |

### 4.3 내적 단련 메커니즘 (교육적 어휘)

**평가 두려움의 자리**:
- 사회불안의 핵심: *부정 평가에 대한 두려움*
- *자기 초점 주의* 가 두려움을 유지하는 자리
- 잠 29:25 의 *"올무"* 는 *자기 초점 주의의 함정* 과 정확히 일치

**사람 두려움 (성경적 어휘) ↔ 인정 갈증 (일상 어휘)**:
- 성경적 *사람 두려움* 을 *인정 갈증* 과 한 자리에서 다루는 storyteller 흐름
- *평가 두려움* 을 *생각 왜곡 인식* 으로 다루는 일반적 단련 어휘

**두려움 방향 다시 맞추기** (본 앱의 통합 서사):
- *두려움 = 0* 이 목표가 아니라 *두려움의 대상 재정렬* 이 목표 — 잠 29:25 의 *방향성* 과 결합
- 보조 참고: *모든 사람을 만족시킬 수 없다는 인식* 이 자유의 시작이라는 통찰

> 근거 서지 (학자 이름은 footer 처리): Clark & Wells (1995) 의 *Social Anxiety Cognitive Model*; Welch (1997) *When People Are Big and God Is Small*; 한국 사회불안 인지행동치료 임상 자원; Brené Brown (2012) *Daring Greatly*. 본 앱은 *임상 치료 제공자가 아닌 storyteller* 로, 위 자료는 *서사·어휘 보조* 로만 사용.

### 4.4 안전선 (R1~R5 적용)

**R1 (자해 키워드 라우팅 — 법적 의무)**:
- 사용자가 *"평가에서 사라지고 싶다"* / *"인정받지 못하면 죽고 싶다"* 류 자해·자살 키워드 발화 → 즉시 위기자원 안내 (109 등) + 흐름 일시중단

**R2 (고난 footer)**:
- *"사람 두려워하지 마라"* 가 *직장 갑질·괴롭힘 피해 상황의 사용자에게* *"네가 약해서 두려워한다"* 로 들릴 위험 → R2 footer + *"두려움은 실재 위협의 신호일 수 있습니다. 안전 확보가 우선입니다. 피해 상황에 있는 분도 이 묵상에 안전하게 머물 수 있게 자원을 함께 안내합니다."* 강조

**R3 (회복 압박 회피)**:
- ❌ "사람을 신경 쓰지 마세요" → ✅ "오늘 *한 사람의 시선* 만 잠시 옆으로 두고 결정해 보는 것도 충분합니다."
- *완전한 무관심 요구* 차단. *부분적 자유* 표현.

**R4 (트리거 동의)**: 해당 없음

**R5 (AI opt-out)**:
- AI OFF → 생각 기록 워크시트 PDF + 잠언 카드 정적 fallback

### 4.5 핵심 기능

```

  ├── 잠 29:25 + 사 51:7 노출 + R2 footer
  ├── 입장 카드: "두려움 = 0 이 목표가 아닙니다. 두려움의 방향만 살펴봅시다."
  └── 3차원 선택

[차원별 활동]
  - 영성: "내가 두려워하는 사람 1명" → "그 사람의 시선이 내 결정을 어떻게 흔들었나" 워크시트
  - 감성: 몸의 신호 입력 (몸 느낌 알아채기)

  - 위기 자원 카드 (R1)
  - "AI 보조 — 본문은 성경 참조" footer
```

### 4.6 신학 분쟁 가능 지점 (disputed_points)

- *"사람을 두려워하지 말라"* vs *"부모를 공경하라"* (출 20:12) — *공경* 과 *두려움* 의 구분 (Karl Barth 의 *Furcht* vs *Ehrfurcht*) 명시
- *"여호와를 두려워하는 것이 지식의 근본"* (잠 1:7) — *fear* 의 의미가 *공포* 가 아니라 *경외* — 영지주의적 *내적 신성 합일* 어휘로 미끄러지지 않게 주의
- *Welch 의 사람 두려움 개념* — 미국 *biblical counseling* 전통의 산물. 한국의 일상 *사회불안 단련 어휘* 와 호환 가능하나 *biblical counseling 의 모든 입장* 을 받아들이는 것은 아님. 본 앱은 storyteller 로서 *어휘만 차용*, 임상 처방 X.

### 4.7 faith_tone 3단 예시 (잠 29:25 동일 본문)

| **strong** | "*사람을 두려워하면 올무에 걸리게 되거니와 여호와를 의지하는 자는 안전하리라* — 두려움의 방향이 바뀌는 자리에서 자유가 옵니다." |
