  (1577-0199 / 1393 / 한국심리상담센터) 안내, 일반 흐름 차단
- *moral injury 방지* (Jones 2022 PMID 35609469 직접 매핑) — Theme 5 (고통)
  / Theme 11 (예수 십자가) 콘텐츠에 *가스라이팅 방지 footer* 자동 첨부
- *부활 회복 압박* 방지 — 우울증·자해 이력 사용자에 회복 narrative 자동 완화
- AI 응답 opt-out 토글 (기본 ON)
- 데이터 완전 삭제 30일 grace (GDPR / 한국 개인정보보호법)

## 자문 역할 · 일주일 시간 부담

- 콘텐츠 변경 시 *임상 체크리스트 4종* (1-5 score) 검토:
  · trauma_safety (트라우마 자극 안전)
  · crisis_resource_compliance (위기 자원 catalog 적절 활용)
  · moral_injury_risk (Jones 2022 매핑)
  · evidence_quality (인용 PMID 적절성)
- 단독 **Veto 권한** — moral_injury / 자해 안전망 부재 시 신학 verdict 무관
  하게 reject 가능
- 주간 시간 부담: 평균 2~4시간 (검토 큐 비례, V1.0 MVP 기준)
- 검토 SLA — routine 5 영업일 / 고난 narrative 10 영업일 / 안전장치 변경
  3 영업일 (긴급)

  (PMID 40859941) 프레임워크 모델 채택
- 정통 개신교 신학 범위 안 (영지주의·뉴에이지 해석 차단)

- 사용자가 *영성·감성·이성* 3차원 중 진입 모드 선택 (사용자 주체성)
- 신학 자문 + 임상 자문 *2-of-2 approve* 필수 (Theme 11 예수 콘텐츠)

## 자문 역할

- 신앙 통합 임상 경험을 *trauma-informed care* 와 결합해 정책 입안
- 위기 자원 catalog (1577-0199 / 한국심리상담센터 등) 의 *문화적 적합성*
  검토

## 시간 부담 / 보상

- 검토 SLA — routine 5 영업일 / 고난 narrative 10 영업일
- V1.0 MVP: 시간당 명목 보상 + 학회 협력 형태 (COPE 모델)

## 학회 차원 협력의 가능성

  - 학회 회원 1~2명의 자문가 영입

## 5. 답변 처리 워크플로

영입 의사 답변 받으면:

1. **30분 화상 미팅** — 거버넌스 (`CLINICAL-REVIEW.md`) 5 섹션 + 본인 동의 범위 + Conflict of interest 확인
2. **OAuth 가입** — 자문가가 lemuel-xr 에 *OAuth 로 가입* (`users` row 생성, `external_id` 결정)
3. **자격 / 동의 범위 합의** — 서면 (이슈 코멘트 또는 별도 PR `docs/governance/reviewers/{role}-{nickname}.md`)
4. **시드 등록** — `application-bootstrap.yml` 에 entry 추가 → backend 재배포 (`ReviewerBootstrap` 자동 시드)
5. **첫 검토 큐** — 시범 콘텐츠 1개 (Theme 1 routine 또는 Theme 5 고난) 검토 부탁, peer cross-training
6. **운영 안내** — Admin Telegram 봇 채널 link, 검토 큐 URL, SLA
