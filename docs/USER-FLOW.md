# USER-FLOW — 사용자 여정 wireframe + 흐름 설계

> **범위**: 첫 진입 → 30일 사용자 여정. 화면별 ASCII wireframe + 전환 조건.

---

## 0. 핵심 원칙

1. **익명 우선** — 첫 화면에 가입·로그인 강요 X
2. **30초 안 첫 가치 전달** — 진입 → 감정 입력 → *즉시 콘텐츠* 제공
3. **이탈 자유** — 어디서든 *나가기* / *건너뛰기*. 압박 0
4. **위기 우선** — 자해·자살 키워드 감지 시 *모든 흐름 중단* → 자원 노출

---

## 1. 사용자 여정 — 전체 그림

```
Day 0: 첫 진입 → 온보딩 (30초) → 첫 감정 입력 → 콘텐츠 → 종료
       │
       ├─ Day 1~3: 매일 1~3회 진입 → 감정 입력 → 콘텐츠 → 종료
       │           (재방문 후크: 푸시 알림 — 옵션)
       │
       ├─ Day 7: 첫 *주간 회복 카드* 노출
       │         "이번 주 너의 감정 어휘가 5 → 9 개로 늘었어요"
       │
       ├─ Day 14: 첫 트랙 B (게임) 추천 시점
       │         "두려움을 자주 만나시네요. 다윗을 만나보실래요?"
       │
       ├─ Day 30: *큰 회복 리포트*
       │         "한 달 함께 한 90 분이 어떤 변화를 만들었나요?"
       │
       └─ Day 90: 사용자 데이터 보존 만료 알림 (옵션)
```

## 6. 일기·시편 작성 흐름 (트랙 A 직접 진입)

```
첫 화면 → "오늘의 기록" 메뉴 →
       │
       ├─ 일기 자유 형식
       ├─ 5W1H 가이드
       ├─ 시편 형식 (탄식/간구/감사/찬양)
       └─ 묵상 일기 (어제·오늘 잇기)
       
작성 중:
       - 자동 저장 (5초마다)
       - 글자 수 표시 (Pennebaker 효과 차원)
       - 위기 키워드 감지 → 위기 자원 노출
       
완료:
       - 저장 / 폐기 선택
       - "AI 묵상으로 변환하시겠어요?" (옵션, 거절 가능)
       - 변환 결과 검토 → 저장 / 다시 / 취소
```

## 12. 화면 간 전환 규칙

## 14. 모바일 vs XR 디바이스 분기

- **Quest 3 / Vision Pro / Galaxy XR**: 트랙 A 콘텐츠 일부 (시편 낭독·일기) + 트랙 B 게임 전체
- **iOS·Android Phone**: 트랙 A 전체 + 트랙 B 미진입 (게임은 XR 권유 화면만)
- **Web (PC)**: 트랙 A 전체 (관리·일기) + 트랙 B 미진입

→ 진입 디바이스 감지 후 *적절한 화면만* 노출.
