## 축 배타 할당

이 미션의 축은 **"드러낼 것인가 / 언제 어떻게 드러낼 것인가"**다(`disclose_label`).
다니엘 미션의 축(협력의 경계)·베드로 미션의 축(행동 이후의 자기 정죄)과 **겹치지 않게** 설계했다
(seed §0). "타협 없이 지켰다"류 다니엘 축 어휘를 이 미션에 들이지 않는다.

## 스키마 정본

  고정 순서·번호 매김(1/2/3) UI 를 명시적으로 금지한다(seed §5-0) — 세 카드가 개시를 향한

## 안전 제약축 (R1~R5 요약)

- **R1** — 자해 본문은 없으나 박해·말살 위협 서사라 `R1_voice_self_harm_listener` 5/5 Scene 상시,
  해시만 저장. `dwell_limit` 는 **두 곳**: Scene 1 조서 낭독 블록(3초) + Scene 4 4:16 "죽으면
  죽으리이다" 블록(3초, R1 에 가장 가까운 문장). 4:16 은 인용 자막으로만, 사용자 1인칭 대사로
  재생성하지 않는다.
- **R2** — "이 박해가 너를 왕후로 세운 이유" 류 목적론 전면 금지. 모르드개는 화자이지 도덕적
  권위가 아니다(4:14 위협 어조를 내레이션이 동의하는 것으로 처리하지 않는다).
- **R3 — 이 미션의 최우선 축.** "숨는 건 비겁하다"·"언젠간 말해야 한다"·"용기를 내면 된다" 류
  전면 금지. Scene 3 세 카드는 전부 정당하며 결말 품질에 차등이 없다. 에스더의 개시는 왕이 두 번
  물은 뒤에야(5:3→5:6→7:2) 이루어지는 **단계적 개시**이며 즉시 개시가 아니다.
- **R4** — Scene 1 Pre-Scene 0 동의 게이트(집단학살 조서 3:13 사전 고지). skip 시 `scene1.yml`
  안의 `s1_alt_summary` 라우트로 대체(6번째 파일 생성 금지).
- **R5** — `default_path: static_curation` + `llm_optin_only: true`. Scene 3·5 라우트 전부 정적
  텍스트 병기(`static_text_ko`) — 기본 경로에서 LLM 은 호출되지 않는다.
- **crisis 자원** — 하드코딩 금지, `{{crisis_resources.default}}` 토큰만. 본 디렉터리 yml 5개
  파일 전부에 `crisis_reminder` 게이트로 배치(`grep -l 'crisis_resources.default' scene*.yml` = 5).

## 4:14 — R2·R3 이중 지뢰

에스더 4:14 는 이 미션에서 가장 다루기 조심스러운 절이다. "네가 왕후의 자리를 얻은 것이 이 때를
위함이 아닌지 **누가 알겠느냐**"는 의문형이며, 본문은 스스로 "네가 만일 잠잠하여 말이 없으면
유다인은 **다른 데로 말미암아 놓임과 구원을 얻으려니와**"라고 먼저 말한다 — 침묵을 선택해도
구원은 온다는 절반이 이 미션 R3 의 신학적 뿌리다. Scene 3 는 이 절반을 반드시 포함한다.

## 마무리 문구 9(+1)종

Scene 5 는 `disclose_label`(nondisclosure/gather_first/speak_now/null 폴백) × `faith_tone`
(strong/balanced/soft) 조합의 정적 큐레이션 마무리 문구로 끝난다(null 은 1문안 고정 — 실질
9+1 패턴). 전문은 `scene5.yml` 의 `br_s5_closing_message.routes[].static_text_ko`.
"당신은 지금 안전한 자리에 있고" 류 **사용자 상태 단정 문장은 전 Scene 에서 금지**한다 — 그
카드를 고르는 사람은 대체로 실제로 안전하지 않은 상황(가정·직장·이주 신분)에 있기 때문에
고르며, 상태를 단정하는 것은 위로가 아니라 오독의 통보다(seed §5-2-a). 대신 사용자의 **선택**만
인정한다.
