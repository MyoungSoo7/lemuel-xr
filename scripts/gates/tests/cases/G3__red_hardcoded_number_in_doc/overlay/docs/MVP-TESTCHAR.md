## 3. 배제 본문 선언 (§7-2 마커 라인)
- EXCLUSION-DECL: 기손 시내로 내려다가 (왕상 18:40) — 폭력 묘사라 서사에서 배제.
- EXCLUSION-DECL: 하사엘의 칼을 피하는 (왕상 19:17) — 심판 대행 위임이라 배제.
- EXCLUSION-DECL: 갈멜산 대결 — 개념 참조. 사용 장 본문에는 등장하지 않는다.
- EXCLUSION-DECL: 심판 대행자 — 개념 참조. 사용 장 본문에는 등장하지 않는다.

## 4. 안전 축
- R1: 다섯 Scene 전부 상시 음성 리스너.
- R2: Scene 2 축이 토큰 4종으로 집행된다.
- R3: Scene 3·4 는 구조 검사로, Scene 5 는 토큰 4종으로 집행된다.
- R4: Scene 2·4 진입 전 동의 카드 + 건너뛰기 대체 Scene.
- R5: Scene 4·5 는 정적 큐레이션이 기본 경로다.

## 5. 3차원 매핑
- 영성: 임재, 쉼의 정당성, 동행.
- 감성: 돌봄받음, 정직한 토로, 안도.
- 이성: 회복 순서의 재구성, 쉼의 근거, 나누는 사명.
